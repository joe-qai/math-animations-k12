分式

分母里有字母

二分之一、四分之三，分子分母都是具体的数；把分母换成一个字母，比如 x 分之二，就成了分式。分式的麻烦全在分母上：分母不能等于零，所以要先算「什么时候有意义」；分子为零时整个分式未必为零，还要回头看分母。这节课从定义讲到四则运算——约分、通分、乘除、加减，最后落在一条铁律上：约分只能约因式，不能约项。

知识精讲

概念 · 公式 · 例题
概念

什么是分式

形如 B 分之 A（写成 A/B）的式子，如果 A、B 都是整式，并且 B 中含有字母，就叫做分式。例如 2/x、(x + 1)/(x − 1) 都是分式。

关键在分母：分母必须含字母。x/2 的分母是 2，它仍是整式，不是分式。判断时只看分母有没有字母。

公式

有意义的条件与值为零

分式的分母不能等于零。所以 2/x 要求 x ≠ 0；(x + 1)/(x − 1) 要求 x ≠ 1。做法：让分母等于零，解出来的值就是不能取的。

分式的值为零，要同时满足两个条件：分子等于零，并且分母不等于零。例如 (x − 2)/(x + 1) 值为零时，由 x − 2 = 0 得 x = 2，此时分母 2 + 1 = 3 ≠ 0，成立。只让分子为零不够，必须回头检查分母。

值为 0：分子 = 0 且 分母 ≠ 0

公式

基本性质

分式的分子与分母同乘（或同除以）一个不等于零的整式，分式的值不变：A/B = (A·C)/(B·C)，其中 C ≠ 0。

这一条是约分与通分的依据：同除以公因式就是约分，同乘适当的整式把分母化相同就是通分。乘的那个式子不能是零，否则分母直接没了。

A/B = (A·C)/(B·C)（C ≠ 0）

公式

约分与最简分式

把分子分母的公因式约去，叫约分。6a²b / 9ab²，分子分母都除以 3ab，得 2a / 3b。

约分的关键是先把分子分母因式分解、写成乘积，公因式才看得清。约到分子分母没有公因式为止，这样的分式叫最简分式。

注意：约分只能约整个因式，不能约项。(x + 1)/(x + 2) 里的 x 不能约，因为它不是分子分母的公因式。

6a²b / 9ab² = 2a / 3b

公式

乘除与加减

乘法：分子乘分子，分母乘分母，a/b × c/d = ac/bd。除法：除以一个分式等于乘它的倒数，a/b ÷ c/d = a/b × d/c = ad/bc。

加减：同分母的，分母不变，分子相加减；异分母的，先通分再算。最简公分母的找法：系数取各分母系数的最小公倍数，字母取各分母中所有字母的最高次。

例如 1/x + 1/y，最简公分母是 xy，结果是 (y + x)/(xy)。算完记得检查能不能再约分。

a/b ÷ c/d = ad/bc

一句话记住

分式是分母中含字母的式子，判断只看分母。分母不能为零，这是有意义的条件；值为零必须分子为零且分母不为零。基本性质：分子分母同乘或同除以一个不为零的整式，值不变。据此可以约分（先因式分解，约到最简分式）和通分（找最简公分母：系数最小公倍数、字母最高次）。乘除：分子乘分子、分母乘分母，除以一个分式乘它的倒数。加减：同分母直接算，异分母先通分。约分只能约因式，不能约项。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 以为分母有字母才算分式，把 x/2 也当成分式——它的分母是数，是整式。
  • 把「有意义」和「值为零」混为一谈：有意义看分母不为零，值为零要分子为零且分母不为零。
  • 约分时约掉了项而不是因式，比如把 (x + 1)/(x + 2) 里的 x 约掉。
  • 异分母加减忘记通分，直接把分子分母分别相加。
  • 除法忘记把除式的分子分母颠倒，或颠倒后忘了同时改乘号。
