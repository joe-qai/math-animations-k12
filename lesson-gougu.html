勾股定理

a² + b² = c²，为什么一定成立

梯子靠墙的生活问题出发，把三条边上的正方形切成小方格，一格一格搬进斜边正方形——定理就这样被看见。

知识精讲

概念 · 公式 · 例题
概念

从梯子靠墙说起

一把梯子斜靠在墙上，梯子底端离墙 3 米，墙高 4 米。梯子有多长？

把地面、墙面和梯子看成一个直角三角形：两条直角边是 3 米和 4 米，斜边就是梯子的长度。

公式

勾股定理

在直角三角形中，两条直角边的平方和，等于斜边的平方。

这里 c 一定表示斜边，也就是直角对面的那条最长边。

a² + b² = c²

概念

面积法：小方格搬家

在两条直角边上各画一个正方形，面积分别是 9 和 16；在斜边上也画一个正方形。

把 9 个小方格和 16 个小方格切成边长 1 米的小块，一共 25 块，正好铺满斜边上的大正方形，一格不剩。

所以两条直角边上的正方形面积之和，等于斜边上的正方形面积。这就是定理的几何含义。

例题

用它算长度

直角边 3 和 4：c² = 9 + 16 = 25，所以 c = 5（米）。

已知斜边 13、一条直角边 5：另一条直角边 b² = 13² − 5² = 169 − 25 = 144，b = 12。

概念

逆定理：判断直角三角形

反过来也成立：如果三角形三边满足 a² + b² = c²，那么它一定是直角三角形，且 c 所对的角是直角。

例如 6、8、10：36 + 64 = 100，是直角三角形；而 2、3、4：4 + 9 = 13 ≠ 16，不是直角三角形。

一句话记住

勾股定理说的是面积关系：两条直角边上的正方形面积之和，等于斜边上的正方形面积。a² + b² = c²。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 勾股定理只适用于直角三角形，锐角三角形、钝角三角形都不成立。
  • c 必须是斜边。题目没有明说时，要先找最长边。
  • 算面积时单位要平方，写「米」就错了。
