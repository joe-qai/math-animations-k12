知识精讲

概念 · 公式 · 例题
概念

定义与一般形式

只含一个未知数、未知数的最高次数是 2 的整式方程，叫一元二次方程。一般形式是 ax² + bx + c = 0，其中 a ≠ 0。

a 是二次项系数，b 是一次项系数，c 是常数项。系数要带符号：3x² − 5x + 2 = 0 中 a = 3、b = −5、c = 2。

ax² + bx + c = 0（a ≠ 0）

概念

解法一：开平方与因式分解

x² = 36，直接开平方得 x = ±6。x² − 5x = 0，提公因式得 x(x − 5) = 0，所以 x = 0 或 x = 5。

因式分解的关键，是把方程变成两个因式相乘等于零；两个因式里只要有一个是零，乘积就是零。

x² = 36 → x = ±6

公式

解法二：配方法

以 x² + 6x − 7 = 0 为例：移项得 x² + 6x = 7，两边加上一次项系数一半的平方 9，得 (x + 3)² = 16，开方得 x + 3 = ±4，所以 x = 1 或 x = −7。

口诀：移常数、加半数平方、写完全平方、开方。加的永远是「一次项系数一半的平方」。

(x + 3)² = 16

公式

解法三：公式法与判别式

求根公式：x = (−b ± √(b² − 4ac)) / (2a)。根号里的 b² − 4ac 叫判别式，记作 Δ。

Δ > 0 有两个不相等的实根；Δ = 0 有两个相等的实根；Δ < 0 没有实根。用公式前必须先把方程化成一般形式。

Δ = b² − 4ac

公式

根与系数的关系

若 x₁、x₂ 是 ax² + bx + c = 0 的两根，则 x₁ + x₂ = −b/a，x₁·x₂ = c/a。

例：x² − 5x + 6 = 0 的两根是 2 和 3，和 2 + 3 = 5，积 2 × 3 = 6，正好对得上。

x₁ + x₂ = −b/a

例题

例：实际问题要检验根

一块长方形菜地，长比宽多 2 米，面积 24 平方米，求宽。设宽为 x，得 x(x + 2) = 24，即 x² + 2x − 24 = 0。

因式分解得 (x + 6)(x − 4) = 0，x = −6 或 x = 4。宽度不能是负数，所以只能取 x = 4，长就是 6 米。

x = 4，长 6 米

一句话记住

一元二次方程的一般形式是 ax² + bx + c = 0（a ≠ 0），a、b、c 分别是二次项系数、一次项系数、常数项，取值要带符号。解法有四种：能开平方的直接开，能分解的先因式分解，一般情况用配方法（加一次项系数一半的平方）或公式法。求根公式是 x = (−b ± √(b²−4ac)) / (2a)，判别式 Δ = b² − 4ac 大于零有两个不等实根，等于零有两个相等实根，小于零没有实根。根与系数的关系是 x₁ + x₂ = −b/a、x₁·x₂ = c/a。解实际问题时一定要检验，负数、超过范围的根要舍去。记住：先化一般式，再挑解法。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • a 忘了不等于 0：二次项系数是字母时，先讨论它不为零。
  • 用公式法前没化一般形式：a、b、c 直接取错。
  • 系数漏掉负号：3x² − 5x + 2 = 0 中 b = −5，不是 5。
  • 配方加错数：要加一次项系数一半的平方，不是系数本身。
  • 实际问题不检验：长度为负的根要舍去。
