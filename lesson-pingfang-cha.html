平方差公式

剪拼图形看懂 (a+b)(a−b)=a²−b²

一张边长 a 的正方形纸，从角上剪掉边长 b 的小正方形，剩下一个 L 形，面积是 a² − b²。把 L 形剪成两块重新拼起来，正好是一个长 a + b、宽 a − b 的长方形。面积不变，所以 (a + b)(a − b) = a² − b²。这节课先用剪纸看懂这条公式，再用乘法展开验证，最后练三种常见的变化。

知识精讲

概念 · 公式 · 例题
概念

剪一刀就能看懂

边长 a 的正方形，面积是 a²。从角上剪掉一个边长 b 的小正方形，剩下的 L 形面积就是 a² − b²。

把 L 形沿虚线剪成两块，把上面那块转个方向拼到右边，正好拼成一个长方形：长是 a + b，宽是 a − b。剪纸前后面积没变，所以 (a + b)(a − b) = a² − b²。

公式

平方差公式

两个数的和乘这两个数的差，等于这两个数的平方差。

用乘法也能验证：(a + b)(a − b) 展开得 a² − ab + ab − b²，中间的 −ab 与 +ab 互为相反数，相加得 0，只剩 a² − b²。

(a + b)(a − b) = a² − b²

公式

认准「相同项」与「相反项」

套公式前先找：哪一项在两个括号里完全一样（相同项），哪一项符号相反（相反项）。结果是「相同项的平方 − 相反项的平方」。

(x + 3)(x − 3)：相同项是 x，相反项是 3，结果 x² − 9。(2a + b)(2a − b)：相同项是 2a，相反项是 b，结果 (2a)² − b² = 4a² − b²，系数也要平方。

如果顺序是乱的，例如 (y − 2x)(y + 2x)，先用交换律调成 (y + 2x)(y − 2x)，再套公式。

相同项的平方 − 相反项的平方

一句话记住

平方差公式：(a + b)(a − b) = a² − b²。几何上就是「大正方形剪掉一个小正方形，再把 L 形拼成长方形」；代数上就是展开后中间两项 −ab 与 +ab 抵消。用时先找相同项和相反项，结果是相同项的平方减相反项的平方，系数要整体平方。和完全平方公式的区别是：平方差只有两项，没有中间的一次项。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 和完全平方公式搞混，把 (a + b)(a − b) 写成 a² − 2ab + b²。平方差的结果只有两项，没有一次项。
  • 把 (a + b)(a + b) 也当成平方差，必须一加一减才符合公式。
  • 系数忘了平方，(2a + b)(2a − b) 写成 2a² − b²，正确是 4a² − b²。
  • 把「相反项」也平方成负号，b² 前面已经是减号，不要再添负号。
  • 顺序打乱时不调整就直接套，把 (y − 2x)(y + 2x) 的相反项认错。
