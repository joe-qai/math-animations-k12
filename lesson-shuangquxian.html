双曲线

到两定点距离差为 2a

双曲线是到两个定点距离之差的绝对值等于常数 2a 的点的轨迹，且 0 < 2a < 2c。它与椭圆最大的区别在关系式：双曲线是 c² = a² + b²，c 最大。渐近线决定图像的「开口方向」，离心率 e = c/a 一定大于 1。

知识精讲

概念 · 公式 · 例题
概念

双曲线的定义

平面内到两个定点 F₁、F₂ 的距离之差的绝对值等于常数 2a 的点的轨迹叫双曲线，要求 0 < 2a < 2c。

若去掉绝对值，只表示靠近一个焦点的一支。

当 2a = 2c 时，轨迹是两条射线；当 2a > 2c 时，轨迹不存在。

定义是处理焦点三角形、焦半径问题的第一工具。

||PF₁| − |PF₂|| = 2a

公式

标准方程

焦点在 x 轴：x²/a² − y²/b² = 1，渐近线 y = ±(b/a)x。

焦点在 y 轴：y²/a² − x²/b² = 1，渐近线 y = ±(a/b)x。

参数关系：c² = a² + b²，c 最大；这一点与椭圆相反。

判断焦点位置：看哪一项为正，焦点就在哪个轴。

c² = a² + b²

例题

例 1：读参数

双曲线 x²/9 − y²/16 = 1，求 a、b、c、离心率与渐近线。

a² = 9，b² = 16，所以 a = 3，b = 4。

c² = a² + b² = 25，c = 5，离心率 e = c/a = 5/3。

渐近线为 y = ±(b/a)x = ±(4/3)x。

e = 5/3，y = ±(4/3)x

公式

离心率与渐近线

离心率 e = c/a，范围是 e > 1。

e 越大，双曲线开口越开阔；e 越接近 1，开口越窄。

渐近线斜率与 a、b 直接相关，已知渐近线可以设出 a : b 的比例。

由 e 求渐近线：b² = c² − a² = a²(e² − 1)。

e = c/a > 1

例题

例 2：由渐近线设方程

已知双曲线的渐近线为 y = ±(1/2)x，且经过点 (2, 1)，求方程。

由渐近线斜率 b/a = 1/2，可设 a = 2k，b = k。

设方程为 x²/(4k²) − y²/k² = 1，代入 (2, 1)。

得 4/(4k²) − 1/k² = 1，即 1/k² − 1/k² = 0，说明点恰在渐近线上，需重新核对题目选取的点。

设 a : b，再代点

一句话记住

距离差的绝对值为 2a；c² = a² + b²；渐近线看正项轴，e > 1。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「焦点在 x 轴」改成「焦点在 y 轴」，正项换成 y²，渐近线斜率取倒数。
  • 把「求渐近线」改成「求离心率范围」，用 b/a 与 e 的关系列不等式。
  • 把「由渐近线设方程」改成「共渐近线系」，设 x²/a² − y²/b² = λ。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 定义中是距离之差的绝对值，漏掉绝对值只剩一支。
  • 双曲线是 c² = a² + b²，c 最大，不要套用椭圆的 a² = b² + c²。
  • 焦点在 x 轴时渐近线斜率是 b/a，不是 a/b。
  • 离心率一定大于 1，算出小于 1 说明参数关系用错了。
