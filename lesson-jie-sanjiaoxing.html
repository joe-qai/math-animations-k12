正弦定理与余弦定理

边比对边，角用余弦

解三角形就是已知一部分边和角，求其余部分。正弦定理把边与对角的正弦连起来，适合「两角一边」；余弦定理把三边与一个角连起来，适合「两边夹角」或「三边」。选对定理，计算量会差很多。

01

知识精讲

概念 · 公式 · 例题
公式

正弦定理

在三角形 ABC 中，a、b、c 分别是角 A、B、C 的对边，则 a/sinA = b/sinB = c/sinC = 2R，R 是外接圆半径。

常用变形：a = 2R sinA，sinA = a/(2R)，a : b : c = sinA : sinB : sinC。

适用情形：已知两角与一边，求其余边角；已知两边与其中一边的对角，判断解的个数。

第二种情形可能出现两解、一解或无解，画图看「高的位置」最直观。

a/sinA = b/sinB = c/sinC

公式

余弦定理

a² = b² + c² − 2bc cosA，另外两个角同理轮换。

推论：cosA = (b² + c² − a²) / (2bc)。

适用情形：已知两边及夹角，求第三边；已知三边，求角。

勾股定理是它的特例：当 A = 90° 时 cosA = 0，就回到 a² = b² + c²。

a² = b² + c² − 2bc cosA

例题

例 1：两角一边

在三角形 ABC 中，A = 30°，B = 45°，a = 2，求 b。

已知两角一边，用正弦定理：b/sinB = a/sinA。

b = a sinB / sinA = 2 × (√2/2) / (1/2) = 2√2。

求出 b 后，C = 180° − 30° − 45° = 105°，还可以继续求 c。

b = 2√2

例题

例 2：三边求角

三角形三边为 3、4、5，求最大角。

最大边 5 对最大角，设为 C。

cosC = (3² + 4² − 5²) / (2 × 3 × 4) = (9 + 16 − 25) / 24 = 0。

所以 C = 90°，这也说明 3、4、5 是直角三角形。

cosC = 0

概念

面积与选择策略

三角形面积 S = 1/2 ab sinC = 1/2 bc sinA = 1/2 ca sinB。

看到「两角一边」优先正弦定理；看到「两边夹角」「三边」优先余弦定理。

既要求边又要求角时，可以先余弦求边，再用正弦求角，注意用「大边对大角」检验。

涉及外接圆用正弦定理，涉及内切圆或面积常用 S = 1/2(a+b+c)r。

S = 1/2 ab sinC

一句话记住

两角一边用正弦，两边夹角或三边用余弦；求角后记得检验解与大小关系。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「已知两角一边」改成「已知两边及其中一边的对角」，先用正弦定理求角，再讨论解的个数。
  • 求面积时把「已知两边夹角」换成「已知三边」，先用余弦定理求一个角，再代入面积公式。
  • 判断三角形形状，把条件全部化成边或全部化成角，再用因式分解。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 正弦定理求角时可能有两解，求出 sinB 后要检查 B 是锐角还是钝角。
  • 余弦定理中减号容易写成加号，记成「平方和减二倍乘积乘余弦」。
  • 大边对大角：求出角后要用边长关系检验是否合理。
  • 面积公式里的夹角必须是两边的夹角，不能随便取一个角。
