一元一次不等式（组）

「最多」「至少」，用不等号说

知识精讲

概念 · 公式 · 例题
概念

不等式、解与解集

用不等号连接的式子叫不等式。使不等式成立的未知数的值，叫不等式的解；所有解合在一起，叫解集。

和解方程不同，不等式的解通常不是一个数，而是一段范围。比如带 50 元买 6 元一瓶的饮料，最多买 8 瓶，写成 x ≤ 8。

x ≤ 8

公式

不等式的基本性质

两边都加或减同一个数，不等号方向不变；两边都乘或除以同一个正数，方向也不变。

两边都乘或除以同一个负数，不等号必须变号。例：−2x > 4，两边除以 −2，得 x < −2，方向反了。

乘除负数 → 变号

概念

解不等式的五步与数轴

去分母、去括号、移项、合并同类项、系数化为一。前四步和解方程一样，区别在最后一步：系数是负数时要变号。

解集画在数轴上：大于向右，小于向左；有等号画实心点，没有等号画空心圈。

五步：去分母 → 系数化为一

概念

一元一次不等式组

几个一元一次不等式合在一起，叫一元一次不等式组；解集是它们解集的公共部分。

口诀：同大取大，同小取小，大小小大中间找，大大小小无解。比如 x > 2 且 x < 5，解集是 2 < x < 5。

同大取大，同小取小

例题

例题：解 2(x + 1) > 3x − 4

去括号：2x + 2 > 3x − 4；移项：2x − 3x > −4 − 2；合并：−x > −6。

系数化为一：两边除以 −1，不等号变向，得 x < 6。数轴上在 6 处画空心圈，向左画。

x < 6

例题

应用题：把「最多」翻译成不等号

「至少」对应 ≥，「最多」「不超过」对应 ≤，「超过」对应 >。找出这些词，题目就变成不等式。

例：一瓶 6 元、带 50 元，买 x 瓶要 6x 元，钱够就是 6x ≤ 50，解得 x ≤ 8.33…，取整数最多 8 瓶。

6x ≤ 50

一句话记住

用不等号连接的式子叫不等式；使不等式成立的未知数的值叫解，所有解合起来叫解集，通常是一段范围。三条基本性质：两边同加同减不变向；两边同乘除正数不变向；两边同乘除负数必须变号。解一元一次不等式按去分母、去括号、移项、合并同类项、系数化为一五步进行，最后一步遇负数要变号。解集画在数轴上：大于向右、小于向左，有等号实心、无等号空心。不等式组的解集是公共部分，口诀是「同大取大，同小取小，大小小大中间找，大大小小无解」。应用题把「至少」「最多」「不超过」翻译成不等号，再求解并检验实际意义。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 乘除负数忘记变号：这是最常见、也最致命的一处错误。
  • 实心点与空心点画错：有等号才取得到，画实心。
  • 解集只写一个数：不等式组的解集是一段范围或「无解」。
  • 移项忘记变号：移项要改变符号，和解方程一样。
  • 应用题不检验：解出的范围要符合实际，个数取整数。
