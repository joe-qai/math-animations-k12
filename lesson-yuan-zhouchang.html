圆的周长

周长总是直径的 3 倍多，C = πd

自行车轮子转一圈能走多远？先得量出车轮的周长。这节课先用绕绳法和滚动法把圆周「拉直」量一量，再比较几个大小不同的圆，发现周长总是直径的 3 倍多一点，从而引出圆周率 π 和公式 C = πd、C = 2πr，最后用车轮滚动求路程收尾。

知识精讲

概念 · 公式 · 例题
概念

周长怎么量

围成圆那一圈的长度，就是圆的周长。

绕绳法：用绳子贴着圆边绕一圈，再拉直了量。滚动法：在圆上做个记号，从记号处滚一周，量出滚了多远。两个办法都能量出周长。

公式

圆周率与周长公式

量几个大小不同的圆会发现：周长 ÷ 直径总是 3.14 左右，也就是直径的 3 倍多一点。这个固定的数叫圆周率，用 π 表示，π ≈ 3.14，它是无限不循环小数。

所以圆的周长 = 圆周率 × 直径，即 C = πd。直径是半径的 2 倍，所以也可以写成 C = 2πr。

C = πd 或 C = 2πr

例题

车轮转一圈走多远

车轮直径 50 厘米：C = 3.14 × 50 = 157（厘米），转一圈走 157 厘米。

转 10 圈就是 157 × 10 = 1570 厘米 = 15.7 米。转几圈就乘几。

概念

半圆的周长

半圆的周长不是半个圆周长。它由一段弧和一条直径围成。

所以半圆周长 = πd ÷ 2 + d，也就是「弧 + 直径」，别漏了那条直的直径。

一句话记住

围成圆那一圈的长度叫周长。用绕绳法或滚动法量一量会发现：周长总是直径的 3 倍多一点，这个固定的数就是圆周率 π ≈ 3.14。所以 C = πd，也可以写成 C = 2πr。已知直径用 C = πd，已知半径用 C = 2πr；半圆的周长等于弧加直径，别忘了那条直径。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 把直径当半径代进去：看到 r 要先乘 2 再用，或用 C = 2πr。
  • 算半圆周长只算弧：半圆还要加上那条直径。
  • 直径和半径单位不统一：先把单位化成一样再算。
  • 把 π 当成 3 计算：题目一般要求取 3.14。
  • 结果单位写成平方厘米：周长是长度，用厘米、米，不带平方。
