二次函数图像与根的分布

先算 Δ、再看对称轴、最后看端点

初中看二次函数，主要看开口、对称轴和顶点，会画图、会求最值就够了。到了高中，题目问的常常不是图长什么样，而是方程的两根落在哪里：都在某个数的右边，分布在某个数的两边，或者落在某个区间里——这就是根的分布。这一节把工具理清：图像三要素（开口由 a 的正负决定、对称轴 x = −b/(2a)、顶点把对称轴代回函数）；判别式 Δ = b² − 4ac 决定交点个数；三个模型——两根都大于 k 要同时满足 Δ > 0、对称轴在 k 右边、f(k) > 0；k 夹在两根之间只需 f(k) < 0；根落在区间内要 Δ ≥ 0、对称轴在区间内、两端点函数值都为正，只有一根在区间内则用 f(m)·f(n) < 0。最后三个提醒：条件靠画图验证、端点能否取到单独算、别忘判别式。

知识精讲

概念 · 公式 · 例题
概念

图像三要素

开口方向由二次项系数 a 的正负决定：a > 0 向上，a < 0 向下。对称轴是 x = −b/(2a)，把对称轴代回函数就得到顶点坐标。这三样定了，抛物线的形状和位置就定了大半。

抛物线与 x 轴的交点横坐标，就是对应方程的两个根。所以讨论根的分布，本质上是在讨论这条抛物线与横轴交在哪里。

x = −b/(2a)

公式

判别式决定交点个数

Δ = b² − 4ac。Δ > 0 时有两个交点，Δ = 0 时有一个交点（重根），Δ < 0 时没有交点。

讨论根的位置之前先算 Δ，它决定了根「有没有」；后面的条件才决定根「在哪」。没有交点时，谈位置是没有意义的。

Δ = b² − 4ac

公式

两根都大于 k

当 a > 0 时，两根都大于 k 需要同时满足三个条件：Δ > 0、对称轴 −b/(2a) > k、f(k) > 0。

画图就能看明白：对称轴要在 k 的右边，图像在 k 处还得在横轴上方，再加上确实有两个交点。三条缺一不可。

Δ > 0，轴 > k，f(k) > 0

公式

k 夹在两根之间

如果 k 夹在两根之间，只需要一个条件：f(k) < 0。因为图像在 k 处落到横轴下方，必然一个交点在左、一个在右。

这种情况下不用再看 Δ：f(k) < 0 本身就保证了有两个交点。反过来，若要求两根在 k 的两侧，写 f(k) < 0 就够了。

f(k) < 0 ⇔ 一根在左、一根在右

公式

根落在区间内

两根都在区间 (m, n) 内，需要：Δ ≥ 0、对称轴在 m 与 n 之间、f(m) > 0 且 f(n) > 0。

如果只有一根在区间内，用 f(m)·f(n) < 0 判断；端点处要单独检验是否能取到，因为「大于」和「大于等于」差一个点。

Δ ≥ 0，m < 轴 < n，f(m)、f(n) > 0

例题

例：端点要单独算

判断 f(x) = x² − 4x + 3 的两根是否都在区间 (0.5, 3.5) 内：Δ = 4 > 0，对称轴 x = 2 在区间内，f(0.5) = 1.25 > 0，f(3.5) = 1.25 > 0，四个条件都满足，两根 1 与 3 确实都在区间内。

如果把区间改成 (1, 3)，两个端点恰好是根，此时「在区间内」不成立，但「在闭区间内」成立。这种差别必须单独说明。

端点取不取，单独检验

例题

例 2：两根都大于 0 的三个条件

方程 x² − (m + 1)x + 1 = 0 的两根都大于 0，求 m 的取值范围。

两根都大于 0，要同时满足三件事：Δ ≥ 0、两根之和大于 0、两根之积大于 0。

Δ = (m + 1)² − 4 ≥ 0，得 m ≥ 1 或 m ≤ −3；和 m + 1 > 0，得 m > −1；积 1 > 0 恒成立。

取交集得 m ≥ 1。只算 Δ 会多出 m ≤ −3，那部分两根之和为负，不符合「都大于 0」。

m ≥ 1

一句话记住

根的分布就是把「根在哪」翻译成图像上的条件。先把图像三要素摆出来：开口看 a 的正负，对称轴 x = −b/(2a)，顶点把对称轴代回函数。再看判别式 Δ = b² − 4ac 决定有没有交点。三个模型要记牢：两根都大于 k，要 Δ > 0、对称轴在 k 右边、f(k) > 0 三条同时成立；k 夹在两根之间，只需 f(k) < 0，一句话搞定；两根都在区间 (m, n) 内，要 Δ ≥ 0、对称轴在区间内、两端点函数值都为正，只有一根在区间内则用 f(m)·f(n) < 0。最后三个提醒：条件靠画图验证、端点能否取到单独算、别忘判别式。

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 题目改问「两根都小于 k」，把对称轴条件改成 −b/(2a) < k，其余条件不变。
  • 改问「一根大于 k、一根小于 k」，直接用 f(k) < 0，不必再算 Δ。
  • 改问「区间 (m, n) 内恰有一根」，用 f(m)·f(n) < 0，再单独检查端点。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 只算 Δ 就下结论，忘了根的位置还要看对称轴和端点。
  • 两根都大于 k 时漏掉 f(k) > 0，画出图才发现不对。
  • k 夹在两根之间还去检查 Δ，多写一步反而容易错。
  • 区间根忘记检验端点，把开区间当成闭区间。
  • 背结论不画图，a < 0 时条件符号写反。
