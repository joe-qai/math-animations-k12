轴对称与等腰三角形

对折里的两条定理

把一张纸对折，剪一刀再展开，两边完全一样——这就是轴对称。它的核心性质只有一句：对称轴垂直平分对应点的连线。等腰三角形正好是轴对称图形，于是有了「等边对等角」和「三线合一」这两条最常用的定理。这一节从对折讲到三线合一，再讲等角的反向判定和等边三角形。

知识精讲

概念 · 公式 · 例题
概念

轴对称图形

沿一条直线对折，直线两旁的部分能够完全重合，这样的图形叫轴对称图形，这条直线叫对称轴。

对称轴是一条直线，不是线段。两个图形也可以关于一条直线对称，这时说这两个图形成轴对称。

对折 → 两边完全重合

公式

轴对称的性质

对称轴垂直平分连接两个对应点的线段。也就是说，对应点的连线被对称轴垂直平分。

由此得到：对应线段相等，对应角相等。反过来，线段的垂直平分线上的任意一点，到线段两端的距离相等。

对称轴 ⊥ 对应点连线，且平分它

公式

画法与坐标规律

画轴对称图形三步：找关键点；从每个关键点向对称轴作垂线并延长等长，得到对称点；把对称点顺次连起来。

在坐标系里：点 (x, y) 关于 x 轴对称得 (x, −y)；关于 y 轴对称得 (−x, y)。横竖一翻，只变一个符号。

(x, y) → (x, −y)　(−x, y)

概念

等腰三角形：等边对等角

两条边相等的三角形叫等腰三角形。相等的两条边叫腰，第三条边叫底边；两腰的夹角叫顶角，腰与底边的夹角叫底角。

性质：等边对等角。AB = AC，则 ∠B = ∠C。注意相等的边所对的角才相等。

AB = AC → ∠B = ∠C

公式

三线合一

等腰三角形顶角的平分线、底边上的中线、底边上的高互相重合，简称三线合一。

边界要记清：三线合一指的是顶角平分线与底边上的中线、高。底角的平分线、腰上的高都不适用。

顶角平分线 = 底边中线 = 底边上的高

例题

例题：一个角 40°

等腰三角形有一个角是 40°，求另外两个角，必须分两种情形。

若 40° 是顶角：底角 = (180° − 40°) ÷ 2 = 70°，另外两个角是 70°、70°。若 40° 是底角：另一个底角也是 40°，顶角 = 180° − 80° = 100°，另外两个角是 40°、100°。

70°、70° 或 40°、100°

一句话记住

沿一条直线对折、两边能完全重合的图形叫轴对称图形，这条直线是对称轴（是直线，不是线段）。轴对称的性质：对称轴垂直平分对应点的连线，对应线段相等、对应角相等；反过来，垂直平分线上的点到两端距离相等。画对称图形三步：找关键点、作垂线取等长、顺次连线；坐标里 (x, y) 关于 x 轴对称是 (x, −y)，关于 y 轴对称是 (−x, y)。等腰三角形等边对等角；顶角平分线、底边中线、底边上的高三线合一，但只对顶角和底边成立。反过来等角对等边；三个角都相等，或有一个角是 60° 的等腰三角形，都是等边三角形。遇到「已知一个角求另外两个角」要分顶角、底角两种情形讨论。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 把对称轴说成线段：对称轴是一条直线，可以向两端无限延伸。
  • 三线合一用错对象：只有顶角平分线、底边上的中线、底边上的高才重合，底角平分线和腰上的高不行。
  • 已知一个角求另外两个角时不分类讨论，只写一组答案，漏掉另一个解。
  • 等边对等角时把边和角配错：相等的边所对的角才相等。
  • 把「等角对等边」和「等边对等角」的条件与结论弄反。
