指数与指数函数

同底相乘，指数相加

一个细胞每次分裂成两个，一小时分裂一次，那么 x 小时后就是 2 的 x 次方个。这类「每份都乘同一个倍数」的变化，就是指数函数的来源。指数运算有三条律：同底相乘指数相加、幂的乘方指数相乘、积的乘方分别乘方。指数函数 y = aˣ 恒过 (0, 1)，底数大于 1 时越涨越快，底数在 0 到 1 之间时越降越慢。

概念 · 公式 · 例题
概念

根式与分数指数幂

如果 xⁿ = a，就把 x 叫做 a 的 n 次方根；n 为偶数时要求 a ≥ 0。

规定 a^(1/n) = ⁿ√a，a^(m/n) = ⁿ√(aᵐ)，其中 a > 0，m、n 为正整数。

负指数表示倒数：a^(−n) = 1 / aⁿ；零指数：a⁰ = 1（a ≠ 0）。

有了分数指数幂，根式和幂就能统一成一种写法，运算更方便。

a^(m/n) = ⁿ√(aᵐ)

公式

指数运算三条律

同底数相乘，底数不变、指数相加：aᵐ · aⁿ = aᵐ⁺ⁿ。

幂的乘方，底数不变、指数相乘：(aᵐ)ⁿ = aᵐⁿ。

积的乘方，等于分别乘方再相乘：(ab)ⁿ = aⁿbⁿ。

三条律都要求 a > 0、b > 0，这样分数指数幂才有意义。

aᵐ · aⁿ = aᵐ⁺ⁿ

概念

指数函数的定义

形如 y = aˣ（a > 0，且 a ≠ 1）的函数叫指数函数。

定义域是全体实数 R，值域是 (0, +∞)，图像永远在 x 轴上方。

无论底数是多少，x = 0 时 y = 1，所以图像一定经过点 (0, 1)。

x 轴是它的水平渐近线，曲线无限接近但永远不穿过 x 轴。

y = aˣ（a > 0，a ≠ 1）

概念

底数决定增减

当 a > 1 时，y = aˣ 在 R 上单调递增，x 越大涨得越快。

当 0 < a < 1 时，y = aˣ 在 R 上单调递减，x 越大越贴近 x 轴。

底数越大，a > 1 时图像越陡；0 < a < 1 时图像越平缓。

y = aˣ 与 y = (1/a)ˣ 的图像关于 y 轴对称。

a > 1 增，0 < a < 1 减

例题

比较大小与平移

同底不同指数：底数大于 1 时指数大的值大，底数小于 1 时反过来。

不同底也不同指数：先找中间量 1，或者化成同底再比。

y = aˣ 向右平移 h 个单位得到 y = a^(x−h)，向左平移就写成 x + h。

记住口诀「左加右减」，平移只改变位置，不改变形状和渐近线。

左加右减

例题

例 2：同底之后让指数相等

解方程 2^(x² − 1) = 4。

先把右边化成同底：4 = 2²，方程变成 2^(x² − 1) = 2²。

底数相同且不等于 1，指数必须相等：x² − 1 = 2。

解得 x² = 3，所以 x = ±√3。指数方程最后别忘记两个根。

x = ±√3

一句话记住

指数运算的三条律是同底相乘指数相加、幂的乘方指数相乘、积的乘方分别乘方，前提是底数为正。指数函数 y = aˣ（a > 0，a ≠ 1）定义域为 R、值域为 (0, +∞)，恒过 (0, 1)，以 x 轴为渐近线；a > 1 时递增，0 < a < 1 时递减。比较大小先看底数是否相同，再看是否落在同一个单调区间。

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 比较两个幂的大小，先化成同底，再看指数函数是增还是减。
  • 解指数方程，先把两边化成同底，再让指数相等。
  • 含根式的式子，先写成分数指数幂，再用三条运算律化简。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 忽略底数限制：a 必须大于 0 且不等于 1，否则不是指数函数。
  • 把 aᵐ · aⁿ 算成 aᵐⁿ：同底相乘是指数相加，不是相乘。
  • 以为指数函数过原点：它过的是 (0, 1)，不是 (0, 0)。
  • 比较大小不看底数：底数小于 1 时，指数越大值反而越小。
