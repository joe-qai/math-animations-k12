回归分析与独立性检验

回归看相关，检验看 χ²

两个变量之间如果有线性相关，可以用回归直线做预测；回归直线一定经过样本中心点。独立性检验则用 χ² 统计量判断两个分类变量是否有关：χ² 越大，越有把握说它们有关，但要与临界值比较后才能下结论。

01

知识精讲

概念 · 公式 · 例题
概念

相关关系

变量之间存在不确定的依赖关系，叫相关关系；函数关系是确定的依赖关系。

相关关系不一定是因果关系，可能只是同时变化。

散点图可以直观判断正相关、负相关或不相关。

相关系数 r 的范围是 −1 到 1，|r| 越接近 1，线性相关越强。

−1 ≤ r ≤ 1

公式

回归直线

回归直线 ŷ = bx + a 一定经过样本中心点 (x̄, ȳ)。

斜率 b = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²。

截距 a = ȳ − b x̄。

回归直线用于预测，但不宜外推到样本范围之外太远。

ŷ = bx + a 过 (x̄, ȳ)

例题

例 1：用回归直线预测

已知回归直线 ŷ = 2x + 1，样本中心为 (3, 7)，验证直线是否经过中心。

代入 x = 3，ŷ = 2×3 + 1 = 7，正好等于 ȳ。

所以回归直线经过样本中心点。

若 x = 5，预测 ŷ = 11；但要注意 5 是否在样本范围内。

ŷ(3) = 7

公式

独立性检验

列 2×2 列联表，记四个格子的频数为 a、b、c、d，总数 n = a+b+c+d。

χ² = n(ad − bc)² / [(a+b)(c+d)(a+c)(b+d)]。

χ² 越大，说明两个分类变量有关的证据越强。

要与临界值比较：超过 3.841 有 95% 把握，超过 6.635 有 99% 把握。

χ² = n(ad−bc)²/[(a+b)(c+d)(a+c)(b+d)]

例题

例 2：下结论

某次独立性检验算得 χ² = 5.2。

查临界值：3.841 对应 95% 把握，6.635 对应 99% 把握。

因为 3.841 < 5.2 < 6.635，所以有 95% 把握认为两个变量有关，但没有 99% 的把握。

结论要写成「有 95% 的把握认为有关」，不能写成「一定有关」。

3.841 < 5.2 < 6.635

一句话记住

相关看 r，回归过中心；χ² 越大证据越强，结论要带把握程度。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「预测」改成「求残差」，用实际值减预测值。
  • 把「χ² 比较」改成「补全列联表」，先由总数与边际和反推格子。
  • 把「线性相关」改成「非线性相关」，散点图呈曲线时回归直线不再合适。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 相关不等于因果，不能由回归直线直接下因果结论。
  • 回归直线必过样本中心，求参数时常用这个性质。
  • χ² 越大越有把握有关，不是「χ² 越大相关性越强」。
  • 结论必须带把握程度，不能写成「一定有关」或「一定无关」。
