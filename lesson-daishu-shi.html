02

知识精讲

概念 · 公式 · 例题
概念

代数式与书写规范

用运算符号把数和字母连接起来的式子叫代数式。单独一个数、单独一个字母，也是代数式。

书写规范：数字写在字母前面；乘号可以省略；除法写成分数线；带分数化成假分数。

概念

单项式与多项式

数与字母的积叫单项式，其中的数字因数叫系数，所有字母的指数之和叫次数。3a²b 的系数是 3，次数是 2 + 1 = 3。

几个单项式的和叫多项式，每个单项式叫一项，次数最高的项的次数就是多项式的次数。2x² - 3x + 1 是二次三项式。

公式

合并同类项

所含字母相同，并且相同字母的指数也相同，这样的项叫同类项。合并时系数相加减，字母和指数都不变。

3x + 5x = 8x；2a²b - 5a²b = -3a²b。注意 3x 与 3x² 指数不同，不是同类项。

系数相加，字母不变

公式

去括号法则

括号前是加号，去掉括号后各项都不变号；括号前是减号，去掉括号后各项都要变号。

a + (b - c) = a + b - c；a - (b - c) = a - b + c。只变第一项是常见错误。

减号后面全变号

一句话记住

代数式就是用运算符号把数和字母连起来的式子。单项式的系数是数字因数，次数是所有字母指数之和；几个单项式的和是多项式，最高次项的次数就是多项式的次数。同类项必须字母相同、相同字母的指数也相同，合并时只把系数相加减。去括号时，括号前是减号，括号里每一项都要变号。化简的最后一步，永远是合并同类项。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 书写代数式时把数字写在字母后面，或把乘号写成「×」。
  • 求单项式次数时只看某一个字母的指数，没有把字母指数相加。
  • 把 3x 与 3x² 当成同类项合并。
  • 去括号时括号前是减号，只变了第一项。
  • 系数乘括号时漏乘括号里的某一项。
