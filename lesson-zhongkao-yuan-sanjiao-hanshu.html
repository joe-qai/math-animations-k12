圆与三角函数（中考专题）

证切线、算弧长、解直角三角形：套路最固定的 15 分

圆几乎年年一道大题，锐角三角函数固定出现在测高与坡度应用题里，两部分加起来约 15 分，而且套路非常固定。这一节讲四块：圆的基本性质——垂径定理、同弧所对的圆周角是圆心角的一半、直径所对的圆周角是 90°、圆内接四边形对角互补；切线的判定与性质——有公共点就连半径证垂直，没有公共点就作垂线证 d = r，性质是切线垂直于过切点的半径，圆外一点引两条切线长相等；圆中的计算——弧长 nπr/180、扇形面积 nπr²/360 也等于 ½ℓr，圆锥侧面展开是扇形、弧长等于底面周长、半径等于母线；锐角三角函数与解直角三角形——三个比的定义、特殊角的值，已知两边用勾股加三角函数，已知一边一角直接用三角函数。最后是应用题的三个关键词：仰角俯角从水平线量起，坡度是垂直高度比水平宽度、等于坡角的正切，方位角从正北或正南量起。

知识精讲

概念 · 公式 · 例题
概念

圆的基本性质：四条跳板

垂径定理：垂直于弦的直径平分这条弦，并且平分弦所对的两条弧。同弧所对的圆周角等于它所对圆心角的一半。

直径所对的圆周角是 90°；圆内接四边形的对角互补。这四条几乎覆盖了圆的选择填空与证明第一问。

同弧圆周角 = ½ 圆心角

概念

切线：判定与性质

判定分两种情形：直线与圆有公共点时，连半径，证半径垂直于直线；没有明确公共点时，过圆心作垂线，证垂线段等于半径。

性质：切线垂直于过切点的半径。从圆外一点引圆的两条切线，切线长相等，这一点与圆心的连线平分两条切线的夹角。

切线 ⊥ 过切点的半径

公式

圆中的计算

弧长 ℓ = nπr/180；扇形面积 S = nπr²/360，也可以写成 ½ℓr。

圆锥侧面展开是扇形：扇形的弧长等于底面圆的周长，扇形的半径等于圆锥的母线长。把这三个量对应清楚，圆锥题就不会错。

ℓ = nπr/180，S = ½ℓr

概念

锐角三角函数：三个比

在直角三角形中，sin A = 对边/斜边，cos A = 邻边/斜边，tan A = 对边/邻边。三个比都只与角的大小有关，与三角形的大小无关。

特殊角要背熟：sin30° = ½，sin45° = √2/2，sin60° = √3/2，cos 与 sin 互换，tan30° = √3/3，tan45° = 1，tan60° = √3。

tan A = 对边 / 邻边

例题

例：解直角三角形

已知两边：先用勾股定理求第三边，再用三角函数求角；已知一边一角：直接用三角函数求其余边。

遇到斜三角形，作高把它拆成两个直角三角形，这是所有测量题的通用第一步。

已知两边 → 勾股；已知一边一角 → 三角比

例题

例：坡度不是坡角

坡度 i 是竖直高度与水平宽度的比，等于坡角的正切值；坡角是坡面与水平面的夹角，是角度。

若坡度 i = 1 : 2，则 tan 坡角 = 1/2，坡角约为 26.6°，而不是 30°。以 1 : 2 当角度写，是最常见的失分点。

i = 竖直高 / 水平宽 = tan 坡角

一句话记住

圆的复习抓两条线。性质线：垂径定理、同弧圆周角是圆心角的一半、直径所对圆周角 90°、圆内接四边形对角互补，这四条是证明的跳板。切线线：判定看有没有公共点，有就连半径证垂直，没有就作垂线证 d = r；性质是切线垂直于过切点的半径；圆外一点的两条切线长相等，连线平分夹角。计算线：弧长 nπr/180，扇形面积 nπr²/360 或 ½ℓr，圆锥侧面展开的扇形弧长等于底面周长、半径等于母线。三角函数线：三个比的定义要能随手写出，特殊角的值要背熟；解直角三角形时，已知两边用勾股，已知一边一角用三角比；应用题先把仰角、俯角、坡度、方位角翻译成直角三角形里的边角关系，再动笔算。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 圆周角与圆心角对应的不是同一条弧，倍数关系用反。
  • 证明切线时不连半径，直接说「切线垂直于直线」，缺少依据。
  • 把坡度当成坡角，或者把仰角、俯角从竖直方向量起。
  • 特殊角的三角函数值记混，尤其是 tan30° 与 tan60°。
  • 圆锥题里把底面半径当成展开扇形的半径，忘了扇形半径是母线。
