函数的零点

方程 f(x) = 0 的根

函数图像穿过 x 轴的地方，横坐标就是零点，它其实是一个数，不是坐标点。零点就是方程 f(x) = 0 的实根，也是两个图像交点问题。判断零点存在用零点存在定理：图像连续不断、两端函数值一正一负，中间至少有一个零点。定理只说「有」，不保证「只有一个」。

知识精讲

概念 · 公式 · 例题
概念

什么是零点

使 f(x) = 0 成立的实数 x，叫函数 y = f(x) 的零点。

图像上，零点就是曲线与 x 轴交点的横坐标。

零点是一个数，不是点，所以不能写成 (3, 0)。

求零点就是解方程，方程的实根有几个，零点就有几个。

f(x) = 0

公式

零点存在定理

如果函数 f(x) 在闭区间 [a, b] 上的图像连续不断，并且 f(a) · f(b) < 0，那么 f(x) 在 (a, b) 内至少有一个零点。

「连续」是说图像中间不能断，「异号」是说两端一个在 x 轴上方、一个在下方。

两个条件缺一不可：不连续时可能断开，同号时可能整段都在一侧。

定理只保证存在，不保证唯一；要证明唯一，还要加上单调性。

f(a) · f(b) < 0

概念

零点个数怎么看

把 f(x) = 0 变形为 g(x) = h(x)，方程的解就是两个图像交点的横坐标。

交点有几个，零点就有几个，这比硬解方程直观。

如果 f 在区间上单调，并且两端异号，那么零点恰好只有一个。

遇到含参数的零点个数问题，通常是让图像上下平移，看交点数怎么变。

f(x) = 0 ⇔ g(x) = h(x)

例题

二分法

已知 f(a) · f(b) < 0，取中点 c = (a + b) / 2，算 f(c)。

若 f(c) = 0，c 就是零点；若 f(a) · f(c) < 0，零点在 (a, c)；否则在 (c, b)。

每次把范围缩小一半，重复到区间长度小于要求的精度。

二分法只适用于连续且端点异号的情况，求的是近似值。

c = (a + b) / 2

概念

零点与不等式

函数的零点把定义域分成几段，在每一段里函数值的符号通常不变。

所以解 f(x) > 0 或 f(x) < 0，先求零点，再判断各段的符号。

这就是「穿根法」的依据：零点处穿过去，符号就翻一次。

重根处不穿过去，符号不变，这是最容易出错的地方。

先求零点，再定符号

例题

例 2：存在定理加单调性，才能数个数

判断 f(x) = x³ + x − 1 在 (0, 1) 内零点的个数。

先看存在性：f(0) = −1 < 0，f(1) = 1 > 0，图像连续，所以 (0, 1) 内至少有一个零点。

再看唯一性：x³ 与 x 在 R 上都递增，所以 f(x) 在 R 上单调递增，图像最多穿过 x 轴一次。

存在且最多一个，所以 (0, 1) 内恰有一个零点。存在定理只管「有」，个数要靠单调性补。

f(0)f(1) < 0 且 f(x) 单调递增

一句话记住

函数的零点就是方程 f(x) = 0 的实根，也是图像与 x 轴交点的横坐标，它是一个数。零点存在定理：f 在 [a, b] 上连续且 f(a) · f(b) < 0，则 (a, b) 内至少有一个零点；加上单调性才能保证唯一。求零点个数可以转化为两个图像的交点个数，近似解用二分法，解不等式则先求零点再判断各段符号。

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 判断零点所在区间，算区间两端函数值，异号就说明至少有一个零点。
  • 判断零点个数，先看单调性，再结合端点函数值。
  • 把 f(x) = g(x) 的根改写成 h(x) = f(x) − g(x) 的零点，再套存在定理。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 零点不是点：答案写 x = 3，不能写成 (3, 0)。
  • 定理只保证存在，不能直接说「有且只有一个」。
  • 图像不连续时定理不成立，用之前先确认连续性。
  • 两端同号也可能有零点，比如两个零点都在区间内。
