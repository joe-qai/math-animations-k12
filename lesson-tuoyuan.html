椭圆

到两定点距离和为 2a

椭圆是到两个定点距离之和等于常数 2a 的点的轨迹，且 2a 必须大于两定点间距离 2c。标准方程里 a² = b² + c²，离心率 e = c/a 描述「扁」的程度。焦点在哪个轴，看分母谁大。

知识精讲

概念 · 公式 · 例题
概念

椭圆的定义

平面内到两个定点 F₁、F₂ 的距离之和等于常数 2a 的点的轨迹叫椭圆，要求 2a > |F₁F₂| = 2c。

两个定点叫焦点，两焦点间距离的一半叫半焦距 c。

当 2a = 2c 时，轨迹是线段 F₁F₂；当 2a < 2c 时，轨迹不存在。

定义是做题的第一工具：看到「到两焦点距离」就回到 |PF₁| + |PF₂| = 2a。

|PF₁| + |PF₂| = 2a

公式

标准方程

焦点在 x 轴：x²/a² + y²/b² = 1，其中 a > b > 0。

焦点在 y 轴：y²/a² + x²/b² = 1，其中 a > b > 0。

三者关系：a² = b² + c²，a 最大，c 最小。

判断焦点位置：看 x²、y² 下面的分母，哪个大，焦点就在哪个轴。

a² = b² + c²

例题

例 1：由方程读参数

椭圆 x²/25 + y²/9 = 1，求 a、b、c 与焦点坐标。

因为 25 > 9，所以焦点在 x 轴，a² = 25，b² = 9。

c² = a² − b² = 16，c = 4。

焦点为 (−4, 0) 和 (4, 0)，离心率 e = c/a = 4/5。

a=5，b=3，c=4

公式

离心率

离心率 e = c/a，范围是 0 < e < 1。

e 越接近 1，椭圆越扁；e 越接近 0，椭圆越接近圆。

由 e 与 a、b、c 的关系，可以互相转化：c = ae，b² = a²(1 − e²)。

求离心率常见思路：找一个关于 a、c 的齐次方程，再解出 c/a。

e = c/a

例题

例 2：焦点三角形

椭圆 x²/25 + y²/9 = 1 上一点 P 满足 ∠F₁PF₂ = 90°，求三角形面积。

由定义 |PF₁| + |PF₂| = 2a = 10，且 |F₁F₂| = 2c = 8。

直角三角形中 |PF₁|² + |PF₂|² = 64。

联立可得 2|PF₁||PF₂| = 100 − 64 = 36，面积 = 1/2 |PF₁||PF₂| = 9。

S = 9

一句话记住

距离和为 2a，a² = b² + c²；分母大的轴是焦点轴，e = c/a 越接近 1 越扁。

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「焦点在 x 轴」改成「焦点在 y 轴」，标准方程中 a² 换到 y² 下面。
  • 把「求离心率」改成「求方程」，先设标准形式，再代入 a、b、c 关系。
  • 把「焦点三角形面积」改成「周长」，周长等于 2a + 2c。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 定义中的常数是 2a，不是 a；距离之和等于 2a。
  • 必须满足 2a > 2c，否则轨迹不是椭圆。
  • a² = b² + c² 中 a 最大，不要与双曲线的 c² = a² + b² 混淆。
  • 焦点在哪个轴看分母大小，不是看 x、y 谁在前面。
