单调性、奇偶性与周期性

奇原点，偶 y 轴

看图像先看三件事：从左往右是在上升还是下降，这就是单调性；关于原点还是关于 y 轴对称，这就是奇偶性；隔一段距离图形又重复，这就是周期性。单调性必须说清在哪个区间，奇偶性必须先看定义域是否关于原点对称，周期性则要找到那个最小的重复间隔。

知识精讲

概念 · 公式 · 例题
概念

单调性

在区间 D 上，任取 x₁ < x₂，如果都有 f(x₁) < f(x₂)，就说 f 在 D 上单调递增。

反过来，如果都有 f(x₁) > f(x₂)，就说 f 在 D 上单调递减。

图像上，递增就是从左往右上升，递减就是从右往左上升。

单调性一定是对某个区间说的，不能笼统说「在整个定义域上单调」。

x₁ < x₂ ⇒ f(x₁) < f(x₂)

公式

判断单调性的方法

定义法：设 x₁ < x₂，作差 f(x₁) − f(x₂)，判断符号。

图像法：看曲线在区间上是上升还是下降。

复合函数：内外两层同增或同减则整体递增，一增一减则整体递减，即同增异减。

常见函数直接记：一次函数看斜率，二次函数看对称轴，反比例函数分两支看。

同增异减

概念

奇偶性

先要求定义域关于原点对称，否则既不是奇函数也不是偶函数。

若对定义域内任意 x，都有 f(−x) = −f(x)，就是奇函数，图像关于原点对称。

若都有 f(−x) = f(x)，就是偶函数，图像关于 y 轴对称。

奇函数若在 x = 0 处有定义，则一定有 f(0) = 0。

f(−x) = ±f(x)

例题

判断奇偶性的三步

第一步：求定义域，看它是否关于原点对称，不对称就直接下结论。

第二步：计算 f(−x)，把 −x 代进去化简。

第三步：与 f(x) 比较，等于 f(x) 是偶函数，等于 −f(x) 是奇函数，都不是就非奇非偶。

以 f(x) = x³ 为例：定义域是 R，f(−x) = −x³ = −f(x)，所以是奇函数。

先定义域，再算 f(−x)

概念

周期性

若存在非零常数 T，使得对定义域内任意 x 都有 f(x + T) = f(x)，就说 f 是周期函数，T 是它的一个周期。

所有周期中最小的正数叫最小正周期，平时说的周期一般指它。

周期函数图像每隔 T 就重复一次，只要研究一个周期内的图像就够了。

常函数是周期函数，但没有最小正周期，所以「有周期」不等于「有最小正周期」。

f(x + T) = f(x)

例题

例 2：判断 f(x) = x³ + x 的奇偶性

先看定义域：R 关于原点对称，具备讨论奇偶性的前提。

再算 f(−x) = (−x)³ + (−x) = −x³ − x。

提出负号：f(−x) = −(x³ + x) = −f(x)。

所以 f(x) 是奇函数，图像关于原点对称。

f(−x) = −f(x)

一句话记住

单调性看区间：任取 x₁ < x₂，函数值同向变化就是增，反向就是减，证明用作差法。奇偶性先看定义域是否关于原点对称，再看 f(−x) 与 f(x) 的关系：等于 −f(x) 是奇函数、图像关于原点，等于 f(x) 是偶函数、图像关于 y 轴。周期性是存在非零常数 T 使 f(x + T) = f(x)，注意并非所有周期函数都有最小正周期。

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 判断奇偶性前先看定义域是否关于原点对称，不对称就直接下结论。
  • 证明单调性用定义：取值、作差、变形、定号，四步写全。
  • 周期函数求大自变量的函数值，先用周期把自变量缩小到一个周期内。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 单调性不写区间：必须说明在哪个区间上递增或递减。
  • 忘记先看定义域：定义域不关于原点对称，直接就是非奇非偶。
  • 算 f(−x) 时只改一处符号，要把所有 x 都换成 −x 再化简。
  • 以为周期函数一定有最小正周期，常函数就是反例。
