圆中的计算

弧长、扇形面积与圆锥

跑道弯道是一段弧，折扇扇面是一个扇形，它们的大小都只跟两件事有关：圆心角 n 和半径 r。圆心角占整个圆 360° 的几分之几，弧长和面积就占整个圆的几分之几。于是得到弧长 l = nπr/180，扇形面积 S = nπr²/360，还有一个更好用的形式 S = ½ l r。后半节把圆锥的侧面剪开铺平：得到一个扇形，扇形的半径是母线 l，扇形的弧长正好是底面周长 2πr，由此推出侧面积 πrl、全面积 πrl + πr²，再用一道「半径 6、圆心角 120°」的例题把公式走一遍。

知识精讲

概念 · 公式 · 例题
概念

弧长与扇形的共同点

弧长和扇形面积都只跟两个量有关：圆心角 n 和半径 r。圆心角占整个圆 360° 的几分之几，弧长和面积就占整个圆的几分之几。

所以先把「占几分之几」想清楚，再乘整个圆的周长或面积，公式就不容易记混。

占几分之几 = n / 360

公式

弧长公式

圆的周长是 2πr，圆心角 n° 占 n/360，所以 l = (n/360)·2πr，约分得 l = nπr/180。

例：半径 6、圆心角 120°，l = (120/180)·π·6 = 4π。

l = nπr / 180

公式

扇形面积公式

整个圆的面积是 πr²，所以 S = (n/360)·πr²。

还有一个更好用的形式：S = ½ l r，其中 l 是弧长、r 是半径。已知弧长时用它更快。

S = ½ l r

概念

圆锥侧面展开图

把圆锥的侧面沿一条母线剪开铺平，得到一个扇形。这个扇形的半径就是圆锥的母线 l，扇形的弧长正好是底面圆的周长 2πr。

母线 l、底面半径 r、高 h 组成直角三角形，所以 l 一定比 r 长。

扇形弧长 = 2πr

公式

圆锥的侧面积与全面积

侧面积用 S = ½ l r 的公式，把弧长换成 2πr：S侧 = ½·(2πr)·l = πrl。

全面积再加上一个底面圆：S全 = πrl + πr²。

S全 = πrl + πr²

例题

例：半径 6、圆心角 120°

求这段弧的弧长与所在扇形的面积。

弧长 l = (120/180)·π·6 = 4π；面积 S = (120/360)·π·36 = 12π。用 S = ½ l r 验证：½·4π·6 = 12π，一致。

l = 4π，S = 12π

一句话记住

圆中的计算只有一条主线：看圆心角占整个圆 360° 的几分之几。弧长 l = nπr/180，分母是 180；扇形面积 S = nπr²/360，也可以写成更好用的 S = ½ l r，这里的 l 是弧长。圆锥的侧面展开后是一个扇形，扇形的半径是母线 l，扇形的弧长是底面周长 2πr，于是侧面积 S侧 = πrl，全面积再补一个底面圆，得 S全 = πrl + πr²。做题时先写清楚「占几分之几」，再套公式，最后用另一个公式验算一遍，既能防记错，也能防算错。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 弧长公式分母写成 360：应为 180，因为 2πr 里的 2 与 360 约掉了一个 2。
  • 把 S = ½ l r 里的 l 当成半径或母线，它其实是弧长。
  • 圆锥展开后把扇形半径当成底面半径 r，实际是母线 l。
  • 求全面积只算侧面积，忘了加底面圆 πr²。
  • 圆锥的母线与高混为一谈：母线是斜边，高是直角边。
