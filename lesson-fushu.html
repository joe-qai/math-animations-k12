复数

实部虚部，i² = −1

复数 z = a + bi，其中 a 是实部、b 是虚部，i 满足 i² = −1。复数可以像多项式一样加减乘，除法则通过「分子分母同乘共轭复数」把分母变成实数。复平面里，复数就是点，模就是到原点的距离。

01

知识精讲

概念 · 公式 · 例题
概念

复数的定义

形如 z = a + bi（a、b 为实数）的数叫复数，a 叫实部，b 叫虚部。

i 叫虚数单位，规定 i² = −1；注意虚部是 b，不是 bi。

当 b = 0 时，z 是实数；当 b ≠ 0 时，z 是虚数；当 a = 0 且 b ≠ 0 时，z 是纯虚数。

两个复数相等，必须实部相等且虚部相等，不能只看一部分。

z = a + bi

公式

四则运算

加减法：实部与实部相加减，虚部与虚部相加减。

乘法：按多项式展开，最后把 i² 换成 −1。

除法：分子分母同乘分母的共轭复数，使分母变成实数。

共轭复数：z = a + bi 的共轭是 a − bi，记作 z̄；z · z̄ = a² + b²。

(a+bi)(c+di) = (ac−bd) + (ad+bc)i

例题

例 1：复数乘法

计算 (1 + 2i)(3 − i)。

展开：1×3 + 1×(−i) + 2i×3 + 2i×(−i) = 3 − i + 6i − 2i²。

把 i² 换成 −1，得 3 + 5i + 2 = 5 + 5i。

所以结果是 5 + 5i，实部 5、虚部 5。

(1+2i)(3−i) = 5 + 5i

例题

例 2：复数除法

计算 (1 + i) / (1 − i)。

分子分母同乘 1 + i：(1 + i)² / (1 − i)(1 + i)。

分子 = 1 + 2i + i² = 2i；分母 = 1² − i² = 2。

所以结果是 i。

(1+i)/(1−i) = i

概念

复平面与模

复数 z = a + bi 对应复平面内的点 (a, b)，也对应向量 OZ。

模 |z| = √(a² + b²)，就是点到原点的距离。

共轭复数 a − bi 与 a + bi 关于实轴对称。

复数不能比较大小，但模可以比较大小。

|z| = √(a² + b²)

一句话记住

复数按多项式算，遇到 i² 换成 −1；除法乘共轭，模是到原点的距离。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「求虚部」改成「求纯虚数的参数范围」，同时要求实部为 0、虚部不为 0。
  • 把「求模」改成「求 z·z̄」，直接用 a² + b²，不必先算乘法。
  • 把「除法」改成「求 1/z」，分子分母同乘 z̄ 即可。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 虚部是 b，不是 bi；写虚部时不要带 i。
  • i² = −1，计算中要及时替换，不能把它当成 1。
  • 纯虚数要求实部为 0 且虚部不为 0，缺一不可。
  • 复数不能比较大小，只有模可以比较。
