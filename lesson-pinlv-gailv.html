频率与概率

次数多了，偶然就露出规律

抛一次硬币，猜不准；抛一万次，正面就接近一半。这种「次数多了就稳定」的现象，是概率的入口。这一节从抛硬币讲起：先分清频数与频率，再讲频率的稳定性，然后用稳定的频率认识概率，最后用公式算等可能事件的概率。

知识精讲

概念 · 公式 · 例题
概念

频数与频率

做了 n 次试验，某个结果出现了 m 次，m 叫这个结果出现的频数；频数除以总次数，得到的比值 m/n 叫频率。

抛 20 次硬币，正面出现 9 次：频数是 9，频率是 9/20 = 0.45。频数是次数，频率是一个比值，两者不是一回事。

频率 = 频数 ÷ 总次数

概念

频率的稳定性

频率会随试验变化，但试验次数越多，频率就在某个固定数值附近摆动，而且摆动越来越小。这个性质叫频率的稳定性。

抛硬币次数足够多时，正面朝上的频率会稳定在 0.5 左右。

次数越多，摆动越小

概念

概率

概率是刻画一个随机事件发生可能性大小的数，记作 P(A)。任何事件的概率都在 0 到 1 之间。

必然事件的概率是 1，比如掷一枚普通骰子点数小于 7；不可能事件的概率是 0，比如点数等于 7。概率是固定的数，不是凭感觉猜的。

0 ≤ P ≤ 1

公式

求概率的两种办法

用频率估计概率：试验次数很大时，把频率当作概率的估计值。比如发芽率稳定在 0.9，就估计任取一颗发芽的概率约为 0.9。

等可能时用公式：P = 所求结果数 ÷ 所有等可能结果数。前提是每种结果出现的可能性相等，不相等就不能直接数个数。

P = 所求结果数 ÷ 等可能结果总数

例题

例题：摸球与骰子

掷一枚均匀骰子：点数等于 1 的概率是 1/6；点数小于 3（即 1 或 2）的概率是 2/6 = 1/3。

袋中有 3 个红球、2 个白球，除颜色外都相同，任摸一个：共 5 个球、可能性相同，红球 3 个，所以摸到红球的概率是 3/5。

P(红球) = 3/5

一句话记住

做 n 次试验、某结果出现 m 次，m 是频数，m/n 是频率。频率会波动，但次数越多越稳定在某个常数附近，这叫频率的稳定性。这个稳定的数就是概率：概率刻画随机事件发生可能性的大小，满足 0 ≤ P ≤ 1，必然事件为 1、不可能事件为 0。求概率有两种办法：次数很大时用频率估计概率；结果等可能时用 P = 所求结果数 ÷ 所有等可能结果数。掷骰子点数等于 1 的概率是 1/6，点数小于 3 的概率是 2/6 = 1/3；3 红 2 白中摸到红球的概率是 3/5。频率会变、概率固定，次数太少时频率不能当概率。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 把频数当频率：频数是出现的次数，频率是频数与总次数的比值。
  • 试验次数太少就把频率当作概率：次数少时频率波动很大，不能作为估计。
  • 认为概率会随试验改变：频率会变，概率是固定的数。
  • 用公式前不检查是否等可能：只有每种结果出现的可能性相等，才能用结果数之比。
  • 把概率写成大于 1 或小于 0 的数：任何事件的概率都在 0 与 1 之间。
