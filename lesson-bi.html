比

两个数相除就是比，同乘同除来化简

知识精讲

概念 · 公式 · 例题
概念

比的意义与各部分

两个数相除，又叫两个数的比。写作 a : b，读作 a 比 b。比号前面的数叫前项，后面的数叫后项。

前项除以后项所得的商，叫比值。比如 3 : 2 的比值是 3 ÷ 2 = 1.5。比也可以写成分数形式。

概念

比、除法、分数

前项相当于被除数，后项相当于除数，比值相当于商；前项相当于分子，后项相当于分母，比值相当于分数值。

所以后项不能是 0，就像除数、分母都不能是 0。

公式

化简比

比的前项和后项同时乘或除以同一个不为 0 的数，比值不变，这和分数的基本性质一样。

整数比：前后项同除以它们的最大公因数。12 : 18 → 2 : 3。分数比：先同乘分母的最小公倍数。小数比：先同乘 10 或 100。结果都要是最简整数比。

a : b = (a × k) : (b × k)

例题

化简 24 : 36

24 和 36 的最大公因数是 12，前后项同时除以 12：24 : 36 = 2 : 3。

化简比的结果还是比（2 : 3），求比值的结果是一个数（2 ÷ 3 = 2/3），两者不要混。

一句话记住

两个数相除又叫两个数的比，写作 a : b，a 是前项，b 是后项，前项除以后项的商是比值。前项相当于被除数、分子，后项相当于除数、分母，所以后项不能是 0。前项和后项同乘或同除同一个不为 0 的数，比值不变；化简比要化成最简整数比，化简比的结果仍是比，求比值的结果是一个数。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 后项写成 0：后项相当于除数，不能为 0。
  • 化简后还留小数或分数：结果必须是最简整数比。
  • 把化简比当成求比值：一个是比，一个是数。
  • 只除前项不除后项：必须前后项同时乘或除。
  • 把比号当成除号直接算出小数，写成 0.5 : 0.2 的最终答案。
