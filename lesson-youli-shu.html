有理数

正数、负数、数轴、相反数与绝对值

零下二十五度和零上二十五度，看起来只差一个字，意义却完全相反。为了让「相反意义的量」也能算，数学引入了负数。这节课从温度和高程出发，把正数、负数、零讲清楚，再把它们排到数轴上，最后用数轴理解相反数和绝对值。

概念

为什么要引入负数

零上 25℃ 和零下 25℃、高于海平面和低于海平面，都是相反意义的量。小学学过的数只能表示「有多少」，表示不了「朝哪个方向」。

于是规定：大于 0 的数叫正数，小于 0 的数叫负数，0 既不是正数也不是负数。正号可以省略，负号不能省。

概念

数轴

规定了原点、正方向和单位长度的直线叫数轴，三样缺一不可。每一个有理数，都能在数轴上找到唯一一个点。

数轴上右边的数总比左边的数大，所以比较有理数大小，画一条数轴就一目了然。

概念

相反数

只有符号不同的两个数互为相反数。3 和 -3 互为相反数，-2.5 和 2.5 互为相反数，0 的相反数还是 0。

在数轴上，互为相反数的两个点关于原点对称。求一个数的相反数，就在它前面加一个负号，所以 -(-3) = 3。

公式

绝对值

一个数在数轴上对应的点到原点的距离，叫这个数的绝对值，记作 |a|。距离不会是负的，所以绝对值一定不小于 0。

正数的绝对值是它本身，负数的绝对值是它的相反数，0 的绝对值是 0。例如 |-3| = 3，|5| = 5，|0| = 0。

|a| 是到原点的距离

一句话记住

正数和负数用来表示相反意义的量，0 既不是正数也不是负数。规定了原点、正方向、单位长度的直线叫数轴，右边的数总比左边的大。只有符号不同的两个数互为相反数，它们在数轴上关于原点对称。一个数到原点的距离叫绝对值，绝对值一定不小于 0：正数是它本身，负数是它的相反数，0 的绝对值是 0。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 把 0 当成正数。0 既不是正数，也不是负数。
  • 以为绝对值等于 3 的数只有 3，漏掉 -3，其实正负两个都行。
  • 认为 -5 比 -3 大，因为 5 比 3 大。负数越往左越小。
  • 画数轴漏掉原点、正方向或单位长度中的某一样。
  • 求相反数时符号处理错，把 -(-3) 算成 -3。
