一元二次方程的应用

增长率、面积、利润与判别式

学会了解方程，还要会用方程解决真实问题。这一节把最常见的三类应用讲透：增长率问题（两年连乘，写成 (1+x)²）、几何面积问题（长比宽多几米，列 x(x+3)=40）、销售利润问题（总利润 = 每件利润 × 销量，降价后销量要加括号）。三类题解完都要回到题意检验，负根、不合理的根一律舍去。后半节把判别式用到含参数的题里：既要二次项系数不为零，又要 Δ 的符号符合要求；再用配方证明判别式总不小于零，说明方程总有实数根。

知识精讲

概念 · 公式 · 例题
概念

增长率问题

设年平均增长率为 x，原产量为 a，经过两年后的产量是 a(1 + x)²。注意是连乘两次，不是 x²。

例：产量从 100 万件增到 121 万件，得 100(1 + x)² = 121，即 (1 + x)² = 1.21，1 + x = ±1.1，x = 0.1 或 −2.1。增长率不能是 −210%，所以取 10%。

a(1 + x)² = b

概念

面积问题

先设宽为 x，再由「长比宽多 3 米」写出长为 x + 3，用「长 × 宽 = 面积」列方程。

例：x(x + 3) = 40，展开得 x² + 3x − 40 = 0，因式分解得 (x + 8)(x − 5) = 0，x = −8 或 5。宽度不能为负，取 x = 5，长就是 8 米。

x(x + 3) = 40

公式

销售利润问题

总利润 = 每件利润 × 销量。降价 x 元后，每件利润变成 40 − x，每天销量变成 20 + 2x，两者都要加括号。

例：(40 − x)(20 + 2x) = 1200，整理得 x² − 30x + 200 = 0，解得 x = 10 或 20。要让顾客更优惠，就取降 20 元。

总利润 = 每件利润 × 销量

例题

例：含参数的两个不相等实根

关于 x 的方程 (m − 1)x² + 2x + 1 = 0 有两个不相等的实根，求 m 的取值范围。

两个条件缺一不可：① 是二次方程，m − 1 ≠ 0，即 m ≠ 1；② Δ = 4 − 4(m − 1) > 0，解得 m < 2。合起来 m < 2 且 m ≠ 1。

m < 2 且 m ≠ 1

例题

例：证明方程总有实数根

证明 x² − (k + 2)x + 2k = 0 总有实数根。

Δ = (k + 2)² − 8k = k² − 4k + 4 = (k − 2)²。平方一定大于等于零，所以 Δ ≥ 0，方程总有实数根。这里配方比硬算更快。

Δ = (k − 2)² ≥ 0

一句话记住

列方程解应用题，第一步永远是找等量关系。增长率问题两年连乘，写成 a(1 + x)² = b，别忘了 (1 + x) 要平方；面积问题先设宽为 x，再按「长比宽多几米」写长，用长乘宽等于面积；销售利润问题记住总利润 = 每件利润 × 销量，降价后每件利润和销量都要加括号。判别式在含参数题里有两件事要同时做：二次项系数不为零，判别式的符号符合题目要求，缺一不可。证明题里把判别式配成完全平方，就能说明它恒不小于零。最后一步一定要回题检验，负根和不合理的根要舍去。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 增长率写成了 x²：两年增长是连乘两次，应写 (1 + x)²。
  • 降价后销量忘了加括号：应写 20 + 2x，不能拆开乱乘。
  • 含参数题只算判别式：二次项系数不为零这个条件最容易漏。
  • 解出根不检验：人数、长度、增长率不合理的根必须舍去。
  • 用判别式前没化成一般形式，a、b、c 取值全错。
