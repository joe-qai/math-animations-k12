知识精讲

概念 · 公式 · 例题
概念

列方程四步法

第一，设未知数：通常问什么就设什么，并写清单位。第二，找等量关系：把题目里表示相等的那句话圈出来。第三，按等量关系列方程。第四，解方程，代回去检验，再写答。

算术解法要倒着推，方程可以顺着题目的意思正着列，所以条件多、关系复杂时，方程更省力。

公式

解方程的固定顺序

有分母先去分母，有括号先去括号，然后移项、合并同类项，最后把未知数的系数化成 1。

移项时，跨过等号的项一定要变号。这一步错，后面全错。

移项要变号

例题

购物问题

三支笔每支 3 元，两个本子一共 19 元。设本子每本 x 元，等量关系是笔的钱加本子的钱等于 19：9 + 2x = 19。

移项得 2x = 10，所以 x = 5，本子每本 5 元。检验：9 + 2 × 5 = 19，正确。

例题

和倍问题

甲乙两数之和是 48，甲是乙的 3 倍。设乙为 x，甲就是 3x，列式 x + 3x = 48。

合并得 4x = 48，x = 12，所以乙是 12，甲是 36。检验：12 + 36 = 48。

一句话记住

列方程解应用题就四步：设未知数、找等量关系、列方程、解并检验。设未知数时问什么设什么，两个未知量就设关键的那个，另一个用式子表示。解方程按去分母、去括号、移项、合并、系数化 1 的顺序来，移项一定变号。最后别忘了检验和写答。

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「购物问题」改成「行程问题」，先找等量关系：路程 = 速度 × 时间。
  • 把「和倍问题」改成「差倍问题」，用两数差除以份数差。
  • 把「直接设所求」改成「设较小的量」，减少分数运算。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 设未知数不写单位，答句也不完整。
  • 移项忘记变号，把加看成减。
  • 两个未知量设了两个字母，方程列不出来。
  • 解完不检验，答案代回去不成立也没发现。
  • 把「甲是乙的 3 倍」理解反，写成 3x = x + 48。
