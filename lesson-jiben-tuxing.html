知识精讲

概念 · 公式 · 例题
概念

线段、射线、直线

线段有两个端点，长度是固定的；射线只有一个端点，向一方无限延伸；直线没有端点，向两方无限延伸。判断时先数端点，再看能不能延伸。

记法上，线段 AB 和直线 AB 两个字母可以交换；射线 OA 的端点 O 必须写在前面，写成射线 AO 就变成另一条射线了。

概念

比较长短与中点

比较两条线段的长短，可以用尺子量出长度，也可以把它们的一端对齐、叠在一起看谁更长。两点之间的所有连线中，线段最短。

把一条线段分成两条相等的线段的点，叫这条线段的中点。如果 C 是 AB 的中点，那么 AC = CB = AB ÷ 2。

公式

角的度量

由两条有公共端点的射线组成的图形叫角，公共端点叫顶点，两条射线叫边。角的单位是度、分、秒，采用六十进制。

1° = 60′，1′ = 60″。所以 30.5° = 30°30′，1.5° = 90′。度分秒换算时千万不要按十进制算。

1° = 60′，1′ = 60″

公式

角平分线

从一个角的顶点出发，把这个角分成两个相等的角的射线，叫这个角的角平分线。

若 OC 平分 ∠AOB，则 ∠AOC = ∠BOC = ½∠AOB。见到角平分线，先想「一半」；反过来，一半乘 2 就是整个角。

∠AOC = ½∠AOB

一句话记住

线段有两个端点、长度固定，射线只有一个端点、向一方延伸，直线没有端点、向两方延伸。两点之间线段最短，把线段分成相等两段的点叫中点。由两条有公共端点的射线组成的图形叫角，1° = 60′、1′ = 60″，按大小分成锐角、直角、钝角、平角和周角。从顶点出发把角分成两个相等角的射线叫角平分线，∠AOC = ∠BOC = ½∠AOB。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 把射线当成直线，忘了射线只有一个端点、只向一方延伸。
  • 射线记法把端点写在了后面，写成射线 AO。
  • 度分秒按十进制换算，把 1.5° 算成 15′。
  • 把角平分线理解成「把角变成两倍」，其实是分成一半。
  • 求中点时忘了除以 2，直接把整条线段的长度当成一半。
