幂函数

y = xᵅ，α 说了算

正方形面积是边长的平方，正方体体积是棱长的立方，这些都可以写成 y = xᵅ 的样子。幂函数的底数是自变量、指数是常数、系数必须是 1。α 取正、取负、取分数，图像差别很大，但所有幂函数都经过点 (1, 1)，这是判断和比较大小的抓手。

概念

幂函数的定义

形如 y = xᵅ 的函数叫幂函数，其中 α 是常数。

三条硬要求：系数是 1、底数是自变量 x、指数是常数。

所以 y = 2x²、y = x² + 1、y = 2ˣ 都不是幂函数。

α 可以是整数，也可以是分数，还可以是负数。

y = xᵅ

例题

五个常见图像

y = x：一条过原点的直线，定义域是 R。

y = x²：开口向上的抛物线，偶函数，值域 [0, +∞)。

y = x³：过原点、递增的曲线，奇函数，定义域是 R。

y = x^(1/2) = √x：只画第一象限那一支，定义域 [0, +∞)。

y = x^(−1) = 1/x：两支双曲线，不过原点，定义域 x ≠ 0。

x　x²　x³　√x　1/x

概念

α > 0 时

图像经过原点 (0, 0)，也经过 (1, 1)。

在 (0, +∞) 上单调递增，曲线从左下往右上走。

当 x > 1 时，α 越大，图像越陡，xᵅ 增长越快。

当 0 < x < 1 时，α 越大，函数值反而越小。

α > 0 ⇒ 过原点、递增

概念

α < 0 时

图像不过原点，x = 0 没有定义。

在 (0, +∞) 上单调递减，曲线从左上往右下走。

以 x 轴和 y 轴为渐近线，越走越贴近坐标轴但不相交。

α = −1 是最典型的例子，也就是反比例函数 y = 1/x。

α < 0 ⇒ 不过原点、递减

公式

比较大小的思路

同指数、不同底数：把它看成同一个幂函数，用单调性比较。

同底数、不同指数：看成指数函数，底数大于 1 时指数越大值越大。

底数和指数都不同：先找中间量 1，或者先化成同底、同指数。

所有幂函数都过 (1, 1)，这就是最常用的分界点。

同指数看底数

例题

例 2：指数不同，先化成同指数

比较 2^(1/2) 与 3^(1/3) 的大小。

两个数的指数不同，不能直接看底数，先化成同指数：取 2 和 3 的最小公倍数 6。

2^(1/2) = 2^(3/6) = (2³)^(1/6) = 8^(1/6)；3^(1/3) = 3^(2/6) = (3²)^(1/6) = 9^(1/6)。

指数相同、底数 8 < 9，所以 8^(1/6) < 9^(1/6)，即 2^(1/2) < 3^(1/3)。

2^(1/2) < 3^(1/3)

一句话记住

幂函数是形如 y = xᵅ 的函数，要求系数为 1、底数是自变量、指数是常数。α > 0 时图像过原点和 (1, 1)，在 (0, +∞) 上递增；α < 0 时不过原点，在 (0, +∞) 上递减，以坐标轴为渐近线。所有幂函数都经过 (1, 1)。比较大小先看指数是否相同，同指数用单调性，不同就找中间量 1。

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 比较两个幂的大小，先看指数是否相同；指数相同看底数，底数相同看指数。
  • 指数不同的根式，先化成同指数或同时乘方，再比较大小。
  • 含负指数的幂，先化成倒数，再判断定义域与单调性。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 系数不是 1 就不是幂函数：y = 2x² 只能算二次函数。
  • α < 0 时定义域不含 0，画图和求值都要先排除 x = 0。
  • 幂函数不一定过原点，α ≤ 0 时就不经过。
  • 比较大小前先确认两个数是否落在同一个单调区间内。
