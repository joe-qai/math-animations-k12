二次根式

开方开不尽，就留着根号

面积是 2 的正方形，边长不是整数，也不是有限小数——它是 √2。开方开不尽时，根号就是它的名字。这一节从正方形的边长讲起，讲清二次根式的定义与双重非负性，再讲两条基本性质、乘除、化简与加减合并，最后用 √((−3)²) 点出最容易错的地方。

知识精讲

概念 · 公式 · 例题
概念

二次根式与双重非负性

形如 √a 的式子叫二次根式，a 叫被开方数。a 必须大于或等于 0，因为负数在实数范围内没有平方根。

同时结果也不小于 0。两条合起来叫双重非负性：被开方数非负，结果也非负。

a ≥ 0，√a ≥ 0

公式

两条基本性质

(√a)² = a（a ≥ 0）；√(a²) = |a|。第二条要加绝对值，因为 a 为负数时开方结果仍然非负。

例：√((−3)²) = √9 = 3 = |−3|，不是 −3。

√(a²) = |a|

公式

乘除法则

√a · √b = √(ab)（a ≥ 0，b ≥ 0）；√a ÷ √b = √(a/b)（a ≥ 0，b > 0）。

这两条只对乘除成立。加减不能直接套：√2 + √3 不等于 √5。

√a·√b = √(ab)

概念

最简二次根式与化简

最简二次根式的两个标准：被开方数不含分母；被开方数不含能开得尽方的因数。

例：√12 = √(4×3) = 2√3；√(4/9) = 2/3。分母有根号要做分母有理化：1/√2 = √2/2。

√12 = 2√3

公式

加减：合并同类二次根式

化成最简后，被开方数相同的叫同类二次根式，可以像合并同类项一样合并，系数相加减、根号不变。

例：√8 + √18 = 2√2 + 3√2 = 5√2。被开方数不同就不能合并。

√8 + √18 = 5√2

例题

例题：√((−3)²)

先算平方：(−3)² = 9；再开方：√9 = 3。用性质写就是 |−3| = 3。

最容易错的是直接写 −3。开方的结果一定非负，所以负数要先变号。

√((−3)²) = 3

一句话记住

面积 a 的正方形边长是 √a；开方开不尽时就用根号表示。形如 √a（a ≥ 0）的式子叫二次根式，具有双重非负性：被开方数非负，结果也非负。两条基本性质：(√a)² = a，√(a²) = |a|，所以 √((−3)²) = 3 而不是 −3。乘除可以合并根号：√a·√b = √(ab)，√a÷√b = √(a/b)；加减不行。化简的目标是最简二次根式：被开方数不含分母、不含能开得尽方的因数，如 √12 = 2√3、√(4/9) = 2/3、1/√2 = √2/2。加减时先化简，再把同类二次根式合并：√8 + √18 = 5√2。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 把 √(a²) 直接写成 a：a 是负数时要写成 |a| 再变号。
  • 忽略被开方数非负：√a 中必须有 a ≥ 0，否则在实数范围内无意义。
  • 把加减当成乘除合并：√2 + √3 不能写成 √5。
  • 化简不彻底：根号里还留着能开得尽方的因数，或分母里还留着根号。
  • 合并时把根号也相加：2√2 + 3√2 = 5√2，根号里的数不变。
