全称量词与存在量词

全称变存在，结论取反

「所有同学都到齐了」和「有人带了伞」，说的是两件不同的事。所有、任意叫全称量词，记作 ∀；存在、至少有一个叫存在量词，记作 ∃。全称命题要真，必须每一个都成立，找到一个反例就能推翻；存在命题要真，举出一个例子就够了。否定时套路固定：全称变存在、存在变全称，结论取反。「所有人都及格」的否定不是「所有人都不及格」，而是「有人没及格」。

知识精讲

概念 · 公式 · 例题
概念

全称量词与全称命题

「所有」「任意」「每一个」这类词叫全称量词，用符号 ∀ 表示。

含有全称量词的命题叫全称命题，形如「∀x ∈ M，p(x)」。

全称命题要真，必须范围内每一个 x 都让 p(x) 成立。

∀x ∈ M，p(x)

概念

存在量词与存在命题

「存在」「至少有一个」「有些」这类词叫存在量词，用符号 ∃ 表示。

含有存在量词的命题叫存在命题，形如「∃x ∈ M，p(x)」。

存在命题要真，只要在范围内找到一个 x 使 p(x) 成立就够了。

∃x ∈ M，p(x)

概念

判断真假的方法

判断全称命题为假，只需举出一个反例。

判断全称命题为真，要给出一般性的证明，验证几个数不算数。

判断存在命题为真，只需举出一个例子；为假则要说明范围内都不成立。

反例推翻全称，举例证明存在

公式

否定的写法

全称命题的否定是存在命题：∀x，p(x) 的否定是 ∃x，¬p(x)。

存在命题的否定是全称命题：∃x，p(x) 的否定是 ∀x，¬p(x)。

两件事同时变：量词换掉，结论取反。

¬(∀x p) = ∃x ¬p　¬(∃x p) = ∀x ¬p

例题

「都及格」的否定

原命题：所有的同学都及格了。

否定：存在同学没及格，而不是「所有的同学都没及格」。

「都不及格」比原命题还强，它不是否定，是另一个命题。

判断否定对不对，就看原命题与否定能不能一真一假。

都及格 → 有人没及格

例题

例 2：否定的两步走

写出 ∀x ∈ R，x² + 1 > 0 的否定，并判断原命题与否定的真假。

否定分两步：全称量词 ∀ 改成存在量词 ∃，结论 x² + 1 > 0 改成 x² + 1 ≤ 0。

所以否定是 ∃x ∈ R，x² + 1 ≤ 0。

原命题真，因为 x² ≥ 0，所以 x² + 1 ≥ 1 > 0；否定命题假，因为找不到这样的 x。原命题与否定命题真假相反，可以用来检查。

否定：∃x ∈ R，x² + 1 ≤ 0

一句话记住

「所有、任意」是全称量词 ∀，「存在、至少一个」是存在量词 ∃。全称命题靠反例推翻，存在命题靠举例证明。否定时量词与结论同时改变：∀ 变 ∃、∃ 变 ∀，结论取反。所以「所有人都及格」的否定是「有人没及格」。

03

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 写否定时先换量词，再把结论改成相反面，两步都要做。
  • 判断全称命题为假，只需举一个反例；判断存在命题为真，只需举一个例子。
  • 存在命题的否定是全称命题，别只把结论加「不」。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 否定只改结论：忘了同时把全称换成存在。
  • 把「不都是」当成「都不是」：否定是「有人不是」，不是「全都不是」。
  • 用几个例子证明全称命题：验证再多也只是举例，不算证明。
  • 存在命题举反例：存在命题要推翻，得说明范围内一个都没有。
