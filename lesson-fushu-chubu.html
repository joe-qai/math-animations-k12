生活中的负数

零下、地下、支出，都能用负数记

哈尔滨零下二十度，电梯停在地下一层，存折上刚取出一笔钱——这些和正数意思相反的量，都能用负数记下来。这节课先看温度计，再把温度计拉直成数轴，弄明白零为什么是分界，最后学会比较两个负数的大小。

02

知识精讲

概念 · 公式 · 例题
概念

零上与零下

温度计中间是 0 ℃。零上五度记作 +5 ℃，读作正五摄氏度；零下五度记作 -5 ℃，读作负五摄氏度。

0 ℃ 是水结冰的温度：零上水不结冰，零下水就结冰。所以 0 不只是「没有」，它是一条分界线。

概念

0 既不是正数也不是负数

把温度计拉直，就得到一条数轴：0 的右边是正数，左边是负数。越往右数越大，越往左数越小。

0 正好在中间，它既不是正数，也不是负数，而是正数和负数的分界点。

公式

用正负数表示相反意义的量

上车 5 人记作 +5 人，下车 3 人记作 -3 人；收入 100 元记作 +100 元，支出 60 元记作 -60 元；水位上升 2 米记作 +2 米，下降 1 米记作 -1 米。

用之前要先说清楚谁为正，和它意思相反的那个量就记为负。正号可以省略，负号一定要写。

+5 与 -5

例题

比较负数的大小

在数轴上比较：-5 在 -2 的左边，所以 -5 < -2。负数越往左越小。

也可以这样记：负号后面的数越大，这个负数反而越小。5 比 2 大，但 -5 比 -2 小。

一句话记住

零上、地下、收入这些和正数意思相反的量，用负数表示。0 是正数和负数的分界，既不是正数也不是负数。把温度计拉直就是数轴：右边正、左边负，越往右越大。比较负数时越往左越小，-5 比 -2 小。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 以为 0 是正数：0 既不是正数也不是负数。
  • 把 -3 写成 3：负号一丢，这个数就变成了它的相反数。
  • 认为 -5 > -2：5 比 2 大，但 -5 比 -2 小。
  • 把正号也当成必需的：+5 可以直接写成 5。
  • 说「0 就是没有」：0 ℃ 表示冰点，是有意义的一个温度。
