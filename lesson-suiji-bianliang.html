离散型随机变量及其分布

分布列概率和为一

离散型随机变量取有限个或可列个值，每个值对应一个概率，列成表就是分布列。分布列的所有概率之和必须为 1。期望描述平均水平，方差描述波动大小；二项分布 B(n,p) 的期望是 np，方差是 np(1−p)。

01

知识精讲

概念 · 公式 · 例题
公式

分布列

离散型随机变量 X 的所有取值 x₁、x₂、… 与对应概率 p₁、p₂、… 列成表，叫分布列。

分布列必须满足 pᵢ ≥ 0，且所有概率之和为 1。

求分布列时，先确定所有可能取值，再逐个算概率。

概率和为 1 既是性质，也是检验计算是否正确的工具。

Σpᵢ = 1

公式

期望与方差

期望 E(X) = x₁p₁ + x₂p₂ + … + xₙpₙ，描述平均水平。

方差 D(X) = (x₁−E(X))²p₁ + … + (xₙ−E(X))²pₙ，描述波动大小。

常用简化公式 D(X) = E(X²) − [E(X)]²。

期望是「加权平均」，方差越小，取值越集中。

E(X) = Σxᵢpᵢ

例题

例 1：求期望

随机变量 X 的分布列为：X = 0、1、2，概率分别为 0.2、0.5、0.3。

E(X) = 0×0.2 + 1×0.5 + 2×0.3 = 1.1。

E(X²) = 0²×0.2 + 1²×0.5 + 2²×0.3 = 0.5 + 1.2 = 1.7。

D(X) = 1.7 − 1.1² = 0.49。

E(X)=1.1，D(X)=0.49

公式

二项分布

n 次独立重复试验中，每次成功的概率为 p，成功次数 X 服从二项分布 B(n,p)。

P(X = k) = C(n,k)pᵏ(1−p)ⁿ⁻ᵏ。

期望 E(X) = np，方差 D(X) = np(1−p)。

判断二项分布要满足：试验次数固定、每次独立、成功概率相同。

X ~ B(n,p)，E(X)=np

例题

例 2：二项分布

投篮命中率为 0.6，投 5 次，求命中次数 X 的期望与方差。

每次投篮独立、命中率相同，所以 X ~ B(5, 0.6)。

E(X) = np = 5 × 0.6 = 3。

D(X) = np(1−p) = 5 × 0.6 × 0.4 = 1.2。

E(X)=3，D(X)=1.2

一句话记住

分布列概率和为一；期望加权平均，方差看波动；二项分布 E=np，D=np(1−p)。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「求期望」改成「求 E(2X+1)」，用 E(aX+b) = aE(X)+b。
  • 把「二项分布」改成「超几何分布」，注意无放回时概率会变化。
  • 把「投篮 5 次」改成「直到命中为止」，改用几何分布。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 分布列概率之和不为 1，说明取值或概率算错。
  • 期望公式是 Σxp，不是 Σx²p。
  • 方差用 D(X) = E(X²) − [E(X)]² 时，别把 [E(X)]² 写成 E(X²)。
  • 二项分布要求每次试验独立且概率相同，无放回抽样一般不满足。
