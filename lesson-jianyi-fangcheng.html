知识精讲

概念 · 公式 · 例题
概念

什么是方程

含有未知数的等式叫方程。x + 2 = 5、2x + 4 = 12 都是方程。

判断方程要同时看两点：一是有没有未知数，二是不是等式。x + 3 没有等号，不是方程；3 + 5 = 8 有等号但没有未知数，也不是方程。

公式

等式的性质

等式两边同时加上或减去同一个数，等式仍然成立；等式两边同时乘或除以同一个不为 0 的数，等式也成立。

就像天平：两边同时加同样重的东西，或者同时减掉同样重的东西，天平仍然平衡。

两边同加同减，等式不变

例题

解 x + 3 = 9

要让左边只剩 x，就把多加的 3 减掉，两边同时减 3：x + 3 − 3 = 9 − 3，左边剩 x，右边得 6，所以 x = 6。

检验：把 x = 6 代回原方程，6 + 3 = 9，左右相等，答案正确。

例题

解 2x + 4 = 12 与 2x − 4 = 12

2x + 4 = 12：两边先同时减 4，得 2x = 8；再两边同时除以 2，得 x = 4。检验：2×4 + 4 = 12，成立。

2x − 4 = 12：两边先同时加 4，得 2x = 16；再同时除以 2，得 x = 8。口诀是先处理加减，再处理乘除。

一句话记住

含有未知数的等式叫方程，两个条件缺一不可。等式两边同时加、减、乘、除同一个数（除数不为 0），等式不变。解 x + b = c 就两边同时减 b；解 ax ± b = c 先两边同时加减 b，再两边同时除以 a。解完把答案代回原方程检验。

03

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把 x + 3 = 9 改成 x − 3 = 9，两边同时加 3。
  • 把 2x + 4 = 12 改成 2x − 4 = 12，先两边加 4 再除以 2。
  • 把「解方程」改成「检验」，把答案代回原方程看左右是否相等。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 以为有等号就是方程：还要含有未知数。
  • 只变一边：等式两边必须同时做同样的运算。
  • 解完不检验：把解代回原方程，左右相等才正确。
  • 两步方程先除以 2：要先把加减的部分处理掉，再处理乘除。
  • 把 x + 3 当成方程：没有等号，它只是一个式子。
