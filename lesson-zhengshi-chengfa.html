整式的乘法

单项式乘单项式、单项式乘多项式、多项式乘多项式

教室里每排 7 张桌子、摆 5 排，一共 35 张；如果每张桌面长 a、宽 b，面积就是 7a × 5b = 35ab。整式的乘法说的就是这件事：系数和系数乘，字母按同底数幂的法则乘。三条路线由易到难：单项式乘单项式、单项式乘多项式、多项式乘多项式，最后都能落到一张分块的长方形上。

02

知识精讲

概念 · 公式 · 例题
概念

从面积看乘法

每排 7 张桌子、摆 5 排，一共 7 × 5 = 35 张。如果每张桌面长 a、宽 b，整个教室的桌面总面积就是 7a × 5b = 35ab。

整式乘法与整数乘法同理：数字和数字乘，字母和字母乘。区别只在于字母部分要用同底数幂的运算法则——相乘时指数相加。

公式

单项式乘单项式

系数相乘，同底数幂相乘，只在一个单项式里出现的字母连同它的指数照抄。

3x² · 2x³ = (3 × 2)x²⁺³ = 6x⁵。系数 3 × 2 = 6，指数 2 + 3 = 5，分两步看就不会乱。

3x² · 2x³ = 6x⁵

公式

单项式乘多项式

用分配律，把单项式分别乘多项式的每一项，再把所得的积相加。

2x(3x + 1) = 2x · 3x + 2x · 1 = 6x² + 2x。括号里有几项，乘完就有几项，一项都不能漏。

m(a + b) = ma + mb

公式

多项式乘多项式

先用一个多项式的每一项，分别乘另一个多项式的每一项，再把所得的积相加，最后合并同类项。

(x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6。两个二项式相乘，先得四项，合并后才变成三项。

这件事画成图就很好懂：把边长 x + 3 和 x + 2 的长方形切成四块，面积分别是 x²、3x、2x、6，加起来正好是结果。

(x + 2)(x + 3) = x² + 5x + 6

一句话记住

整式乘法有三条路线：单项式乘单项式，系数相乘、同底数幂相乘，3x² · 2x³ = 6x⁵；单项式乘多项式，用分配律逐项相乘，2x(3x + 1) = 6x² + 2x；多项式乘多项式，逐项相乘再合并同类项，(x + 2)(x + 3) = x² + 5x + 6。整个过程可以画成一块被切成四块的长方形，面积相加就是答案。做完先数项数，再合并同类项。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 单项式乘多项式只乘了第一项，后面的项被漏掉。
  • 负号乘进括号时没有变号，(−1) × 3 写成 3。
  • 多项式乘多项式后没有合并同类项，把 3x + 2x 就那么放着。
  • 单项式乘单项式时把系数也相加，3x² · 2x³ 写成 5x⁵。
  • 把字母的指数当成系数相乘，2x · 3x 写成 6x。
