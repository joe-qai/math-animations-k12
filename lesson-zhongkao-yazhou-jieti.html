压轴题拆解（中考专题）

几何综合：标图、模型、动点、最值，按步拿分

中考最后一道大题通常十二分，前两问是送分的，最后一问才拉开差距。很多人整题空着，把前两问的分也一起丢了。这一节按考场顺序拆：读题先标图——垂直画直角符号、中点打点、角平分线画等角、等腰标两边相等、平行画箭头，标完再判断图形是固定的还是有动点；两个高频模型——一线三等角（一条直线上三个相等的角，两侧三角形相似）与手拉手（共顶点、两边相等，连出来的两条线段相等、夹角等于顶角）；半角模型（正方形里的 45°、等边三角形里的 30°），处理方式固定，旋转让相等的边重合，再说明三点共线；动点三步——设元、建式、写定义域；最后一问的两类考法——最值（配方求顶点，但要检查顶点在不在定义域内）与存在性（等腰分三类、直角分三类，逐一验证）。最后是答题策略：按步给分，先把必得的分拿到手。

知识精讲

概念 · 公式 · 例题
概念

读题先标图

压轴题的图不是看懂的，是标出来的。读到垂直就画直角符号，读到中点就打点，读到角平分线就画等角，读到等腰就标两边相等，读到平行就画箭头。

标完再分两类：图形固定不动，靠全等、相似、特殊四边形的性质；图形里有动点，靠设元、建函数、写定义域。这一步定了，后面的路就清楚了。

先标条件，再选模型

概念

模型一：一线三等角

一条直线上有三个相等的角，两侧的两个三角形一定相似，因为剩下两个角也分别相等。这个模型常和坐标系、函数图象结合，用来把线段关系转成比例式。

手拉手是它的常见变形：两个等腰三角形共用一个顶点且顶角相等，那么连出来的两条线段相等，它们的夹角等于两个顶角之和或差。看到共顶点、两边相等，第一反应就该是旋转。

共顶点 + 两边相等 → 想旋转

概念

模型二：半角模型

正方形里出现 45°，等边三角形里出现 30°，都是半角。处理方法固定：把其中一个小三角形绕顶点旋转，让两条相等的边重合，半角就变成完整角的一部分，从而构造出全等。

旋转之后必须说明三点共线，这一步在评分标准里是给分点。只说「旋转得到」而不说明共线，往往拿不到满分。

旋转 → 边重合 → 说明三点共线

公式

动点三步

第一步设元：设运动时间为 t，或设某条线段长为 x，并把能用它表示的线段都写出来。第二步建式：用勾股定理、相似或面积关系列出函数。第三步写定义域：动点有起点和终点，x 的取值范围必须写出来。

定义域是最容易漏的一步，也是压轴题最常见的扣分点。求最值时如果顶点不在定义域内，就只能取端点。

设元 → 建式 → 定义域

例题

例：最值要先看范围

若得到 y = −(x − 2)² + 4，且 0 ≤ x ≤ 4，顶点 x = 2 在范围内，最大值是 4；最小值在端点处取得，y(0) = y(4) = 0。

如果定义域换成 3 ≤ x ≤ 4，顶点就不在范围内，最大值变成 y(3) = 3，最小值仍是 y(4) = 0。不检查范围直接写顶点，是典型错误。

顶点在范围内取顶点，不在就取端点

例题

例：存在性要分类

问「是否存在点 P，使 △ABP 为等腰三角形」，要按 PA = PB、PA = AB、PB = AB 三种情况分别列方程，逐一求解并检验点是否在图形上。

问「是否存在点 P，使 △ABP 为直角三角形」，要按直角在 A、B、P 三个顶点分别讨论。分类不全，就是压轴题最后一问最常见的失分。

等腰三类，直角三类

一句话记住

压轴题的策略就是按步得分。读题先标图，把垂直、中点、角平分、等腰、平行这些条件都画上去，再判断图形固定还是有动点。固定图形靠模型：一线三等角得到相似，手拉手得到两条相等线段和夹角关系，半角模型靠旋转造全等并说明三点共线。有动点就三步走：设元、建式、写定义域，定义域千万别漏。最后一问考最值就配方后检查顶点在不在范围内，考存在性就按等腰三类、直角三类分类讨论并逐一验证。前两问写清楚就是六到八分，先把稳的拿到手，再去冲最后一问。

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 整题空着，把前两问的六到八分一起丢掉。
  • 旋转之后不说明三点共线，关键步骤缺依据。
  • 分类讨论漏情况，等腰或直角只讨论了一两种。
  • 求最值不检查顶点是否在定义域内，直接写顶点。
  • 算完不回到题目问的结论，答非所问。
