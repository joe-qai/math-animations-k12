勾股定理的逆定理

用边长判断直角

勾股定理反过来也成立：如果一个三角形的三边满足 a² + b² = c²，那它就是直角三角形。装修师傅量出 60、80、100 就能画出直角，用的正是这一条。这一节讲清定理的条件、和原定理的区别、判断的三步流程，以及要记住的几组勾股数。

知识精讲

概念 · 公式 · 例题
概念

逆定理说的是什么

如果一个三角形的三条边满足 a² + b² = c²，那么这个三角形是直角三角形，并且边 c 所对的角是直角。

c 必须是三条边里最长的那条。也就是说，直角在最长边的对面，这条最长边就是斜边。

a² + b² = c² → 直角三角形

公式

和勾股定理正好反过来

勾股定理：已知是直角三角形，得到 a² + b² = c²，用来算边长。

逆定理：已知 a² + b² = c²，得到它是直角三角形，用来判断形状。做题先看问什么，再决定用哪一个。

直角 → 关系；关系 → 直角

公式

判断只有三步

第一步，找出最长边，记作 c；第二步，算出另外两边的平方和；第三步，和最长的平方比一比。

相等，就是直角三角形；不相等，就不是。注意比的是平方，不是边长本身：6 + 8 不能拿去和 10 比。

平方和 = 最长边的平方

概念

常用的勾股数

3、4、5（9 + 16 = 25）；5、12、13（25 + 144 = 169）；8、15、17（64 + 225 = 289）；7、24、25（49 + 576 = 625）。

它们的整数倍也成立，比如 6、8、10，或者 9、12、15。考试里看到这几组数，可以直接反应出直角。

3、4、5　5、12、13

例题

例题：判断 5、12、13

最长边是 13，所以 c = 13。算 5² + 12² = 25 + 144 = 169，而 13² = 169，两者相等。

所以这个三角形是直角三角形，13 所对的角是直角，即 ∠B = 90°。

5² + 12² = 13²

一句话记住

勾股定理的逆定理：如果三角形的三边满足 a² + b² = c²，那么这个三角形是直角三角形，且 c 所对的角是直角。c 必须是最长边。它和勾股定理正好反过来——原定理已知直角、用来算边长，逆定理已知边的关系、用来判断形状。判断三步：找最长边 c、算另两边的平方和、与 c² 比较，相等就是直角三角形。常用勾股数 3-4-5、5-12-13、8-15-17、7-24-25 及其整数倍要熟。注意比的是平方而不是边长相加减，逆定理也只判定直角，推不出另外两个角的度数。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 没有先找最长边，c 认错了，直角就标到了别的顶点上。
  • 拿边长相加减去比，比如用 6 + 8 和 10 比；要比较的是平方和与最长边的平方。
  • 三边不满足等式就说「不是三角形」——它只是不是直角三角形，仍然是三角形。
  • 逆定理只能判定它是直角三角形，不能顺手写出另外两个角各是多少度。
  • 写公式时把 c 放错位置：c 必须是最长边，另两条才是直角边。
