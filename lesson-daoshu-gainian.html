导数的概念与运算

导数就是瞬时变化率

导数描述函数在某一点变化的快慢，几何上就是切线斜率。定义是极限，但计算靠公式：幂函数、和差、乘积、商、复合函数各有法则。求切线方程时，先求导数值作斜率，再代点写点斜式。

01

知识精讲

概念 · 公式 · 例题
概念

定义与几何意义

函数 y = f(x) 在 x₀ 处的导数记作 f'(x₀)，定义为 Δy/Δx 当 Δx 趋于 0 时的极限。

几何意义：f'(x₀) 是曲线在点 (x₀, f(x₀)) 处切线的斜率。

物理意义：位移对时间的导数是瞬时速度。

导数存在，要求左右两侧的极限都存在且相等。

f'(x₀) = lim Δy/Δx

公式

基本公式与法则

常用导数：(xⁿ)' = n xⁿ⁻¹，(sinx)' = cosx，(cosx)' = −sinx，(eˣ)' = eˣ，(lnx)' = 1/x。

和差法则：(u ± v)' = u' ± v'。

乘积法则：(uv)' = u'v + uv'；商的法则：(u/v)' = (u'v − uv')/v²。

常数函数的导数为 0，常数可以提到导数外面。

(xⁿ)' = n xⁿ⁻¹

公式

复合函数求导

若 y = f(g(x))，则 y' = f'(g(x)) · g'(x)，叫链式法则。

操作顺序：先对外层求导，再乘以内层函数的导数。

例如 (2x+1)³ 的导数是 3(2x+1)² × 2 = 6(2x+1)²。

复合层次多时，由外向内一层一层乘，不要漏掉最内层。

y' = f'(g(x)) · g'(x)

例题

例 1：求导数值

已知 f(x) = x³ + 2x，求 f'(1)。

先求导：f'(x) = 3x² + 2。

代入 x = 1：f'(1) = 3 + 2 = 5。

所以曲线在 x = 1 处的切线斜率为 5。

f'(1) = 5

例题

例 2：切线方程

求曲线 y = x³ + 2x 在点 (1, 3) 处的切线方程。

由例 1，斜率 k = f'(1) = 5。

代入点斜式：y − 3 = 5(x − 1)。

整理得 y = 5x − 2。

y = 5x − 2

一句话记住

导数看瞬时变化；切线斜率取导数值；复合函数由外向内层层乘。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「在点 (1,3) 处的切线」改成「过点 (1,3) 的切线」，要先判断该点是否在曲线上。
  • 把「x³」改成「x⁻¹」，用幂函数公式，指数为负。
  • 把「单独函数」改成「乘积」，用 (uv)' = u'v + uv'。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 导数是极限，不是 average rate，Δx 必须趋于 0。
  • 「在点 P 处」与「过点 P」不同，后者点不一定在曲线上。
  • 复合函数求导漏乘内层导数，是最高频错误。
  • 常数的导数是 0，不要写成常数本身。
