对数与对数函数

对数就是问指数

已知 2 的几次方等于 8，这个「几次方」就是对数的意思，写成 log₂8 = 3。所以对数和指数是同一件事的两种问法：指数是「底数乘几次」，对数是「要乘几次」。对数有三条运算律，把乘除变成加减、把乘方变成倍数。对数函数 y = logₐx 与指数函数互为反函数，图像关于 y = x 对称。

概念 · 公式 · 例题
概念

对数的定义

如果 aᵇ = N（a > 0，a ≠ 1，N > 0），就把 b 叫做以 a 为底 N 的对数，记作 b = logₐN。

a 叫底数，N 叫真数，真数必须大于 0。

它回答的是「a 要乘几次才等于 N」，所以对数就是问指数。

两个恒等式：a^(logₐN) = N，logₐaᵇ = b。

aᵇ = N ⇔ b = logₐN

公式

三条运算律

积的对数等于对数的和：logₐ(MN) = logₐM + logₐN。

商的对数等于对数的差：logₐ(M/N) = logₐM − logₐN。

幂的对数等于指数乘对数：logₐMⁿ = n · logₐM。

三条律把乘除降成加减、把乘方降成乘法，这就是对数最大的用处。

logₐ(MN) = logₐM + logₐN

公式

换底公式

logₐb = log_c b / log_c a，换底时分子是目标真数、分母是原底数。

常用推论：logₐb · log_b a = 1，logₐb = 1 / log_b a。

计算器一般只有以 10 为底或自然对数，换底后就能算任意底。

换底公式也常用来把不同底的对数化成同底再比较。

logₐb = log_c b / log_c a

概念

对数函数的图像

y = logₐx（a > 0，a ≠ 1）的定义域是 (0, +∞)，值域是 R。

图像一定经过点 (1, 0)，因为 logₐ1 = 0。

y 轴是它的竖直渐近线，x 趋近 0 时图像向下无限延伸。

它与 y = aˣ 互为反函数，图像关于直线 y = x 对称。

y = logₐx

例题

比较大小的套路

同底不同真数：直接看单调性，a > 1 时真数大的值大。

同真数不同底：画图或换底，底数大于 1 时底数越大值越小。

底和真数都不同：先找 0 或 1 当中间量，把两个数夹在两侧。

例：log₂3 > 1，log₃2 < 1，所以 log₂3 > log₃2。

一句话记住

对数是指数的逆运算：aᵇ = N 等价于 b = logₐN，真数必须为正。三条运算律把积、商、幂分别变成和、差、倍数，换底公式能把任意底化成同底。对数函数 y = logₐx 定义域 (0, +∞)、值域 R、恒过 (1, 0)，a > 1 时递增、0 < a < 1 时递减，与指数函数互为反函数。

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 真数必须大于 0：写 logₐN 之前先确认 N > 0。
  • 把 log(M + N) 拆成 log M + log N：运算律只管乘除，不管加减。
  • 忘记底数限制：底数要大于 0 且不等于 1。
  • 换底时分子分母颠倒：分子是目标真数的对数，分母是原底的对数。
