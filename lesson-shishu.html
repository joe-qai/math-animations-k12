实数

面积是 2，边长是多少

边长 3 的正方形面积是 9，反过来面积 9 求边长就是 3。可面积正好是 2 呢？边长是 √2 ≈ 1.4142…，小数位写不完也循环不了，这样的数叫无理数。这节课从「开方」出发：先分清平方根与算术平方根，再讲立方根为什么负数也有；然后给实数分类，把无理数放到数轴上，用两个能开方的数夹出 √2 的大致值；最后辨析两个最容易混的式子 √(a²) 与 (√a)²。

知识精讲

概念 · 公式 · 例题
概念

开方：已知面积求边长

正方形面积 9，边长是 3，因为 3² = 9；反过来，已知面积求边长，这个运算就叫开方。面积是 2 时，边长是 √2，它的小数部分是 1.414 213 56…，写不完也循环不了。

这就是无理数出现的原因：不是我们算不出来，而是它本来就不能写成一个有限小数或分数。

公式

平方根与算术平方根

因为 3² = 9，(−3)² = 9，所以 9 的平方根有两个：3 和 −3，记作 ±3。一个正数有两个平方根，它们互为相反数；0 的平方根只有 0；负数没有平方根，因为任何数的平方都不可能是负数。

其中正的那个叫算术平方根，用 √ 表示：√9 = 3。注意 √9 只等于 3，不等于 ±3；要表示两个平方根，得写成 ±√9。

正数有两个平方根，负数没有

公式

立方根

因为 2³ = 8，所以 8 的立方根是 2，记作 ³√8 = 2；因为 (−2)³ = −8，所以 −8 的立方根是 −2。

和平方根不同，任何数都有且只有一个立方根：正数的立方根是正数，0 的立方根是 0，负数的立方根是负数。符号可以直接从根号里搬出来。

³√(−8) = −2

公式

实数与数轴

整数和分数统称有理数，都能写成两个整数相除；无限不循环小数叫无理数，例如 √2、π。有理数和无理数合起来就是实数。

数轴上的每一个点都对应一个实数，每一个实数也都对应数轴上的一个点，这叫一一对应。估算 √2 时，找左右两个能开方的数夹住它：1.4² = 1.96，1.5² = 2.25，所以 1.4 < √2 < 1.5。

实数与数轴上的点一一对应

公式

两个容易混的式子

√(a²) = |a|：先平方再开方，结果一定是非负数，所以要套绝对值。例如 √((−3)²) = √9 = 3，不是 −3。

(√a)² = a：先开方再平方，直接还原，但前提是 a ≥ 0，因为负数不能开平方。两个式子运算顺序不同，结果也不同。

√(a²) = |a|　(√a)² = a（a ≥ 0）

一句话记住

开方就是已知面积求边长。正数有两个互为相反数的平方根，0 的平方根是 0，负数没有平方根；其中正的那个叫算术平方根，√9 = 3。任何数都有唯一的立方根，负数的立方根是负数。整数和分数是有理数，无限不循环小数是无理数，两者合起来是实数，实数与数轴上的点一一对应。两个易混式子：√(a²) = |a|，(√a)² = a（a ≥ 0）。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 把 9 的平方根只写成 3，漏掉 −3。一个正数的平方根有两个，要写 ±3。
  • 把 √(a²) 直接写成 a。正确是 |a|，因为开出来必须是非负数。
  • 以为负数没有立方根。负数有立方根，只是没有平方根。
  • 把 π 当成 3.14。3.14 只是近似值，π 是无限不循环的无理数。
  • 以为 √2 能写成分数。它是无理数，不能表示成两个整数相除。
