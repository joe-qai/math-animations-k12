平面向量的线性运算

首尾相接，指向终点

向量是既有大小又有方向的量。加法用三角形法则：首尾相接，从起点指向终点；减法用「指向被减向量的终点」；数乘只改变长度，负数则反向。把向量放进坐标系，加减与数乘就变成坐标的加减与倍数。

知识精讲

概念 · 公式 · 例题
概念

向量与相等向量

既有大小又有方向的量叫向量，记作 a 或 AB，其中 A 是起点、B 是终点。

向量的大小叫模，记作 |a|；模为 1 的叫单位向量，模为 0 的叫零向量，零向量的方向任意。

长度相等、方向相同的两个向量叫相等向量，与起点位置无关；方向相同或相反的非零向量叫共线向量，也叫平行向量。

注意：向量不能比较大小，只能说模长谁大谁小。

|a| = 向量的长度

公式

加法与减法

三角形法则：把 b 的起点移到 a 的终点，从 a 的起点指向 b 的终点，就是 a + b。

平行四边形法则：把 a、b 平移到同一起点，以它们为邻边作平行四边形，同起点的对角线就是 a + b。

减法：a − b 可以看成 a + (−b)，结果从 b 的终点指向 a 的终点，口诀是「指向被减向量的终点」。

数乘：λa 的模是 |λ||a|；λ > 0 时方向不变，λ < 0 时方向相反，λ = 0 时得到零向量。

AB + BC = AC

例题

例 1：向量化简

化简 AB + BC + CD。

先把前两个相加：AB + BC = AC；再与 CD 相加：AC + CD = AD。

所以原式 = AD。做这类题的关键，是不断把「终点」和下一个「起点」接上。

AB + BC + CD = AD

例题

例 2：共线求参数

已知 a = (1, 2)，b = (2, λ)，且 a 与 b 共线，求 λ。

共线的坐标条件是 x₁y₂ − x₂y₁ = 0，即 1 × λ − 2 × 2 = 0，解得 λ = 4。

也可以直接观察：b 的第一分量是 a 的 2 倍，所以第二分量也应是 2 倍，λ = 4。

x₁y₂ − x₂y₁ = 0

概念

坐标运算

设 a = (x₁, y₁)，b = (x₂, y₂)，则 a + b = (x₁ + x₂, y₁ + y₂)，a − b = (x₁ − x₂, y₁ − y₂)。

数乘 λa = (λx₁, λy₁)，每个坐标都乘 λ。

若 A(x₁, y₁)、B(x₂, y₂)，则 AB = (x₂ − x₁, y₂ − y₁)，一定是「终点减起点」。

判断三点共线，可以先写出两条有公共起点的向量，再看它们是否成倍数。

AB = (x₂ − x₁, y₂ − y₁)

一句话记住

加法首尾相接指向终点，减法指向被减向量终点，数乘只改长度；坐标运算逐个分量做。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「AB + BC」换成「AB − CB」，先统一成首尾相接：AB − CB = AB + BC = AC。
  • 给出三点坐标判断共线，先算 AB 与 AC，再验证 AB = λAC。
  • 已知 a + b 与 a − b 求 a、b，用方程组相加、相减反解。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 向量不能比较大小，写「a > b」一定是错的。
  • 零向量方向任意，讨论共线时要注意排除零向量。
  • 减法方向容易反：AB − AC = CB，不是 BC。
  • 坐标运算忘记「终点减起点」，把 AB 写成 (x₁ − x₂, y₁ − y₂)。
