导数的应用

导数定单调与极值

导数的符号决定函数的增减：f' > 0 递增，f' < 0 递减。f' = 0 只是极值点的候选，还要看导数是否变号。闭区间上的最值，要把极值与两端点函数值一起比较；恒成立问题则转化为最值问题。

导数定单调与极值
01

知识精讲

概念 · 公式 · 例题
公式

单调性

在区间 I 上，若 f'(x) > 0，则 f(x) 在 I 上单调递增；若 f'(x) < 0，则单调递减。

求单调区间先求定义域，再解 f'(x) > 0 与 f'(x) < 0。

单调区间之间用「和」或逗号连接，不能用并集符号。

含参数时，先求导，再对参数分类讨论导数的符号。

f' > 0 ⇒ 递增

公式

极值

f'(x₀) = 0 只是极值点的必要条件，还要看 f' 在 x₀ 两侧是否变号。

f' 由正变负，x₀ 是极大值点；由负变正，x₀ 是极小值点。

极值是局部概念，极大值不一定大于极小值。

列表法是判断极值的稳妥办法：按零点分段，标出每段导数的符号。

f' 变号 ⇒ 极值

例题

例 1：求单调区间与极值

已知 f(x) = x³ − 3x，求单调区间与极值。

f'(x) = 3x² − 3 = 3(x−1)(x+1)，零点为 −1 和 1。

f' > 0 得 x < −1 或 x > 1，f' < 0 得 −1 < x < 1。

所以在 (−∞,−1) 和 (1,+∞) 递增，在 (−1,1) 递减；极大值 f(−1) = 2，极小值 f(1) = −2。

极大值 2，极小值 −2

公式

闭区间最值

求闭区间 [a, b] 上的最值：先求区间内的极值点，再算这些点与端点 a、b 的函数值。

比较所有候选值，最大的是最大值，最小的是最小值。

极值不一定是最值，端点常常被忽略。

若函数在区间上单调，最值直接在端点取到。

比较极值与端点

例题

例 2：恒成立

若对任意 x > 0，不等式 x² − ax + 1 ≥ 0 恒成立，求 a 的取值范围。

分离参数：a ≤ x + 1/x 对 x > 0 恒成立。

由基本不等式 x + 1/x ≥ 2，当 x = 1 时取等。

所以 a ≤ 2。

a ≤ 2

一句话记住

导数符号定增减，变号才是极值；闭区间最值连端点一起比；恒成立转最值。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「求单调区间」改成「已知单调性求参数」，转化为 f' ≥ 0 或 f' ≤ 0 恒成立。
  • 把「闭区间最值」改成「开区间最值」，注意端点是否取得到。
  • 把「恒成立」改成「存在解」，不等号方向与最值类型要相应调整。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • f'(x₀) = 0 不一定是极值点，例如 y = x³ 在 0 处。
  • 求闭区间最值只比极值，漏掉端点。
  • 忘记先求定义域，单调区间可能写错。
  • 含参数时不做分类讨论，直接默认导数的符号。
