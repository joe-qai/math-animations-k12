知识精讲

概念 · 公式 · 例题
概念

先画一个大正方形

边长为 a + b 的正方形，面积就是 (a + b)²。这是公式的左边，也是我们要求的那块面积。

在大正方形里，切出一个边长 a 的正方形和一个边长 b 的正方形。

公式

面积分块相加

除了两个正方形，剩下的部分是两块长 a、宽 b 的长方形，每块面积 ab，一共 2ab。

四块拼起来就是整个大正方形，所以 (a + b)² = a² + 2ab + b²。

(a + b)² = a² + 2ab + b²

例题

代入数字验证

取 a = 3、b = 2：(3 + 2)² = 5² = 25。

用公式展开：3² + 2 × 3 × 2 + 2² = 9 + 12 + 4 = 25。两边一致。

如果错写成 a² + b²，就只有 9 + 4 = 13，少了整整 12。

概念

减法的版本

把 b 换成 −b，就得到 (a − b)² = a² − 2ab + b²。中间项变成减号。

记忆口诀：首平方，尾平方，首尾二倍放中央；符号看中间。

一句话记住

完全平方公式不是背出来的，而是一块正方形的面积账：(a + b)² = a² + 2ab + b²，中间那 2ab 就是两块长方形。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 把 (a + b)² 写成 a² + b²，漏掉中间项 2ab。
  • (a − b)² 的中间项是 −2ab，不是 +2ab。
  • 公式里的 a、b 可以是数、字母或整式，别只当成单个字母。
