数量积与坐标运算

点乘出数，垂直为零

数量积 a·b = |a||b|cosθ，结果是一个数，不是向量。它把「夹角」和「长度」装进同一个式子：垂直等价于点积为零，求模用 a·a，求夹角用 cosθ。坐标形式下，点积就是对应坐标相乘再相加。

核心公式
数量积 = 模乘余弦
01

知识精讲

概念 · 公式 · 例题
公式

数量积的定义

已知两个非零向量 a、b，它们的夹角为 θ，规定 a·b = |a||b|cosθ。

θ 的取值范围是 0° 到 180°；a·b 是一个实数，可正、可负、可为零。

几何意义：a·b 等于 a 的模乘以 b 在 a 方向上的投影。

当 θ = 90° 时 cosθ = 0，所以 a⊥b 等价于 a·b = 0。

a·b = |a||b|cosθ

公式

坐标形式

设 a = (x₁, y₁)，b = (x₂, y₂)，则 a·b = x₁x₂ + y₁y₂。

由此得到模长 |a| = √(x₁² + y₁²)，因为 a·a = |a|²。

夹角余弦 cosθ = (x₁x₂ + y₁y₂) / (√(x₁²+y₁²) · √(x₂²+y₂²))。

垂直条件 x₁x₂ + y₁y₂ = 0；共线条件 x₁y₂ − x₂y₁ = 0。两个条件不要混。

a·b = x₁x₂ + y₁y₂

例题

例 1：坐标点积

已知 a = (3, 4)，b = (1, 2)，求 a·b 与 |a|。

a·b = 3 × 1 + 4 × 2 = 3 + 8 = 11。

|a| = √(3² + 4²) = √25 = 5。

若还要求夹角，先算 |b| = √5，再代入 cosθ = 11 / (5√5)。

a·b = 11，|a| = 5

例题

例 2：垂直求参数

已知 a = (1, 2)，b = (2, m)，且 a⊥b，求 m。

垂直等价于点积为零：1 × 2 + 2 × m = 0。

解得 2 + 2m = 0，m = −1。

检验：a·b = 2 − 2 = 0，确实垂直。

1·2 + 2·m = 0

概念

模与夹角

求模优先用平方：|a + b|² = (a + b)·(a + b) = |a|² + 2a·b + |b|²。

求夹角先算点积，再算两个模，最后取反余弦；注意夹角范围是 0° 到 180°。

点积为正，夹角是锐角；点积为负，夹角是钝角；点积为零，两向量垂直。

投影是一个数，可正可负，等于 |b|cosθ，不要与投影向量混淆。

|a + b|² = |a|² + 2a·b + |b|²

一句话记住

点积出数：模乘余弦；坐标对应相乘再相加；垂直看零，求模先平方。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「a⊥b」改成「a 与 b 的夹角为钝角」，条件变成 a·b < 0 且两向量不共线。
  • 求 |a + b| 时先平方，再代点积，避免直接求坐标。
  • 已知 |a|、|b| 与夹角，求 (a + b)·(a − b)，展开后等于 |a|² − |b|²。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 数量积的结果是数，不是向量，不能写成 a·b = (x, y)。
  • a·b = 0 包含零向量的情况，判断垂直时要说明两向量非零。
  • 夹角范围是 0° 到 180°，不要写成 0° 到 360°。
  • 求 |a + b| 忘记先平方，直接把模相加是错的。
