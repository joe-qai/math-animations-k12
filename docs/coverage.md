## 六、学习路径（关键依赖链）

补课不能按教材顺序拍，要按依赖链走。四条主干：

```
代数主干：X14 分数 → X22 简易方程 → C01/C02 有理数 → C04/C05 整式与幂
        → C07/C08 乘法公式与因式分解 → C15 一元二次方程 → C23 二次函数

几何主干：X27 线角 → X28 三角形 → C28 全等 → C33 相似
        → C34 锐角三角函数 → C35 解直角三角形
        → C39 圆 → C40 切线 → C41 圆中计算

函数主干：C20 函数概念 → C21 一次函数 → C22 反比例 → C23 二次
        → G05/G06 高中函数性质 → G08/G09 指对 → G31/G32 导数

高中几何：G15 向量 → G16 解三角形 / G19 空间向量
        G20 直线 → G21 圆 → G22–G25 圆锥曲线
```

**最容易踩的坑**：直接讲 C23 二次函数，学生因式分解不熟，配方法就卡死；直接讲 C33 相似，全等没学透，比例线段写不出来。前置不补，后面每节都变成"听懂但不会做"。
