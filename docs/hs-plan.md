## 三、顺序理由

1. **先逻辑与不等式**：它们是后面所有证明的语言，也是高考第 1、2 题。
2. **函数一条线走完**（H2+H3）：概念 → 性质 → 幂 → 指对 → 三角，再接零点与模型，避免来回跳。
3. **几何分两步**：先向量与立体几何初步（H4），再空间向量法（H5）——没有 H4 的线面关系，空间向量就是背公式。
4. **圆锥曲线单独成批**（H6）：计算量大，集中做更容易统一「设点、联立、韦达」的套路。
5. **数列与导数压轴**（H7）：导数必须等函数性质（H2）讲完。
6. **计数概率最后**（H8）：独立性强，放最后不影响别的链条。
