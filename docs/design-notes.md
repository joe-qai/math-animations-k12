# 动画设计理念

## 一、为什么要用动画教数学？

传统教法：先给公式 → 让学生背诵 → 做题验证
动画教法：先建立直觉 → 看到规律 → 公式自然浮现

**关键区别：**
- 背诵记住的是符号（"三七二十一"）
- 动画理解的是结构（"7 个 3 排成矩形，面积是 21"）

符号会在忘记后丢失，结构记忆会伴随迁移能力。

## 二、每个动画解决的核心问题

### 九九乘法表
- **传统痛点**：81 条口诀死记硬背，忘了就卡住
- **动画方案**：对称性折叠（只背一半）+ 点阵生长（理解本质）
- **认知突破**：乘法 = 重复加法 = 矩形面积，三个表征自由切换

### 竖式加减法
- **传统痛点**："进位""借位"是空洞术语，学生不知道为什么
- **动画方案**：个位满 10 自动打包成十位，视觉上可追踪
- **认知突破**：进位不是规则，是"10 个一换 1 个十"的自然结果

### 勾股定理
- **传统痛点**：a²+b²=c² 背了但不知道是什么意思
- **动画方案**：三个正方形用颜色填充，小方块拼成大方块
- **认知突破**：面积守恒，不是公式是拼图

## 三、动画设计通用模板

```
Phase 1: 直观呈现（3-5秒）
  → 展示当前状态，不加解释

Phase 2: 动态展开（5-10秒）
  → 逐步变化，每步有视觉提示（高亮/箭头/数字）
  → 关键帧暂停，让学生跟上

Phase 3: 规律总结（2-3秒）
  → 显示结论，与动画直接对应
  → 不额外添加文字，让动画本身说话

Phase 4: 交互探索（无限）
  → 学生可以改参数，重播，暂停在任何帧
```

## 四、音效设计原则

- 每个点的出现配不同音高（C-D-E-F-G...）
- 进位/借位时有特殊音效（"叮"）
- 完成时有一段和弦
- 所有音效可静音（提供开关）

## 五、可扩展方向

| 主题 | 核心动画 | 认知突破点 |
|------|---------|----------|
| 分数 | 圆形/条形分割动画 | 1/2 就是"整体的一半" |
| 小数 | 数轴放大动画 | 0.1 是"把1分成10份取1份" |
| 面积公式 | 图形割补动画 | 长方形面积 = 拼出来的格子数 |
| 周长 | 线段展开动画 | 周长 = 绕一圈的长度 |
| 方程 | 天平动画 | 等号 = 天平平衡 |
| 百分比 | 100格网格填充 | 百分就是"每100份中的几份" |
