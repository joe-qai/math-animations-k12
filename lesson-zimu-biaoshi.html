知识精讲

概念 · 公式 · 例题
概念

字母表示数

数学里，可以用字母表示一个还不知道的数，也可以表示任意一个数。正方形边长记作 a，周长就是 4a，面积就是 a²。

字母还能表示两个量之间的关系：小明 n 岁，妈妈比他大 26 岁，妈妈就是 (n + 26) 岁。n 变，妈妈的年龄跟着变，但「大 26 岁」这个关系不变。

公式

用字母写定律和公式

加法交换律：a + b = b + a；加法结合律：(a + b) + c = a + (b + c)。

长方形面积 S = ab，正方形周长 C = 4a，长方形周长 C = 2(a + b)。字母写起来短，规律却一点没少。

S = ab

概念

四个书写规矩

字母与字母相乘，乘号可以省略：a × b 写成 ab。数与字母相乘，数字写在前面：3 × a 写成 3a。1 与字母相乘，1 不写：1 × a 就是 a。

相同的字母相乘，写成平方：a × a 写成 a²，读作 a 的平方。注意 4a 仍然表示 4 × a，只是乘号省略了。

例题

代入求值

当 a = 5 时，4a = 4 × 5 = 20；a² = 5 × 5 = 25。代入时要把省略的乘号补回来再算。

a² 表示两个 a 相乘，不是 a 乘 2；a + a 才等于 2a。这三个式子是四年级最容易混的地方。

例题

例 2：用字母写公式，再代入求值

长方形的长是 a、宽是 b，周长就是两条长加两条宽：C = 2(a + b)。

当 a = 5、b = 3 时，先算括号：a + b = 8。

再乘 2：C = 2 × 8 = 16。

字母式先写清楚关系，再代入数值，比直接列算式更不容易漏项。

C = 2(a + b) = 2 × 8 = 16

一句话记住

字母可以表示任何数，也可以表示数量关系。写的时候：乘号可省略、数字写在字母前、1 不写、相同字母相乘写平方。a² 是 a × a，不是 2a；a + a 才是 2a。代入求值要把省略的乘号补回来。

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「a²」改成「2a」，带 a = 5 分别算，比较 25 和 10。
  • 把「妈妈比小明大 26 岁」改成「爸爸比小明大 30 岁」，写出式子再代入。
  • 用字母表示长方形周长 2(a + b)，再代入具体数求值。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 把 a² 当成 2a：a² = a × a，a = 5 时是 25，不是 10。
  • 把 a + a 写成 a²：相加得 2a，相乘才得 a²。
  • 把 3a 读成 3 + a：3a 表示 3 × a。
  • 数字写在字母后面：应写 3a，不写 a3。
  • 代入时忘记补乘号：4a 代 a = 5，要算 4 × 5，不是 45。
