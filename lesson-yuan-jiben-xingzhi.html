圆的基本性质

弦、弧、垂径定理与圆周角

车轮、井盖、水面荡开的波纹，都是圆。这一节先把圆里的名字认清楚：圆心 O、半径 r、弦、直径（最长的弦）、弧（优弧与劣弧）。接着用圆的轴对称性得到垂径定理——垂直于弦的直径平分这条弦，并且平分弦所对的两条弧；再把它变成最好用的计算模型：半径、半弦、弦心距正好组成直角三角形，r² = (a/2)² + d²。后半节讲角：同圆或等圆中，相等的圆心角所对的弧相等、弦也相等；一条弧所对的圆周角等于它所对圆心角的一半，于是有「直径所对的圆周角是直角」和「同弧所对的圆周角相等」两个推论；最后是圆内接四边形对角互补。

知识精讲

概念 · 公式 · 例题
概念

圆里的名字

圆是平面内到定点的距离等于定长的所有点组成的图形。定点叫圆心，记作 O；定长叫半径，记作 r。

连接圆上任意两点的线段叫弦，经过圆心的弦叫直径，直径是最长的弦，且 d = 2r。圆上两点之间的部分叫弧，大于半圆的叫优弧，小于半圆的叫劣弧。

直径 = 2 × 半径

公式

垂径定理

垂直于弦的直径平分这条弦，并且平分弦所对的两条弧。

注意两个条件：必须是直径，必须垂直于弦。只说「垂直」或只说「过圆心」都不够。

直径 ⊥ 弦 → 平分弦与弧

公式

垂径定理的计算模型

半径 r、弦长的一半 a/2、圆心到弦的距离 d（弦心距），三条线段正好组成直角三角形。

例：弦长 a = 8，半径 r = 5，则 a/2 = 4，d² = 5² − 4² = 9，d = 3。

r² = (a/2)² + d²

概念

圆心角、弧、弦

顶点在圆心的角叫圆心角。在同圆或等圆中，相等的圆心角所对的弧相等，所对的弦也相等。

反过来也成立：相等的弧或相等的弦，所对的圆心角相等。这是证明弧相等、弦相等最常用的依据。

同圆中圆心角、弧、弦一一对应

公式

圆周角定理

顶点在圆上、两边都与圆相交的角叫圆周角。一条弧所对的圆周角，等于它所对圆心角的一半。

两个常用推论：① 直径所对的圆周角是直角；② 同一条弧所对的圆周角都相等。

∠ACB = ½ ∠AOB

概念

圆内接四边形

四个顶点都在同一个圆上的四边形叫圆内接四边形，它的对角互补。

即 ∠A + ∠C = 180°，∠B + ∠D = 180°。因为每组对角所对的弧合起来是整个圆，圆心角之和是 360°，圆周角就是一半。

∠A + ∠C = 180°

一句话记住

圆是到圆心距离等于半径的所有点。弦是连接圆上两点的线段，直径是过圆心的弦、也是最长的一条，长度是半径的两倍；圆上两点之间的部分叫弧，大于半圆是优弧、小于半圆是劣弧。垂径定理是这一节的核心：垂直于弦的直径平分弦，也平分弦所对的两条弧，用的时候「直径」和「垂直」两个条件缺一不可。做题时把它变成直角三角形：半径、半弦、弦心距满足 r² = (a/2)² + d²。再看角：同圆或等圆中，相等的圆心角所对的弧相等、弦也相等；一条弧所对的圆周角等于圆心角的一半，于是直径所对的圆周角是直角、同弧所对的圆周角相等。最后记住圆内接四边形对角互补，是「对角」，不是「对边」。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 把弦和直径混为一谈：直径是经过圆心的弦，是最长的弦。
  • 用垂径定理时漏条件：必须「直径垂直于弦」，两个条件缺一不可。
  • 圆周角和圆心角没有对同一条弧就套一半的关系。
  • 圆内接四边形记成「对边互补」，正确说法是对角互补。
  • 算出弦心距后忘了它可能是两条（圆心两侧各一条弦）。
