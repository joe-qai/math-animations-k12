函数与方程、不等式的图像

交点即解，上下即大小

两家快递的收费画成两条直线，交点就是收费相同的地方，交点左边乙便宜、右边甲便宜——方程和不等式的问题，很多时候画成图像一眼就能看出来。这一节把「数」和「形」连起来：一次函数与 x 轴交点的横坐标就是方程 kx + b = 0 的解，图像在 x 轴上方还是下方对应不等式的解集；抛物线与 x 轴的交点个数由判别式决定，交点横坐标就是方程的根；二次不等式的解集看图像在轴上方还是下方，「大于取两边，小于取中间」。最后用 y = x² − 2x − 3 完整读一遍图像。

知识精讲

概念 · 公式 · 例题
概念

方程的解就是交点

一次函数 y = kx + b 的图像是一条直线。令 y = 0，方程 kx + b = 0 的解就是直线与 x 轴交点的横坐标；令 y = m，解就是直线与水平线 y = m 交点的横坐标。

所以解方程，本质上是在图像上找交点，交点的横坐标就是解。

kx + b = 0 ↔ 与 x 轴交点

概念

不等式看上下

kx + b > 0 就是图像在 x 轴上方的部分，对应的 x 范围就是解集；kx + b < 0 就是 x 轴下方那一段。

比较两个函数的大小，看同一处谁的图像在上：在上面的函数值大，在下面的函数值小。

上方 → 函数值大

公式

抛物线与 x 轴

抛物线 y = ax² + bx + c 与 x 轴的交点，就是方程 ax² + bx + c = 0 的根。

判别式 Δ > 0 有两个交点（两个不等实根），Δ = 0 有一个交点（两个相等实根），Δ < 0 没有交点（没有实数根）。

Δ = b² − 4ac

概念

二次不等式的口诀

开口向上时，大于 0 取两边，小于 0 取中间；开口向下时正好相反。

所以做题第一步一定先看开口方向，再读图像在 x 轴上方的部分还是下方的部分。

大于取两边，小于取中间

例题

例：读 y = x² − 2x − 3 的图像

令 y = 0，得 (x − 3)(x + 1) = 0，所以抛物线与 x 轴交于 −1 和 3，开口向上。

x < −1 或 x > 3 时图像在 x 轴上方，即 x² − 2x − 3 > 0；−1 < x < 3 时图像在下方，即 x² − 2x − 3 < 0。

x² − 2x − 3 > 0 ⇔ x < −1 或 x > 3

例题

例：两函数比大小

两条直线交于 x = 4：交点左边乙的图像在下，乙更便宜；交点右边甲的图像在下，甲更便宜。

求「甲比乙便宜」的范围，就是求甲的函数值小于乙的函数值时 x 的范围，看图像即可直接读出。

交点左边：乙低；右边：甲低

一句话记住

数形结合的核心只有两句话：方程的解是图像与 x 轴交点的横坐标，不等式看图像在 x 轴上方还是下方。一次函数 y = kx + b 与 x 轴交点的横坐标就是 kx + b = 0 的解；kx + b > 0 对应图像在 x 轴上方的部分。抛物线与 x 轴的交点个数由判别式决定：Δ > 0 两个、Δ = 0 一个、Δ < 0 没有。二次不等式开口向上时「大于取两边，小于取中间」，开口向下正好相反。比较两个函数的大小，就看同一处谁的图像在上。做题顺序永远是：先画图，再找交点，最后读范围，端点取不取要用空心或实心标清楚。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 把交点的横坐标和纵坐标搞混：方程的解是横坐标，不是纵坐标。
  • 解二次不等式不看开口方向：开口向下时口诀正好相反。
  • 端点取不取搞不清：大于 0、小于 0 不含等号，端点画空心；大于等于、小于等于含端点。
  • 只算不画：算完范围不回图像上核对，符号写反也不知道。
  • 把「Δ < 0」说成没有解：方程没有实数根，但不等式仍然可能有解集。
