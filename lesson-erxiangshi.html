二项式定理

二项展开看通项

二项式定理给出 (a+b)ⁿ 的完整展开：共有 n+1 项，每一项的系数是组合数 C(n,k)，a 的指数从 n 降到 0，b 的指数从 0 升到 n。求特定项、常数项、系数和，都从通项公式出发。

01

知识精讲

概念 · 公式 · 例题
公式

二项式定理

(a+b)ⁿ = C(n,0)aⁿ + C(n,1)aⁿ⁻¹b + … + C(n,n)bⁿ。

展开式共有 n+1 项，a 的指数从 n 递减到 0，b 的指数从 0 递增到 n。

每一项中 a 与 b 的指数之和都等于 n。

二项式系数是 C(n,k)，与 a、b 的具体取值无关。

(a+b)ⁿ = Σ C(n,k)aⁿ⁻ᵏbᵏ

公式

通项公式

第 k+1 项 T(k+1) = C(n,k) aⁿ⁻ᵏ bᵏ，注意下标从 0 开始。

求指定次数的项，先设通项，再令指数等于目标值，解出 k。

求常数项，令所有含变量的指数之和为 0。

求出 k 后要检查是否为 0 到 n 的整数，否则该项不存在。

T(k+1) = C(n,k)aⁿ⁻ᵏbᵏ

例题

例 1：求指定项系数

求 (x + 2)⁵ 展开式中 x³ 的系数。

通项 T(k+1) = C(5,k) x⁵⁻ᵏ 2ᵏ。

令 5 − k = 3，得 k = 2。

系数为 C(5,2) × 2² = 10 × 4 = 40。

系数 = 40

公式

系数和

令 a = b = 1，得各项系数之和为 2ⁿ。

令 a = 1、b = −1，得奇数项系数和减偶数项系数和。

求「所有项系数和」时，把变量全部换成 1。

注意区分「二项式系数和」2ⁿ 与「项的系数和」，后者要把常数因子算进去。

系数和 = f(1)

例题

例 2：赋值法

求 (2x + 1)⁵ 展开式各项系数之和。

把 x 换成 1，得 (2×1 + 1)⁵ = 3⁵ = 243。

若求二项式系数之和，则是 2⁵ = 32。

两个结果不同，因为项的系数还包含 2ᵏ 因子。

3⁵ = 243

一句话记住

展开 n+1 项，通项 C(n,k)aⁿ⁻ᵏbᵏ；求项看指数，求和令 x=1。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「求 x³ 的系数」改成「求常数项」，令变量指数为 0。
  • 把「(x+2)⁵」改成「(2x−1)⁵」，注意负号与常数因子的幂。
  • 把「系数和」改成「奇数项系数和」，用 f(1) 与 f(−1) 联立。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 通项下标从 0 开始，T(k+1) 对应 b 的指数 k，容易错一位。
  • 二项式系数 C(n,k) 与项的系数不是一回事，后者含常数因子。
  • 求常数项时忘记把常数因子的幂算进去。
  • 赋值法只能求整体和，求某一项仍需通项。
