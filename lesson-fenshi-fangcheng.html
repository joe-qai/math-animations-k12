分式方程

解完必须检验

分母里出现未知数，方程就变成了分式方程。解法很直接：两边同乘最简公分母，把分母消掉，化成整式方程再解。麻烦在于这一步有陷阱——同乘的那个式子如果恰好等于零，就会凭空多出一个「根」，叫增根。所以解分式方程的流程是三件事，而不是两件：去分母、解整式方程、检验。少了最后一步，答案可能就是错的。

概念 · 公式 · 例题
概念

什么是分式方程

分母中含有未知数的方程叫分式方程。例如 2/x = 3、(x + 1)/(x − 1) = 2。它和整式方程的唯一区别，就是未知数跑到了分母里。

动手之前先圈出不能取的值：让每个分母等于零的 x 都不能当答案。2/x = 3 要求 x ≠ 0；(x + 1)/(x − 1) = 2 要求 x ≠ 1。

公式

解法：去分母

两边同乘最简公分母，把所有分母消掉，化成整式方程，再按整式方程的办法解。例如 2/x = 3，两边同乘 x 得 2 = 3x，所以 x = 2/3。

整个流程有三步：① 去分母；② 解整式方程；③ 检验。第三步最容易漏，也最不能漏。

两边同乘最简公分母

公式

增根与检验

去分母时两边同乘的是一个整式，它有可能等于零。零乘任何数都得零，等式两边会同时变成 0，原来不成立的式子也可能变得「成立」，于是凭空多出一个根，这个根叫增根。

所以必须检验：把解出来的 x 代回最简公分母（或原方程的各个分母）。公分母为 0，这个解就是增根，必须舍去；公分母不为 0，才是原方程的根。

如果唯一的解是增根，那原方程就无解——这不是算错了，而是本来就没有解。

公分母 = 0 → 增根，舍去

例题

无解的例子

解 1/(x − 1) = 2/(x² − 1)。右边分母分解为 (x + 1)(x − 1)，最简公分母是 (x + 1)(x − 1)。

两边同乘它，左边得 x + 1，右边得 2，于是 x + 1 = 2，x = 1。检验：x = 1 时 x − 1 = 0，公分母为零，是增根，舍去。所以原方程无解。

1/(x−1) = 2/(x²−1) → 无解

例题

应用题：工程问题

甲单独做 x 天完成，乙单独做 x + 3 天完成，两人合作 2 天完成。把总工作量看作 1，甲每天做 1/x，乙每天做 1/(x+3)，列方程 2/x + 2/(x+3) = 1。

去分母得 2(x + 3) + 2x = x(x + 3)，整理成 x² − x − 6 = 0，因式分解 (x − 3)(x + 2) = 0，得 x = 3 或 x = −2。天数是正数，x = −2 舍去；再检验 x = 3 分母不为零，所以 x = 3。列方程的关键是弄清谁做了多少、总量是多少。

一句话记住

分母中含未知数的方程叫分式方程。解法是两边同乘最简公分母，化成整式方程再解，然后必须检验：把解代回最简公分母，为零则是增根、要舍去，不为零才是原方程的根。增根来自去分母时乘了可能为零的整式，所以检验不是可选项。若唯一的解是增根，原方程无解。应用题要注意根是否符合实际意义（天数、长度不能为负），最后仍要检验。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 解完不检验，把增根当成答案写上去。
  • 去分母时漏乘不含分母的项，只乘了有分母的那几项。
  • 检验时只算自己乘的那个式子，没有代回原方程的分母。
  • 应用题解出两个根就都写上，忘了天数、速度这类量不能为负，也没检验。
  • 把「解出增根」误判为算错，其实是原方程无解。
