数列的概念与通项

通项看 aₙ，和看 Sₙ

数列是按顺序排好的一列数，本质是定义在正整数集上的函数。通项公式给出第 n 项，前 n 项和 Sₙ 与 aₙ 之间可以互推。由递推式求通项，常用累加、累乘和构造等比数列三种方法。

知识精讲

概念 · 公式 · 例题
概念

数列是什么

按一定顺序排列的一列数叫数列，第 n 项记作 aₙ。

通项公式 aₙ = f(n) 把项数与项对应起来，相当于定义域为正整数的函数。

数列可以递增、递减、摆动或常数，判断单调性可以比较 aₙ₊₁ 与 aₙ。

aₙ 与 Sₙ 是两套语言，题目给谁就用谁。

aₙ = f(n)，n ∈ N*

公式

aₙ 与 Sₙ

Sₙ = a₁ + a₂ + … + aₙ。

当 n ≥ 2 时，aₙ = Sₙ − Sₙ₋₁；当 n = 1 时，a₁ = S₁。

先由 Sₙ − Sₙ₋₁ 求出 n ≥ 2 的表达式，再单独验证 n = 1 是否适用。

若 n = 1 也满足，就合并写成一个通项；否则要分段写。

aₙ = Sₙ − Sₙ₋₁（n ≥ 2）

例题

例 1：由 Sₙ 求 aₙ

已知 Sₙ = n² + n，求通项 aₙ。

当 n ≥ 2 时，aₙ = Sₙ − Sₙ₋₁ = (n²+n) − [(n−1)²+(n−1)] = 2n。

当 n = 1 时，a₁ = S₁ = 2，也满足 2n。

所以 aₙ = 2n。

aₙ = 2n

例题

例 2：累加法

已知 a₁ = 1，aₙ₊₁ − aₙ = 2n，求 aₙ。

把 n 从 1 到 n−1 的等式相加：aₙ − a₁ = 2(1+2+…+n−1) = n(n−1)。

所以 aₙ = n(n−1) + 1 = n² − n + 1。

验证 n = 1：1 − 1 + 1 = 1，与 a₁ 一致。

aₙ = n² − n + 1

概念

累乘与构造

若 aₙ₊₁/aₙ = f(n)，把 n 从 1 到 n−1 的等式相乘，叫累乘法。

若 aₙ₊₁ = paₙ + q（p ≠ 1），可以构造 aₙ₊₁ + t = p(aₙ + t)，转成等比数列。

构造时令 t = q/(p−1)，再求等比数列的通项。

所有方法都要回到 n = 1 检验，递推式只对 n ≥ 1 的某些值成立。

aₙ₊₁ + t = p(aₙ + t)

一句话记住

通项与和互推：n ≥ 2 作差，n = 1 单独验；差用累加，比用累乘。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「由 Sₙ 求 aₙ」改成「由 aₙ 求 Sₙ」，直接对通项求和。
  • 把「累加」改成「累乘」，条件由差变成比。
  • 把「aₙ₊₁ = paₙ + q」改成「aₙ₊₁ = paₙ + qⁿ」，两边同除 qⁿ⁺¹ 构造。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 用 aₙ = Sₙ − Sₙ₋₁ 时忘记注明 n ≥ 2。
  • n = 1 不验证，导致通项在首项处不成立。
  • 累加法相加的项数容易多算一项或少算一项。
  • 构造等比数列时 t 的符号算错，回代检验最稳妥。
