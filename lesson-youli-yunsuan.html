公式

加法法则

同号两数相加，取相同的符号，再把绝对值相加；异号两数相加，取绝对值较大的加数的符号，再用较大的绝对值减去较小的绝对值；互为相反数的两个数相加得 0。

口诀：先定符号，再算绝对值。例如 (-3) + (-5) = -8，(-3) + 5 = 2，3 + (-3) = 0。

先定符号，再算绝对值

公式

减法转加法

减去一个数，等于加上它的相反数：a - b = a + (-b)。减号变加号，同时减数变相反数。

3 - (-5) = 3 + 5 = 8；-2 - 3 = -2 + (-3) = -5。减法一律先改成加法，再按加法法则算。

a - b = a + (-b)

概念

乘除的符号规律

两数相乘或相除，同号得正，异号得负，再把绝对值相乘或相除。任何数乘 0 都得 0。

多个因数相乘，先数负号的个数：奇数个负号结果为负，偶数个负号结果为正。除法可以换成乘法：除以一个数，等于乘它的倒数。0 不能作除数。

例题

乘方与混合运算

乘方是求几个相同因数的积：2³ = 2 × 2 × 2 = 8。负数的偶次幂为正，奇次幂为负。(-2)² = 4，而 -2² = -(2²) = -4，括号管着负号。

混合运算顺序：先乘方，再乘除，最后加减；有括号先算括号里的。例如 -2² + (-3) × 2 = -4 - 6 = -10。

一句话记住

有理数运算，第一步永远是定符号。加法：同号取相同符号、绝对值相加，异号取绝对值大的符号、大减小。减法先转成加法。乘除：同号得正，异号得负；多个因数看负号个数的奇偶。乘方注意括号，(-2)² 与 -2² 不同。混合运算按「先乘方，再乘除，最后加减」的顺序来。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 减法忘记转成加法，直接把减数当加数。
  • 异号相加时忘了先比较绝对值大小，符号取错。
  • 多个因数相乘时数错负号个数，符号判断反了。
  • 把 -2² 当成 (-2)²，一个等于 -4，一个等于 4。
  • 混合运算跳步，先算了加减，忘了先乘方。
