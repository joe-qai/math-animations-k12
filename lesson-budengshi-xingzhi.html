不等式的性质

乘负数要变号

跷跷板两边同时加上同样重的东西，倾斜方向不变；同时乘一个正数，方向也不变；但乘负数，方向就要反过来。不等式就是这样：a > b 时，两边同加同减同一个数，不等号不变；同乘一个正数也不变，同乘一个负数必须变号。还有两条常用结论：同向不等式可以相加，同向的正数不等式可以相乘。每次变形前先问一句：我乘或除的这个数是正还是负？

知识精讲

概念 · 公式 · 例题
概念

比较大小的依据

判断 a 与 b 的大小，就看它们的差：a − b > 0 则 a > b。

差等于 0 则 a = b，差小于 0 则 a < b。

所以证明不等式，常转化为判断差的符号。

a − b > 0 ⇔ a > b

公式

同加同减

不等式两边同时加上或减去同一个数，不等号方向不变。

a > b ⇒ a + c > b + c，a − c > b − c。

这就像天平两边同时加同样的砝码，谁重谁轻不变。

a > b ⇒ a ± c > b ± c

公式

乘除正数不变号

不等式两边同时乘或除以同一个正数，不等号方向不变。

a > b，c > 0 ⇒ ac > bc。

例如 3 > 2，两边乘 5 得 15 > 10，方向没变。

a > b，c > 0 ⇒ ac > bc

公式

乘除负数要变号

两边同时乘或除以同一个负数，不等号方向要反过来。

a > b，c < 0 ⇒ ac < bc。

例如 3 > 2，两边乘 −1 得 −3 < −2，方向反了。

这是最容易错的一步，做题时先看清乘的是正是负。

a > b，c < 0 ⇒ ac < bc

公式

同向可加、正数可乘

两个同向不等式可以相加：a > b，c > d ⇒ a + c > b + d。

两个同向且都是正数的不等式可以相乘：a > b > 0，c > d > 0 ⇒ ac > bd。

但同向不等式不能直接相减，也不能随便相除。

a > b，c > d ⇒ a + c > b + d

一句话记住

不等式的基本性质来自「看差」：a − b > 0 就是 a > b。两边同加同减不变号；同乘同除正数不变号，乘除负数必须变号。同向不等式可以相加，同向正数不等式可以相乘，但不能直接相减。变形前先问一句：这个数是正还是负？

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 乘负数忘记变号：这是不等式变形里最高频的错。
  • 同向不等式直接相减：a > b、c > d 推不出 a − c > b − d。
  • 乘含字母的式子不讨论正负：不知道正负就不能直接乘。
  • 取倒数不变号：同号两数取倒数，大小关系要反过来。
