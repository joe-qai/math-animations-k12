数列求和

错位相减，裂项相消

数列求和先看通项的结构：等差、等比用公式；等差乘等比用错位相减；分式且分母是相邻两项乘积用裂项相消；项数有规律可以分组。方法选对，计算量会小一个数量级。

01

知识精讲

概念 · 公式 · 例题
公式

公式法

等差数列：Sₙ = n(a₁ + aₙ)/2 = na₁ + n(n−1)d/2。

等比数列：q = 1 时 Sₙ = na₁；q ≠ 1 时 Sₙ = a₁(1 − qⁿ)/(1 − q)。

1 + 2 + … + n = n(n+1)/2，1² + 2² + … + n² = n(n+1)(2n+1)/6。

先判断通项是等差、等比还是它们的组合，再选公式。

Sₙ = n(a₁+aₙ)/2

公式

错位相减

形如 (an + b)qⁿ 的通项，用错位相减：写出 Sₙ，再乘 q 得 qSₙ。

两式相减，中间部分变成等比数列，最后解出 Sₙ。

相减时注意对齐，尤其是最后一项和常数项。

q = 1 时退化为等差求和，可直接用公式。

Sₙ − qSₙ

公式

裂项相消

1/[n(n+1)] = 1/n − 1/(n+1)。

1/[(2n−1)(2n+1)] = 1/2 [1/(2n−1) − 1/(2n+1)]，系数 1/2 不能漏。

裂项后相加，中间项两两相消，只剩首尾少数几项。

写答案前数清剩下哪些项，避免多写或少写。

1/[n(n+1)] = 1/n − 1/(n+1)

例题

例 1：裂项求和

求 1/(1×2) + 1/(2×3) + … + 1/[n(n+1)]。

每一项裂成 1/k − 1/(k+1)。

相加后中间项全部抵消，只剩 1 − 1/(n+1)。

所以和为 n/(n+1)。

Sₙ = n/(n+1)

例题

例 2：错位相减

求 Sₙ = 1×2 + 2×2² + 3×2³ + … + n×2ⁿ。

写出 Sₙ，再乘 2 得 2Sₙ = 1×2² + 2×2³ + … + n×2ⁿ⁺¹。

两式相减：−Sₙ = 2 + 2² + … + 2ⁿ − n×2ⁿ⁺¹。

化简得 Sₙ = (n−1)2ⁿ⁺¹ + 2。

Sₙ = (n−1)2ⁿ⁺¹ + 2

一句话记住

先看通项结构：等差等比套公式，等差乘等比错位减，分式裂项，复杂就分组。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「等差乘等比」改成「等差除以等比」，先乘公比再错位。
  • 把「1/[n(n+1)]」改成「1/[n(n+2)]」，裂项后系数变为 1/2。
  • 把「从 1 开始」改成「从 2 开始」，注意首项与剩余项。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 裂项时系数漏掉，例如 1/[(2n−1)(2n+1)] 前面要乘 1/2。
  • 错位相减对齐错位，导致中间等比项数算错。
  • 等比求和忘记讨论 q = 1。
  • 裂项相消后剩余项数数错，尤其是首尾各剩几项。
