抛物线

到焦点与准线等距

抛物线是到焦点和准线距离相等的点的轨迹。标准方程 y² = 2px 中，p 是焦点到准线的距离，焦点是 (p/2, 0)，准线是 x = −p/2。做题时把「到焦点的距离」换成「到准线的距离」，往往一步就能化简。

01

知识精讲

概念 · 公式 · 例题
概念

定义与 p

平面内到定点 F 与定直线 l 距离相等的点的轨迹叫抛物线，F 叫焦点，l 叫准线。

焦点到准线的距离记作 p，p 一定大于 0。

定义中的「距离相等」是解题的核心，遇到焦半径先想准线。

定点不能在定直线上，否则轨迹退化为过定点且垂直于定直线的直线。

|PF| = d(P, l)

公式

四种标准方程

y² = 2px：焦点 (p/2, 0)，准线 x = −p/2，开口向右。

y² = −2px：焦点 (−p/2, 0)，准线 x = p/2，开口向左。

x² = 2py：焦点 (0, p/2)，准线 y = −p/2，开口向上。

x² = −2py：焦点 (0, −p/2)，准线 y = p/2，开口向下。

y² = 2px

例题

例 1：读焦点与准线

抛物线 y² = 8x，求 p、焦点坐标与准线方程。

对比 y² = 2px，得 2p = 8，所以 p = 4。

焦点为 (p/2, 0) = (2, 0)。

准线为 x = −p/2 = −2。

焦点 (2, 0)，准线 x = −2

公式

焦半径

对于 y² = 2px 上一点 P(x₀, y₀)，焦半径 |PF| = x₀ + p/2。

这个公式来自「到焦点的距离等于到准线的距离」，准线是 x = −p/2。

焦点弦长 |AB| = x₁ + x₂ + p，常用于求最值。

开口方向不同，焦半径公式中的符号也要相应调整。

|PF| = x₀ + p/2

例题

例 2：用定义转化

抛物线 y² = 4x 上一点 P 到焦点的距离为 3，求 P 的横坐标。

这里 2p = 4，p = 2，准线为 x = −1。

由定义，P 到焦点的距离等于 P 到准线的距离，即 x₀ + 1 = 3。

所以 x₀ = 2。

x₀ + 1 = 3

一句话记住

到焦点与准线等距；y²=2px 的焦点是 (p/2,0)，准线 x=−p/2；焦半径用定义转化。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「开口向右」改成「开口向上」，方程换成 x² = 2py，焦点在 y 轴。
  • 把「求焦半径」改成「求焦点弦长」，用 x₁ + x₂ + p。
  • 把「求最值」改成「到定点与焦点距离之和」，用定义把焦点距离转成准线距离。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 标准方程中是 2p，不是 p；由 y² = 8x 得 p = 4。
  • 四种形式容易混，先看开口方向，再写焦点与准线。
  • 准线符号与焦点相反：焦点在正半轴，准线就在负半轴。
  • 焦半径公式只适用于对应开口方向，不能无条件套 x₀ + p/2。
