直线与方程

一个点和斜率定一条线

直线由「一个点 + 一个方向」确定，斜率就是方向的量化。点斜式、斜截式、一般式只是同一件事的不同写法。两条直线平行看斜率相等，垂直看斜率乘积为 −1；点到直线的距离则用一般式直接代入。

01

知识精讲

概念 · 公式 · 例题
公式

斜率

过两点 P₁(x₁,y₁)、P₂(x₂,y₂) 的直线斜率 k = (y₂ − y₁)/(x₂ − x₁)，要求 x₁ ≠ x₂。

倾斜角 α 的范围是 0° ≤ α < 180°，k = tanα。

当 x₁ = x₂ 时，直线垂直于 x 轴，斜率不存在，不能写成 k = 0。

斜率为正，直线从左往右上升；斜率为负，直线下降。

k = (y₂ − y₁)/(x₂ − x₁)

公式

三种方程

点斜式：y − y₀ = k(x − x₀)，已知一点和斜率时使用。

斜截式：y = kx + b，b 是纵截距。

一般式：Ax + By + C = 0，A、B 不同时为 0，适合统一处理。

截距式 x/a + y/b = 1 要求 a、b 都不为零，注意截距不是距离，可以为负。

y − y₀ = k(x − x₀)

例题

例 1：写直线方程

求过点 (1, 2) 且斜率为 3 的直线方程。

直接代入点斜式：y − 2 = 3(x − 1)。

展开得 y = 3x − 1，也可以写成一般式 3x − y − 1 = 0。

写完代回已知点检验：3×1 − 2 − 1 = 0，成立。

y − 2 = 3(x − 1)

例题

例 2：点到直线距离

求点 (1, 1) 到直线 x + y − 3 = 0 的距离。

距离公式 d = |Ax₀ + By₀ + C| / √(A² + B²)。

代入得 d = |1 + 1 − 3| / √2 = 1/√2 = √2/2。

使用前要把直线化成一般式，系数 A、B、C 对应清楚。

d = |Ax₀ + By₀ + C| / √(A²+B²)

概念

平行与垂直

两条直线斜率都存在时，平行等价于 k₁ = k₂ 且截距不同。

垂直等价于 k₁k₂ = −1；若一条斜率不存在，另一条斜率为 0，也垂直。

含参数问题先讨论斜率是否存在，再比较斜率与截距。

平行时还要排除重合：截距相等就变成同一条直线。

平行 k₁=k₂；垂直 k₁k₂=−1

一句话记住

一点一斜率定直线；平行看斜率相等，垂直看乘积 −1；距离用一般式代入。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「过一点写方程」改成「过两条直线交点写方程」，先联立求交点。
  • 把「求距离」改成「求平行线间距离」，先化成相同系数再用两常数差。
  • 把「垂直」改成「对称」，用垂直加中点两个条件求对称点。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 斜率不存在的情况不能漏，垂直 x 轴的直线没有斜率。
  • k₁k₂ = −1 只在两条直线斜率都存在时成立。
  • 点到直线距离公式中的分子要加绝对值，距离不能为负。
  • 平行时只比较斜率不够，还要确认截距不同，否则两线重合。
