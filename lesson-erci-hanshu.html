二次函数

开口、顶点与最值

喷泉的水柱、投篮的弧线、拱桥的桥洞，弯出来的都是抛物线。这一节从生活里的三条曲线讲起，给出二次函数 y = ax² + bx + c（a ≠ 0）的定义，再一步步拆开它的图像：先看最简单的 y = ax²，弄清开口方向由 a 的符号决定、宽窄由 |a| 决定；再看 y = a(x − h)² + k 的平移规律「左加右减、上加下减」，顶点就是 (h, k)；然后用配方法把一般式化成顶点式，得到对称轴 x = −b/(2a) 与顶点纵坐标；最后用顶点求最值，解决「篱笆围出最大面积」这类应用题。

知识精讲

概念 · 公式 · 例题
概念

二次函数的定义

形如 y = ax² + bx + c（a、b、c 是常数，a ≠ 0）的函数叫二次函数，它的图像是一条抛物线。

a 不能等于零，否则最高次就不是 2，函数就变成一次函数了；b、c 可以等于零。

y = ax² + bx + c（a ≠ 0）

概念

y = ax² 的图像

y = ax² 的图像关于 y 轴对称，顶点在原点。a > 0 开口向上，a < 0 开口向下。

|a| 越大，开口越小、越窄；|a| 越小，开口越大、越平缓。

开口看 a 的符号

公式

顶点式与平移

y = a(x − h)² + k 的顶点是 (h, k)，对称轴是直线 x = h。

平移规律：左右「左加右减」，上下「上加下减」。例：y = (x − 2)² + 3 的顶点是 (2, 3)。

y = a(x − h)² + k

公式

一般式的对称轴与顶点

用配方法可以把一般式化成顶点式。例：y = x² − 4x + 5 = (x² − 4x + 4) + 1 = (x − 2)² + 1，顶点 (2, 1)，对称轴 x = 2。

推广到一般式：对称轴是 x = −b/(2a)，顶点的纵坐标是 (4ac − b²)/(4a)。

x = −b/(2a)

概念

顶点就是最值

a > 0 时开口向上，顶点是最低点，函数有最小值；a < 0 时开口向下，顶点是最高点，函数有最大值。

求最值分两步：先看 a 的符号判断是最大还是最小，再把顶点的纵坐标算出来。

a > 0 有最小值

例题

例：篱笆围出最大面积

用 20 米篱笆靠墙围一个矩形，设宽为 x 米，则长为 20 − 2x 米（靠墙的一边不用篱笆）。

面积 S = x(20 − 2x) = −2x² + 20x = −2(x − 5)² + 50。当 x = 5 时，面积最大，是 50 平方米。

S = −2(x − 5)² + 50

一句话记住

二次函数的一般式是 y = ax² + bx + c（a ≠ 0），图像是一条抛物线。y = ax² 关于 y 轴对称、顶点在原点，a > 0 开口向上、a < 0 开口向下，|a| 越大开口越窄。顶点式 y = a(x − h)² + k 的顶点是 (h, k)，对称轴是 x = h，平移遵循「左加右减、上加下减」。把一般式用配方法化成顶点式，就得到对称轴 x = −b/(2a) 和顶点纵坐标 (4ac − b²)/(4a)。a > 0 时顶点是最低点，函数有最小值；a < 0 时顶点是最高点，有最大值。遇到篱笆围面积、商品定价求利润这类问题，先列出二次函数，再化成顶点式，最值自然就出来了。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • a 忘了不等于 0，把二次函数当成一次函数。
  • 对称轴写成 x = b/(2a)，漏掉负号。
  • 平移方向记反：向右移是括号里减，不是加。
  • 求最值时只看顶点，忘了实际问题的 x 有取值范围。
  • 把顶点纵坐标当成最值本身，没先判断 a 的符号是最大还是最小。
