知识精讲

概念 · 公式 · 例题
概念

数位与十进制

数位从右往左依次是个位、十位、百位、千位、万位。同一个数字写在不同的数位上，表示的大小完全不同。

相邻两个数位之间的进率都是 10：10 个一是 1 个十，10 个十是 1 个百，10 个一千是 1 个万。

例题

读数写数：0 怎么处理

3005 读作三千零五，中间的 0 要读出来；3050 读作三千零五十，末尾的 0 不读。

写数时哪一位上一个单位也没有，就用 0 占位。比如「三千零五」，百位和十位都没有，必须写成 3005，不能写成 305。

公式

比大小：先比位数，再比高位

位数不同，位数多的数大：3865 是四位数，985 是三位数，所以 3865 ＞ 985。

位数相同，就从最高位开始一位一位往下比，哪一位上的数大，那个数就大。5860 和 5840 千位、百位都相同，十位 6 ＞ 4，所以 5860 ＞ 5840。

例题

竖式加减：对齐数位最重要

3865 + 1240：相同数位对齐，从个位加起。个位 5 + 0 = 5；十位 6 + 4 = 10，写 0 向百位进 1；百位 8 + 2 + 1 = 11，写 1 向千位进 1；千位 3 + 1 + 1 = 5。结果是 5105。

验算用减法：5105 − 3865 = 1240，正好等于原来的加数，说明算对了。计算前还可以估算：3865 ≈ 4000，1240 ≈ 1200，和约 5200，实际 5105 离它不远，答案合理。

3865 + 1240 = 5105

一句话记住

大数计算抓住三件事：数位对齐、从个位算起、满十进一不够减借一。算完用相反运算验算，先用估算看答案量级对不对。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 数位没对齐：把 4 位数和 3 位数右对齐时错位，答案就整体偏了。
  • 忘记加进位的 1：百位算 8 + 2 就写 10，漏掉十位进上来的 1。
  • 减法忘记退位：0 减 6 直接写 6，实际要借 1 当 10 再减。
  • 读写出错：三千零五写成 305，中间的 0 被吞掉。
  • 把 0 当成可以省略：480 写成 48，数值差了十倍。
