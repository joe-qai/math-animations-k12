三角恒等变换

余弦相反，正弦相同

15° 不是特殊角，但 45° 减 30° 是，于是可以用两角差的余弦公式把它算出来。和角、差角公式是三角恒等变换的地基：余弦公式中间符号相反，正弦公式中间符号相同。由和角公式令两个角相等，就得到二倍角公式；把 a sinx + b cosx 合成一个正弦，就得到辅助角公式。

知识精讲

概念 · 公式 · 例题
公式

两角差的余弦

cos(α − β) = cosα cosβ + sinα sinβ。

它是所有和差角公式的起点，可以用单位圆上的两点距离推出来。

注意中间是加号：余弦的差角公式里，两个乘积相加。

例：cos15° = cos(45° − 30°) = cos45°cos30° + sin45°sin30°。

cos(α − β) = cosαcosβ + sinαsinβ

公式

和角与差角的正弦

sin(α + β) = sinα cosβ + cosα sinβ。

sin(α − β) = sinα cosβ − cosα sinβ。

正弦公式的中间符号与括号里一致，余弦公式的中间符号与括号里相反。

把 β 换成 −β，就能由和角公式得到差角公式。

sin(α ± β) = sinαcosβ ± cosαsinβ

公式

正切与二倍角

tan(α ± β) = (tanα ± tanβ) / (1 ∓ tanα tanβ)，分母符号与分子相反。

令 β = α 得二倍角：sin2α = 2sinαcosα。

cos2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α。

tan2α = 2tanα / (1 − tan²α)，使用前要确认各角的正切都存在。

sin2α = 2sinαcosα

例题

辅助角公式

a sinx + b cosx = √(a² + b²) sin(x + φ)，其中 tanφ = b/a。

它的作用是把「正弦加余弦」合成一个正弦，方便求最值和周期。

例：sinx + cosx = √2 sin(x + π/4)，最大值是 √2。

合成后周期不变，最值变成 ±√(a² + b²)。

a sinx + b cosx = √(a²+b²) sin(x+φ)

概念

化简求值三步

一看角：把角尽量化成相同或成倍数，比如 2α 与 α。

二看名：统一成正弦余弦，切化弦是最常用的手段。

三看结构：能用平方差、完全平方、辅助角的，优先套公式。

化简的最后目标是：项数最少、次数最低、函数名最少。

看角、看名、看结构

例题

例 2：二倍角选哪个形式

已知 sinα = 3/5，α ∈ (π/2, π)，求 sin2α 与 cos2α。

先求 cosα：α 在第二象限，cosα = −√(1 − 9/25) = −4/5。

sin2α = 2sinαcosα = 2 × (3/5) × (−4/5) = −24/25。

cos2α = 1 − 2sin²α = 1 − 2 × 9/25 = 7/25。选这个形式是因为题目直接给了 sinα，不必先求 cosα。

sin2α = −24/25，cos2α = 7/25

一句话记住

和差角公式是三角变换的地基：cos(α ∓ β) = cosαcosβ ± sinαsinβ，sin(α ± β) = sinαcosβ ± cosαsinβ，正切公式分母符号与分子相反。令两角相等得二倍角公式，其中 cos2α 有三种等价写法。a sinx + b cosx 可以合成 √(a²+b²) sin(x+φ)。化简时按看角、看名、看结构三步走。

03

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 求非特殊角，先拆成两个特殊角的和或差，再套公式。
  • 已知 sinα 求 cos2α，用 cos2α = 1 − 2sin²α，不必先求 cosα。
  • 形如 a sinx + b cosx，先提 √(a² + b²)，再合成一个正弦。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 符号记反：余弦的差角是加号，正弦的和角是加号，两者规律不同。
  • cos2α 三个形式选错：要看题目给的是 sinα 还是 cosα，选能直接代入的那个。
  • 辅助角漏掉系数：合成后前面的系数是 √(a² + b²)，不是 1。
  • 忽略定义域：正切公式要求分母不为零，tanα、tanβ 都要存在。
