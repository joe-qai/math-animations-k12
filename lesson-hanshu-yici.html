知识精讲

概念 · 公式 · 例题
概念

变量与常量

在一个变化过程中，数值会变的量叫变量，始终不变的量叫常量。比如匀速骑车，时间是变量、路程也是变量，每分钟骑的距离是常量。

骑车每分钟 200 米，x 分钟走的路程就是 y = 200x。时间一变，路程跟着变。

y = 200x

概念

函数的定义

在一个变化过程中有两个变量 x 和 y，如果 x 每取一个确定的值，y 都有唯一确定的值和它对应，就说 y 是 x 的函数，x 叫自变量，y 叫因变量。

关键词是「唯一确定」：一个 x 只能对应一个 y。比如 x = 4 时 y 若既能取 2 又能取 −2，那就不是函数。

y 是 x 的函数

概念

三种表示方法

解析式：写成一个式子，如 y = 200x；列表：把几组对应值列成表格；图像：把对应点画在坐标系里。

三种方法说的是同一个关系。题目给哪一种，就先用哪一种。

解析式 · 列表 · 图像

公式

一次函数

形如 y = kx + b（k、b 是常数，k ≠ 0）的函数叫一次函数。k 是一次项系数，b 是常数项。

当 b = 0 时，y = kx，叫正比例函数。k 必须不为 0：k = 0 时 y = b 是固定的数，不再随 x 变化，不是一次函数。

y = kx + b（k ≠ 0）

公式

图像与性质

一次函数的图像是一条直线，取两点就能画：x = 0 得 (0, b)，y = 0 得 (−b/k, 0)。

k > 0 时直线从左往右上升，y 随 x 增大而增大；k < 0 时下降，y 随 x 增大而减小；|k| 越大越陡。b 是直线与 y 轴交点的纵坐标。

k 决定方向，b 决定位置

例题

例题：待定系数法

已知直线过 (0, 3) 和 (2, 7)，求解析式。设 y = kx + b，代入 (0, 3) 得 b = 3；代入 (2, 7) 得 2k + 3 = 7，解得 k = 2。

所以解析式是 y = 2x + 3。一次函数只需要两个点，四步是：设、代、解、写。

y = 2x + 3

例题

例 2：看 k 和 b，读出图像信息

一次函数 y = −2x + 3 中，k = −2 < 0，所以 y 随 x 增大而减小。

令 x = 0，得 y = 3，图像与 y 轴交于 (0, 3)。

令 y = 0，得 −2x + 3 = 0，x = 1.5，图像与 x 轴交于 (1.5, 0)。

k 管方向：k > 0 上升、k < 0 下降；b 管位置：b 是图像与 y 轴交点的纵坐标。

y = −2x + 3 过 (0, 3) 与 (1.5, 0)

一句话记住

一个变化过程中，会变的量叫变量，不变的是常量。若 x 每取一个确定的值，y 都有唯一确定的值对应，则 y 是 x 的函数，x 是自变量。函数有解析式、列表、图像三种表示。一次函数形如 y = kx + b，其中 k ≠ 0；b = 0 时是正比例函数 y = kx；k = 0 时 y = b 不是一次函数。图像是一条直线，过 (0, b) 与 (−b/k, 0)。k > 0 上升、y 随 x 增大而增大；k < 0 下降、y 随 x 增大而减小；|k| 越大越陡；b 决定直线与 y 轴交点的位置。求解析式用待定系数法：设 y = kx + b、代入两点、解出 k 与 b、写出解析式。

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「由两点求解析式」改成「由 k、b 画图」，先定方向再定截距。
  • k > 0 时 y 随 x 增大而增大，k < 0 时相反。
  • 求与 x 轴交点，令 y = 0；求与 y 轴交点，令 x = 0。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 把 k = 0 的情况当成一次函数：此时 y = b 是固定的数，不随 x 变化。
  • 把 b 叫成「距离」：b 是直线与 y 轴交点的纵坐标，可以是负数。
  • 判断增减性不看 k 的符号，只看 b 的大小。
  • 画图时把直线画成线段：一次函数的图像是向两端无限延伸的直线。
  • 求解析式只代入一个点：一次函数有两个待定系数，需要两组条件。
