代数式求值

先代入，再计算

知道 a = 3、b = −2，求 2a + b 的值，就是把字母换成数再算。代入时要注意两件事：负数要加括号，乘号不能省——2a 要写成 2 × 3。所以原式变成 2 × 3 + (−2) = 6 − 2 = 4。有些题不用分别求出每个字母，把一整个式子看成整体更方便：已知 x + y = 5，2x + 2y = 2(x + y) = 10。还要分清 a² 和 2a：a = 3 时，a² = 9，2a = 6。

知识精讲

概念 · 公式 · 例题
概念

什么是求值

用数值代替代数式里的字母，算出的结果叫代数式的值。

同一个代数式，字母取不同的值，结果也不同。

所以求值时，字母的值必须由题目给出。

字母换成数 → 按顺序算

例题

代入 2a + b

已知 a = 3，b = −2，求 2a + b。

把 a 换成 3、b 换成 −2：2 × 3 + (−2)。

先算乘法：6 + (−2) = 4。

所以当 a = 3、b = −2 时，2a + b 的值是 4。

2 × 3 + (−2) = 4

概念

两个常见的代入错误

负数要加括号：写成 (−2)，避免和减号混在一起。

乘号不能省：2a 代入时要写成 2 × a，不能直接拼成 23。

分数、平方也要看清位置，先算括号和乘方，再算乘除，最后算加减。

负数加括号，乘号不省

例题

整体代入更快

已知 x + y = 5，求 2x + 2y。

不用分别求 x 和 y，先提公因数：2x + 2y = 2(x + y)。

把 x + y 看成整体代入：2 × 5 = 10。

整体代入能省掉很多步骤。

2x + 2y = 2(x + y) = 10

公式

a² 和 2a 的区别

a² 表示 a × a，是 a 自己乘自己。

2a 表示 2 × a，是 2 乘 a。

a = 3 时，a² = 9，2a = 6，两者不相等。

只有 a = 2 或 a = 0 时，它们才碰巧相等。

a² = a × a　2a = 2 × a

一句话记住

代数式求值就是把字母换成数，再按运算顺序算。a = 3、b = −2 时，2a + b = 2 × 3 + (−2) = 4。代入要注意两点：负数加括号，乘号不能省。遇到 x + y = 5 求 2x + 2y，可以整体代入得 10。还要分清 a² 是 a 乘 a，2a 是 2 乘 a：a = 3 时分别是 9 和 6。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 把 2a 直接写成 23：乘号省略了，代入时必须补上。
  • 负数不加括号：−2 代入后与前面的减号混在一起，容易算错。
  • 把 a² 算成 2a：a = 3 时 a² 是 9，不是 6。
  • 运算顺序颠倒：先算加减后算乘除，结果就错了。
