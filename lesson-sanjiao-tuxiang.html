五点作图，周期 2π

把单位圆上的点转一圈，纵坐标随时间画出来，就是一条波浪线，这就是正弦曲线。它每隔 2π 重复一次，最大值 1、最小值 −1。画图不用描很多点，取五个关键点就够：零点、最高点、零点、最低点、零点。余弦曲线只是把正弦曲线向左平移 π/2 得到的。

知识精讲

概念 · 公式 · 例题
概念

正弦曲线

y = sinx 的定义域是 R，值域是 [−1, 1]。

它是最小正周期为 2π 的周期函数，图像每隔 2π 重复一次。

它是奇函数，图像关于原点对称，且 sin(−x) = −sinx。

曲线在 x = π/2 + 2kπ 处取最大值 1，在 x = −π/2 + 2kπ 处取最小值 −1。

y = sinx，T = 2π

概念

余弦曲线

y = cosx 的定义域是 R，值域也是 [−1, 1]，周期 2π。

它是偶函数，图像关于 y 轴对称，且 cos(−x) = cosx。

把正弦曲线向左平移 π/2 就得到余弦曲线：cosx = sin(x + π/2)。

它在 x = 2kπ 处取最大值 1，在 x = π + 2kπ 处取最小值 −1。

y = cosx，T = 2π

例题

五点作图法

在一个周期 [0, 2π] 内取五个关键点，就能定出整条曲线的形状。

正弦的五个点是 (0,0)、(π/2,1)、(π,0)、(3π/2,−1)、(2π,0)。

余弦的五个点是 (0,1)、(π/2,0)、(π,−1)、(3π/2,0)、(2π,1)。

用光滑曲线连接，再按周期向两边延伸，不要画成折线。

0，π/2，π，3π/2，2π

公式

单调区间与对称性

y = sinx 的增区间是 [−π/2 + 2kπ, π/2 + 2kπ]，减区间是 [π/2 + 2kπ, 3π/2 + 2kπ]。

y = cosx 的增区间是 [−π + 2kπ, 2kπ]，减区间是 [2kπ, π + 2kπ]。

正弦的对称轴是 x = π/2 + kπ，对称中心是 (kπ, 0)。

余弦的对称轴是 x = kπ，对称中心是 (π/2 + kπ, 0)。

对称轴 x = π/2 + kπ

公式

y = Asin(ωx + φ)

A 叫振幅，决定最大值与最小值，值域是 [−|A|, |A|]。

ω 决定周期，T = 2π / |ω|，ω 越大曲线越密。

φ 叫初相，决定左右平移，平移量是 |φ/ω|，遵循左加右减。

先平移后伸缩和先伸缩后平移，平移量不一样，做题要看清顺序。

T = 2π / |ω|

例题

例 2：周期只看 ω，最值只看 A

求 y = 3sin(2x + π/3) 的周期、最大值和初相。

周期只看 x 前的系数 ω = 2：T = 2π / |ω| = 2π / 2 = π，不是 2π。

振幅是 3，所以最大值 3、最小值 −3。

把 2x + π/3 看成整体，初相是 π/3；求单调区间时也是把这个整体放进 sin 的区间里。

T = π，y_max = 3

一句话记住

正弦曲线 y = sinx 与余弦曲线 y = cosx 的定义域都是 R、值域都是 [−1, 1]、最小正周期都是 2π；正弦是奇函数、余弦是偶函数，余弦曲线是正弦曲线左移 π/2 的结果。五点作图取零点与最值点共五个。y = Asin(ωx + φ) 中 A 管振幅、ω 管周期 T = 2π/|ω|、φ 管平移。

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 求 y = Asin(ωx + φ) 的周期，用 T = 2π/|ω|，不要直接写 2π。
  • 求单调区间，把 ωx + φ 整体放进正弦的单调区间里解不等式。
  • 图像平移，先看 x 前有没有系数 ω；有系数要先提出来再平移。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 把周期写成 π：y = sinx 的周期是 2π，不是 π。
  • 五点法取错点：要取零点、最值点，不能随便取五个。
  • 平移方向搞反：左加右减，向左移是 x + h。
  • 忽略 ω 对周期的影响：T = 2π/|ω|，不是固定的 2π。
