锐角三角函数

正弦、余弦、正切与特殊角

推车上坡、放风筝、梯子靠墙，这些问题的共同点是：角度固定，直角三角形里两条边的比值就固定，只随角的大小改变，跟三角形大小无关。这个比值就是三角函数。在直角三角形里认准三条边——对边、邻边、斜边，就得到 sinA = 对边/斜边、cosA = 邻边/斜边、tanA = 对边/邻边。接着把 30°、45°、60° 的三个值背熟，看清锐角变大时正弦、正切变大而余弦变小的规律，再掌握 sin²A + cos²A = 1、tanA = sinA/cosA 和互余关系。最后用 5-12-13 的直角三角形把三个函数各算一遍。

知识精讲

概念 · 公式 · 例题
概念

为什么叫函数

角度固定，直角三角形里任意两边的比值就固定；三角形放大或缩小，比值不变。也就是说，比值由角的大小唯一确定。

既然角一变比值就跟着变，这个「角 → 比值」的对应关系就是函数，叫三角函数。

比值只与角的大小有关

公式

三个定义

在直角三角形中，对角 A：对边比斜边叫正弦 sinA，邻边比斜边叫余弦 cosA，对边比邻边叫正切 tanA。

认边之前先看是哪个角：对边是角对面的边，邻边是挨着角的那条直角边，斜边永远是直角所对的最长边。

sinA = 对边/斜边

公式

特殊角的值

30°：sin = 1/2，cos = √3/2，tan = √3/3；45°：sin = cos = √2/2，tan = 1；60°：sin = √3/2，cos = 1/2，tan = √3。

窍门：正弦按 1/2、√2/2、√3/2 依次变大，余弦正好倒过来，正切从 √3/3 增到 1 再到 √3。

sin30° = 1/2

概念

变化规律与范围

锐角从 0° 增到 90°，正弦和正切逐渐变大，余弦逐渐变小。所以同一个三角形里，大角对大边，正弦值也大。

因为直角边一定比斜边短，所以 0 < sinA < 1、0 < cosA < 1；正切是两条直角边之比，可以大于 1。

0 < sinA < 1

公式

两条常用关系

sin²A + cos²A = 1，它其实就是勾股定理两边同除以斜边的平方；tanA = sinA / cosA。

互余关系：若 A + B = 90°，则 sinA = cosB，因为 A 的对边正好是 B 的邻边。

sin²A + cos²A = 1

例题

例：斜边 13、直角边 5

Rt△ABC 中 ∠C = 90°，AB = 13，BC = 5，求 ∠A 的三个三角函数值。

先由勾股定理得 AC = √(13² − 5²) = 12。对边 BC = 5、邻边 AC = 12、斜边 AB = 13，所以 sinA = 5/13，cosA = 12/13，tanA = 5/12。

sinA = 5/13，cosA = 12/13

一句话记住

三角函数来自一个简单的事实：角固定，直角三角形两边的比值就固定，跟三角形画多大没关系。在直角三角形里认准对边、邻边、斜边，就有 sinA = 对边/斜边、cosA = 邻边/斜边、tanA = 对边/邻边。特殊角的三组值必须背熟：30° 是 1/2、√3/2、√3/3，45° 是 √2/2、√2/2、1，60° 是 √3/2、1/2、√3。锐角变大时，正弦和正切变大、余弦变小；正弦和余弦都在 0 到 1 之间，正切可以很大。再加上 sin²A + cos²A = 1、tanA = sinA/cosA 和互余关系 sinA = cos(90° − A)，这一节的工具就齐了。做题三步：定角、认边、写比值。

03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 对边、邻边找错：认边之前先看清是哪个角，换了角，对边和邻边就换了。
  • 把 sinA 拆成 sin 乘 A：sinA 是一个整体记号，不能拆，也不能漏写角。
  • 算出 sin 或 cos 大于 1：直角边一定比斜边短，正弦、余弦不可能大于 1。
  • 特殊角的值记混：30° 的余弦是 √3/2，60° 的正弦才是 √3/2。
  • 用互余关系时把角对错：必须是两个角的和等于 90°。
