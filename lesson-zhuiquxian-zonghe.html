圆锥曲线综合

设点、联立、韦达、代入

圆锥曲线综合题看起来千变万化，骨架却稳定：设点或设线，联立得到二次方程，用韦达定理把条件翻译成关于参数的方程，最后解参数并检验范围。定点、定值、最值、面积，都是这套骨架的不同外壳。

01

知识精讲

概念 · 公式 · 例题
概念

通法骨架

第一步：设点或设线，明确哪些量是参数。

第二步：联立方程，得到一元二次方程，写出 Δ > 0 的范围。

第三步：用韦达定理写出两根之和与两根之积。

第四步：把题目条件翻译成含参数的等式，解出参数并检验。

设 → 联 → 韦 → 代

公式

常见条件翻译

以 AB 为直径的圆过原点：OA·OB = 0，即 x₁x₂ + y₁y₂ = 0。

两点关于某直线对称：垂直加中点两个条件。

面积为定值：用 1/2 × 底 × 高，底取弦长。

定点问题：把直线方程整理成关于参数的一次式，令参数系数与常数项同时为零。

OA·OB = 0

例题

例 1：定值问题

椭圆 x²/4 + y² = 1，直线 l 与椭圆交于 A、B，且 OA⊥OB，求证原点 O 到 l 的距离为定值。

设 l：y = kx + m，联立得 (1+4k²)x² + 8kmx + 4m² − 4 = 0。

由 OA·OB = 0 得 x₁x₂ + y₁y₂ = 0，代入韦达定理化简。

可得 5m² = 4(1+k²)，于是 d = |m|/√(1+k²) = 2/√5，为定值。

d = 2/√5

公式

最值与范围

求最值先把目标量表示成一个变量的函数，再确定定义域。

常见目标：弦长、面积、向量点积、斜率之和。

定义域来自 Δ > 0、参数的实际意义、图形位置限制。

求出最值后要回头检查取等条件是否在定义域内。

先表示，再定域，后求最值

例题

例 2：面积最值

直线 y = x + m 与椭圆 x²/2 + y² = 1 交于 A、B，求三角形 OAB 面积的最大值。

联立得 3x² + 4mx + 2m² − 2 = 0，Δ > 0 给出 m² < 3。

弦长 |AB| = √2 |x₁ − x₂|，原点到的距离 d = |m|/√2。

面积 S = 1/2 |AB| d，化简后关于 m² 求最值，在 m² = 3/2 时取到。

S = 1/2 |AB| · d

一句话记住

设点联立、韦达代入；先写 Δ 定范围，再把条件翻译成等式，最后检验取舍。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「证明定值」改成「求定值」，先猜后证，用特殊位置算出候选值。
  • 把「面积最大」改成「面积等于某值」，得到关于参数的方程，注意多解取舍。
  • 把「OA⊥OB」改成「∠AOB = 60°」，用点积与模长联立。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 只写韦达定理不写 Δ > 0，参数范围会漏。
  • 几何条件翻译错，例如把 OA⊥OB 写成 x₁x₂ − y₁y₂ = 0。
  • 斜率不存在的情况没有单独讨论，定点问题可能漏解。
  • 求出参数后不检验是否满足 Δ > 0 与图形位置。
