方程与不等式（中考专题）

解法、条件、建模：三条线一次串完

方程与不等式是中考的高频工具，选择填空直接考解法，应用题靠它建模，函数压轴也常回到它。这一节按三条线梳理：一次方程的五步解法与方程组的消元思路；分式方程去分母后为什么必须验根、增根与无解的关系；一元二次方程的四种解法、判别式与根与系数的关系；不等式两边乘除负数要变号、数轴上空心与实心、不等式组取交集的口诀；最后用「设、找、列、验」四步做一道利润题，强调设未知数带单位、解完看实际意义。

知识精讲

概念 · 公式 · 例题
概念

一元一次方程：五步走

去分母、去括号、移项、合并同类项、系数化为一。每一步只做一件事，别跳步，尤其是去分母时不含分母的项也要乘。

移项要变号；系数化为一是在两边同除以未知数的系数，不是把系数直接搬到右边。

3(x − 1) = 2x + 4 → x = 7

概念

二元一次方程组：消元

代入消元：从一个方程解出一个未知数，代入另一个方程；加减消元：把两个方程相加或相减，直接消掉一个未知数。

系数相同或相反时用加减最快，一个是另一个的倍数时用代入更快。消元的目标始终是把两个未知数化成一个。

x + y = 5，2x − y = 1 → x = 2，y = 3

概念

分式方程：增根与无解

去分母是把两边同乘最简公分母，这一步可能引入使分母为零的解，叫增根，必须代回公分母检验后舍去。

分式方程无解有两种情况：化成的整式方程本身无解，或者唯一的解是增根。所以「无解」也是一种正确答案，不能直接写增根的值。

1/(x − 2) + 3 = (x − 1)/(x − 2) → 无解

公式

一元二次方程：解法与判别式

四种解法：直接开平方、配方法、公式法、因式分解法。能因式分解就先分解，最快；不能分解再用公式。

判别式 Δ = b² − 4ac：Δ > 0 两个不等实根，Δ = 0 两个相等实根，Δ < 0 没有实根。根与系数关系：x₁ + x₂ = −b/a，x₁x₂ = c/a。

x = (−b ± √(b² − 4ac)) / 2a

概念

不等式（组）：变号与取交集

两边同乘或同除一个负数，不等号必须变向，这是和方程最大的区别。数轴上空心圈表示不含端点，实心点表示含端点。

不等式组取公共部分，口诀：同大取大，同小取小，大小小大取中间，大大小小无解。

−2x + 1 > 5 → x < −2

例题

例：打折利润率

某商品进价 40 元、标价 60 元，要保证利润率不低于 20%，问最多打几折。

设打 k 折，售价为 60k，列不等式 60k − 40 ≥ 40 × 20%，解得 k ≥ 0.8，所以至少打八折。

60k − 40 ≥ 8 → k ≥ 0.8

例题

例 2：分式方程解完必须验根

解方程 1/(x − 2) = 3/x。

去分母，两边同乘 x(x − 2)：x = 3(x − 2)。

解得 x = 3x − 6，即 2x = 6，x = 3。

检验：x = 3 时 x(x − 2) = 3 ≠ 0，不是增根；如果解出 x = 2，分母为 0，就必须舍去。

x = 3，检验 x(x − 2) ≠ 0

一句话记住

方程与不等式的复习要抓三条线。解法上，一元一次方程按五步走，方程组靠消元把两个未知数化成一个；分式方程去分母后必须验根，增根要舍去，无解也是答案；一元二次方程优先因式分解，不行再用公式，判别式决定根的个数，根与系数的关系在压轴题里常用。不等式要记住乘除负数变号，解集画在数轴上，不等式组取公共部分。建模按设、找、列、验四步，等量关系列方程，不等关系列不等式，最后一定要回到实际情境检查范围。

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 分式方程解完必须验根，增根要舍去。
  • 移项要变号，去分母不要漏乘不含分母的项。
  • 不等式两边乘除负数，不等号方向要反过来。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 去分母时漏乘不含分母的项。
  • 移项不变号，把 −3 从左边搬到右边还是 −3。
  • 两边乘除负数时忘记改变不等号方向。
  • 分式方程解完不验根，把增根当成答案写上去。
  • 应用题设未知数不带单位、解完不检查是否符合实际（人数为整数、长度为正、折扣范围）。
