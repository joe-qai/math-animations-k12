因式分解强化

十字相乘、分组分解、拆项添项：高中第一道坎

高中一开学，题目里的式子就从 x² − 4 变成 x² − 5x + 6、2x² + 7x + 3，还有四个项要分组。这些不是新知识，而是初中因式分解的强化版，只是初中只练了提公因式和两个公式。这一节把三招补齐：一提二套三检查——先提公因式，再套平方差与完全平方，最后检查每个因式是否还能继续分解；十字相乘——二次项系数为 1 时找「和为一次项系数、积为常数项」的两个数，系数不为 1 时拆两头、看交叉相乘之和；分组分解——四项式两项一组，各提公因式后要出现公共括号，走不通就换一种分法；拆项添项与换元——x⁴ + 4 拆成配方再平方差，重复出现的部分记成一个字母降次。最后是四个易错点和一条自检习惯：分解完乘回去。

知识精讲

概念 · 公式 · 例题
概念

一提、二套、三检查

第一步提公因式：每一项都有同一个因式，就先提出来，提完再看括号里能不能继续分解。第二步套公式：平方差 a² − b² = (a + b)(a − b)，完全平方 a² ± 2ab + b² = (a ± b)²。

第三步检查：每个因式都不能再分解才算完成。顺序不能乱——先提公因式，再套公式；反过来做，往往会漏掉还能提的公因式。

3x² − 6x = 3x(x − 2)

公式

十字相乘：系数为 1

对 x² + px + q，只要找到两个数，它们的和是 p、积是 q，就能写成 (x + a)(x + b)。做法是从积出发枚举，再用和验证，符号看和。

例如 x² − 5x + 6：两数之和为 −5、积为 6，取 −2 与 −3，于是 x² − 5x + 6 = (x − 2)(x − 3)。

和 = p，积 = q

公式

十字相乘：系数不为 1

二次项系数不是 1 时，把两头都拆开，画十字，让交叉相乘之和等于一次项系数。

例如 2x² + 7x + 3：2x² 拆成 2x 与 x，3 拆成 1 与 3，交叉相乘 2x·3 = 6x、x·1 = x，和为 7x，正好等于一次项系数，所以 2x² + 7x + 3 = (2x + 1)(x + 3)。

交叉相乘之和 = 一次项系数

概念

分组分解

四项式常按两项一组：ax + ay + bx + by = a(x + y) + b(x + y) = (a + b)(x + y)。分组的目标只有一个——分完能继续提公因式或用公式。

另一种分法是把能凑成完全平方的三项放一组，剩下一项单独看。一种分法走不通就换一种，不要死磕。

ax + ay + bx + by = (a + b)(x + y)

例题

例：拆项添项

x⁴ + 4 直接看不出来，就补上中间项：x⁴ + 4x² + 4 − 4x² = (x² + 2)² − (2x)²，再用平方差得 (x² + 2x + 2)(x² − 2x + 2)。

补上的项要能减回去，式子的值才不变。这种「加了再减」的拆法，是处理高次式的常用手段。

x⁴ + 4 = (x² + 2x + 2)(x² − 2x + 2)

例题

例：换元降次

式子中某一部分反复出现时，把它记成一个字母。例如把 x² + x 记作 t，原来的四次式立刻变成二次式，分解完再把 t 换回 x² + x。

换元的关键是「换得回」：换元后要写清 t 的取值范围，最后一步必须还原成原来的字母。

令 t = x² + x，降次后再换回

一句话记住

因式分解是高中一切运算的起点，三招要练到条件反射。第一招是顺序：一提公因式、二套公式、三检查，检查的标准是每个因式都不能再分。第二招是十字相乘：系数为 1 时找和为一次项系数、积为常数项的两个数；系数不为 1 时拆两头，让交叉相乘之和等于一次项系数，不对就换组合。第三招是分组：四项式两项一组，各提公因式后出现公共括号，或者三项凑完全平方；走不通就换分法。遇到高次式就用拆项添项，补一项再减一项，配成完全平方后套平方差；结构重复就用换元降次，记得最后换回来。最后养成习惯：分解完乘回去验一遍。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 分解不彻底，括号里还能继续分解就停了。
  • 负号没有提干净，导致后面符号全错。
  • 十字相乘只试了一种拆法就放弃，没有换组合。
  • 拆项添项时补的项没有减回去，式子的值被改变。
  • 分解完不检验，结果乘开和原式对不上。
