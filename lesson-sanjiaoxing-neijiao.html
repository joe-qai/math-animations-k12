三角形内角和与三边关系

三个角加起来 180°，三条边要凑得成

屋顶木架、自行车车架为什么都用三角形？因为三条边一定，形状就定了，推都推不动。这节课讲三角形的两条基本规律：一是内角和恒为 180°，可以用「过顶点作平行线」把它变成一个平角来证明；二是三边关系，任意两边之和大于第三边，任意两边之差小于第三边。最后用它们解决求第三边范围和等腰三角形分类两类常考题。

知识精讲

概念 · 公式 · 例题
概念

三角形最稳定

把三根木条钉成一个三角形，用手去推，推不动；把四根木条钉成一个四边形，一推就歪。原因是：只要三条边的长度确定了，三角形的形状和大小就唯一确定；四边形的四条边确定后，还可以压扁、拉长。

这就是三角形的稳定性，也是屋顶、桥梁、脚手架里到处是三角形的原因。

公式

内角和等于 180°

任意一个三角形，三个内角的和都是 180°，与它的大小、形状无关。

证明方法：过顶点 C 作一条平行于 AB 的直线，用量角器看不出来，用内错角看得很清楚——AC 是截线，∠A 与 C 点左侧的那个角是内错角，相等；BC 是截线，∠B 与 C 点右侧的那个角是内错角，相等。三个角正好拼成 C 点处的一个平角，所以 α + β + γ = 180°。

视频里第 2 节就是用这个方法：把 α、β 用平行线「搬」到顶点 C，与 γ 拼成一个平角。

∠A + ∠B + ∠C = 180°

公式

两个常用推论

推论一：直角三角形的两个锐角互余。因为直角三角形有一个角是 90°，剩下两个角的和就是 180° − 90° = 90°。

推论二：三角形的一个外角，等于与它不相邻的两个内角之和，并且大于任何一个与它不相邻的内角。注意外角与它相邻的那个内角是互补关系，加起来 180°。

直角三角形：∠B + ∠C = 90°

公式

三边关系

两点之间线段最短。从 A 到 B 走直线段最近，绕道走折线 A—M—B 一定更长，所以三角形任意两边之和大于第三边：a + b > c。

把它变形，就得到另一边的不等式：c > a − b，也就是任意两边之差小于第三边。判断三条线段能不能围成三角形，只需要把两条较短的加起来，看是否大于最长的那一条。

已知两边求第三边的范围：第三边大于两边之差、小于两边之和，两个端点都取不到。例如两边是 3 和 5，第三边 x 满足 2 < x < 8。

两边之差 < 第三边 < 两边之和

一句话记住

三角形内角和恒为 180°，证明的关键是过顶点作对边的平行线，用内错角把两个角搬到顶点，与第三个角拼成平角。推论有两条：直角三角形两锐角互余；三角形的外角等于不相邻两内角之和，且大于其中任何一个。三边关系来自「两点之间线段最短」：任意两边之和大于第三边，任意两边之差小于第三边。判断能否围成三角形，只需看两条较短边之和是否大于最长边；已知两边求第三边，用「差 < 第三边 < 和」；等腰三角形记得分两种情况并回头检验。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 把内角和记成 360°。360° 是四边形的内角和，三角形是 180°。
  • 等腰三角形只算一种情况。已知两条边时要分「这条边是腰」和「这条边是底」两种，分别算完再检验。
  • 算出答案就交卷，忘了用三边关系检验。3、3、7 这种组合算得出周长，但根本围不成三角形。
  • 求第三边范围时把端点也算进去。2 < x < 8 不能写成 2 ≤ x ≤ 8，等于端点时会退化成一条线段。
  • 以为外角和它相邻的内角相等。它们是互补，加起来 180°。
