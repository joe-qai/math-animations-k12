解直角三角形

已知一边一角，求其余

要测一栋楼的高度，站在离楼 30 米处测得仰角 30°，这道题就变成了：在直角三角形里，已知一个锐角和一条边，求另一条边。这就是解直角三角形——除直角外再知道两个元素（至少一个是边），剩下的边和角都能求出来。这一节讲清三件事：怎么按「已知谁、求谁」挑公式，解题的四步流程，以及实际应用中的仰角、俯角与坡度。最后用「30 米、仰角 30°、眼高 1.6 米」完整算一遍楼高，提醒别忘加眼高。

知识精讲

概念 · 公式 · 例题
概念

什么叫解直角三角形

直角三角形有六个元素：三个角和三条边。直角已知，所以只要再知道两个元素，其中至少有一个是边，就能把其余元素全部求出来。

这个过程叫解直角三角形。只知道两个角不行，因为所有相似的直角三角形角的度数一样，边却可以任意大。

再知两个元素，至少一边

公式

怎么选公式

看已知谁、求谁：求对边，用正弦或正切；求邻边，用余弦；求斜边，用正弦或余弦。

已知斜边 c 与锐角 A：a = c·sinA，b = c·cosA；已知邻边 b 与锐角 A：a = b·tanA，c = b / cosA。

a = c·sinA

概念

四步流程

第一步画图，把已知条件标在图上；第二步看清已知哪条边、要求哪条边；第三步选一个同时含这两条边的式子；第四步解方程，按题目要求取近似。

如果式子选不出来，就回到定义：对边比斜边是正弦，邻边比斜边是余弦，对边比邻边是正切。

画图 → 选式 → 求解 → 取近似

概念

仰角、俯角与坡度

从下往上看，视线与水平线的夹角叫仰角；从上往下看，视线与水平线的夹角叫俯角。两者都从水平线量起。

坡面的坡度是竖直高度与水平宽度之比，等于坡角的正切：i = tanα，不是正弦。

i = 竖直高度 / 水平宽度 = tanα

例题

例：测楼高

站在离楼底 30 米处，测得楼顶仰角 30°，眼高 1.6 米，求楼高。

先算视线以上的高度：h = 30·tan30° = 10√3 ≈ 17.3 米；再加上眼高，楼高 ≈ 17.3 + 1.6 = 18.9 米。

楼高 ≈ 17.3 + 1.6 = 18.9 米

例题

例：已知斜边和锐角

Rt△ABC 中 ∠C = 90°，斜边 c = 10，∠A = 30°，求 a 与 b。

a = c·sin30° = 10 × 1/2 = 5；b = c·cos30° = 10 × √3/2 = 5√3 ≈ 8.66。

a = 5，b = 5√3

一句话记住

解直角三角形就是在直角三角形里，除直角外再知道两个元素（至少一个是边），把其余元素求出来。做法四步：画图把条件标上、看清已知谁求谁、选一个同时含这两条边的式子、解方程并按题目要求取近似。选式子的口诀是：求对边用正弦或正切，求邻边用余弦，求斜边用正弦或余弦。实际应用中要分清仰角、俯角都从水平线量起；坡度是竖直高度比水平宽度，等于坡角的正切。测高题的标准流程是先算视线以上的高度，再加上眼高，这一步最容易丢分。

03

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 先画图，把已知边和角标在图上，再选公式。
  • 求对边用 sin，求邻边用 cos，求两边关系用 tan。
  • 仰角、俯角都从水平线量起，不是从竖直线量。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 正弦余弦用反：求邻边时错乘 sin，求对边时错乘 cos。
  • 仰角、俯角从竖直线量起：两者都必须从水平线量起。
  • 把坡度当成正弦：坡度是竖直高度比水平宽度，等于 tanα。
  • 单位不统一就直接代：米和厘米要先统一。
  • 测高题忘了加眼高或用 1.6 米代替整栋楼高。
