函数的概念与表示

一个 x 配一个 y

汽车匀速行驶，时间定了，路程就定了；正方形边长定了，面积就定了。这种「一个量定了，另一个量跟着唯一确定」的关系，就是函数。函数有三要素：定义域、对应关系、值域，其中定义域和对应关系决定一切。判断两个函数是不是同一个，只看定义域和对应关系，字母叫什么名字不算数。

概念

函数是什么

设 A、B 是非空实数集，如果按某种对应关系 f，对 A 中任意一个 x，B 中都有唯一确定的 y 与之对应，就把 f 叫做从 A 到 B 的函数。

记作 y = f(x)，x ∈ A。其中 x 叫自变量，A 叫定义域，所有函数值组成的集合叫值域。

关键词是「任意」和「唯一」：A 里的每个 x 都要有，而且只能有一个 y。

所以一个 x 配两个 y 不是函数，比如 x² + y² = 1 整体就不能看成 y 关于 x 的函数。

y = f(x)，x ∈ A

概念

三要素

函数有三要素：定义域、对应关系、值域。

其中定义域和对应关系是根本，值域由这两个共同决定。

判断两个函数是否相同，就看定义域是否相同、对应关系是否相同，两者都相同才算同一个函数。

所以 y = x 和 y = x²/x 不是同一个函数，后者的定义域少了 x = 0。

定义域 + 对应关系

公式

区间怎么写

开区间 (a, b)：两端都取不到；闭区间 [a, b]：两端都取得到。

半开半闭区间 [a, b) 或 (a, b]：只取到一端。

无穷一侧写成 (a, +∞)、(−∞, b)、全体实数写成 (−∞, +∞)。

写区间前先解出 x 的取值范围，再检查端点处函数有没有意义。

[a, b]　(a, +∞)

概念

三种表示法

解析法：写出式子，如 y = 2x + 1，简洁、便于计算。

图像法：把点画在坐标系里，能一眼看出变化趋势。

列表法：把几组对应值列成表格，适合数据不多、没有明显公式的情况。

三种方法可以互相转换，做题时优先选最能看清关系的那一种。

式子 · 图像 · 表格

概念

分段函数

在定义域的不同部分，用不同式子表示的函数叫分段函数。

分段函数仍然是一个函数，不是几个函数，它的定义域是各段定义域的并集。

求值时先看 x 落在哪一段，再用那一段的式子算，不能混用。

画图像时也是一段一段画，注意端点处是实心点还是空心点。

先看落在哪一段

一句话记住

函数是两个非空实数集之间的对应关系：定义域里任意一个 x，都有唯一确定的 y 与之对应，记作 y = f(x)。三要素中定义域和对应关系是根本，值域由它们决定，判断两个函数相同也只看这两条。表示方法有解析法、图像法、列表法；分段函数本质仍是一个函数，求值时先判断 x 落在哪一段。

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 定义域优先：先解出 x 的取值范围，再化简式子，否则会把丢掉的点补回来。
  • f(x) 与 f(a) 不一样：f(x) 是一个函数，f(a) 是一个具体的数。
  • 判断同一函数只看定义域和对应关系，自变量写成 x 还是 t 不影响。
  • 分段函数要分段讨论，别把第一段的公式套到第二段的 x 上。
