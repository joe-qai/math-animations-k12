圆的方程

圆心定位置，半径定大小

圆是到定点距离等于定长的点的集合。标准方程 (x−a)²+(y−b)²=r² 一眼看出圆心和半径；一般式需要配方还原。判断直线与圆的位置关系，只比较圆心到直线的距离 d 与半径 r，不需要联立解方程。

01

知识精讲

概念 · 公式 · 例题
公式

标准方程

以 (a, b) 为圆心、r 为半径的圆的标准方程是 (x − a)² + (y − b)² = r²。

看到方程就能读出圆心和半径，注意括号里是减号，圆心坐标取相反数。

若圆心在原点，方程简化为 x² + y² = r²。

半径 r 一定大于 0，右边是 r² 而不是 r。

(x−a)² + (y−b)² = r²

公式

一般方程

x² + y² + Dx + Ey + F = 0 叫圆的一般方程，前提是 D² + E² − 4F > 0。

配方得圆心 (−D/2, −E/2)，半径 r = 1/2 √(D² + E² − 4F)。

若 D² + E² − 4F = 0，方程只表示一个点；小于 0 则不表示任何图形。

一般方程中 x² 与 y² 的系数必须相等且不为零，否则不是圆。

r = 1/2 √(D²+E²−4F)

例题

例 1：配方求圆心

求圆 x² + y² − 4x + 2y = 0 的圆心和半径。

配方：(x² − 4x + 4) + (y² + 2y + 1) = 5。

即 (x − 2)² + (y + 1)² = 5。

所以圆心是 (2, −1)，半径是 √5。

(x−2)² + (y+1)² = 5

概念

直线与圆的位置关系

设圆心到直线的距离为 d，半径为 r：d < r 相交，d = r 相切，d > r 相离。

相交时弦长 = 2√(r² − d²)，这是勾股定理的直接应用。

求切线方程时，先判断点在圆上还是圆外：在圆上只有一条切线，在圆外有两条。

过圆外一点求切线，设斜率时要单独讨论斜率不存在的情况。

弦长 = 2√(r² − d²)

例题

例 2：判断位置关系

判断直线 3x + 4y − 10 = 0 与圆 x² + y² = 4 的位置关系。

圆心 (0, 0)，半径 r = 2，d = |−10| / √(3² + 4²) = 10/5 = 2。

因为 d = r = 2，所以直线与圆相切。

相切时只有一个公共点，不需要解方程组。

d = r ⇒ 相切

一句话记住

标准方程读圆心半径，一般方程先配方；直线与圆看 d 与 r，弦长用勾股。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「判断位置关系」改成「求弦长」，先算 d，再用 2√(r²−d²)。
  • 把「过圆上一点求切线」改成「过圆外一点求切线」，设斜率并讨论不存在的情况。
  • 把「圆与直线」改成「圆与圆」，比较圆心距与半径和、半径差。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 标准方程中圆心坐标是括号内取相反数，容易把 (x−2) 的圆心写成 (−2)。
  • 一般方程表示圆的前提是 D² + E² − 4F > 0。
  • 判断位置关系时 d 是圆心到直线的距离，不是圆心到弦的距离之外的其他量。
  • 过圆外一点求切线，忘记讨论斜率不存在会漏解。
