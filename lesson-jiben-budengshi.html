基本不等式

和定积最大，积定和最小

周长固定的一块矩形菜地，长和宽怎么取面积最大？答案是围成正方形。这背后就是基本不等式：a、b 都是正数时，a + b ≥ 2√(ab)，当且仅当 a = b 时取等号。它有两个常用说法：和一定时，积有最大值；积一定时，和有最小值。用的时候记住六个字——一正、二定、三相等：先确认都是正数，再凑出定值，最后检查能不能取到等号。

知识精讲

概念 · 公式 · 例题
概念

从平方非负推出来

对任意正数 a、b，都有 (√a − √b)² ≥ 0。

展开得 a − 2√(ab) + b ≥ 0，移项就是 a + b ≥ 2√(ab)。

所以这条不等式不是背来的，是平方非负的直接结果。

(√a − √b)² ≥ 0

公式

基本不等式

当 a > 0、b > 0 时，a + b ≥ 2√(ab)。

两边除以 2：(a + b)/2 ≥ √(ab)，即算术平均数不小于几何平均数。

当且仅当 a = b 时，等号成立。

a + b ≥ 2√(ab)

概念

几何意义

把 a、b 看成两条线段，√(ab) 是它们的比例中项。

不等式说明：两段之和，总不小于它们比例中项的两倍。

等号成立时两段一样长，画面最「正」。

两段相等时最短

例题

和定，积最大

已知 a + b = 10，求 ab 的最大值。

由 a + b ≥ 2√(ab) 得 10 ≥ 2√(ab)，所以 √(ab) ≤ 5，ab ≤ 25。

当 a = b = 5 时取到 25。

周长固定的矩形，围成正方形时面积最大。

a + b = 10 ⇒ ab ≤ 25

例题

积定，和最小

已知 ab = 16，a、b > 0，求 a + b 的最小值。

a + b ≥ 2√(ab) = 2 × 4 = 8。

当 a = b = 4 时取到 8。

用之前先检查：是不是都是正数、定值有没有凑出来、等号能不能取到。

ab = 16 ⇒ a + b ≥ 8

一句话记住

基本不等式 a + b ≥ 2√(ab) 来自 (√a − √b)² ≥ 0，条件是两个数都为正，当且仅当 a = b 时取等号。它有两句话：和一定时积有最大值，积一定时和有最小值。使用口诀是一正、二定、三相等，三步都满足才敢写最值。

03

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 和不是定值时，先拆项或配凑，把和凑成常数再用不等式。
  • 形如 a + 4/a，先确认 a > 0，再用积为定值求和的最小值。
  • 等号取不到时，改看单调性，在区间端点找最值。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 不检查正数就用：基本不等式要求 a、b 都是正数。
  • 等号取不到还写最值：等号条件不成立，结论就不成立。
  • 把方向记反：写成 a + b ≤ 2√(ab) 就完全错了。
  • 没凑出定值：和或积不是常数，算出的只是不等式，不是最值。
