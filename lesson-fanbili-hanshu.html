反比例函数

一个变大，另一个就变小

走得越快，用时越少；长拉得越长，宽就得越窄——两个量此消彼长、乘积不变，这就是反比例。这一节从两个生活例子讲起，给出 y = k/x 的定义与 x、y 都不能为零的限制，画出两支双曲线看象限与增减性，再讲列表描点连线的画法、用一个点求解析式，最后落在面积应用与三个易错点上。

知识精讲

概念 · 公式 · 例题
概念

反比例函数

两个变量的乘积是一个不为零的常数时，这两个量成反比例。写成函数是 y = k/x（k ≠ 0），也可以写成 xy = k。

因为 x、y 都不能等于零，所以图像永远不与坐标轴相交。

y = k / x（k ≠ 0）

概念

图像与性质

图像叫双曲线，有两只。k > 0 时两只分别在第一、第三象限，在每一支上 y 随 x 增大而减小。

k < 0 时两只分别在第二、第四象限，在每一支上 y 随 x 增大而增大。性质只对同一支成立，跨支不能直接比较大小。

k > 0 → 一、三象限

公式

画图三步

列表：x 取正负对称的几个值，算出对应的 y；描点：把每一对坐标画成点；连线：用平滑曲线连接，不能画成折线。

曲线越来越靠近坐标轴，但永远不相交，因为 x 和 y 都不能为零。

列表 → 描点 → 连线

公式

待定系数法

反比例函数只有一个参数 k，所以一个点就够。把点的坐标代入 xy = k 求出 k，再写回 y = k/x。

例：图像过 (2, 3)，k = 2 × 3 = 6，解析式是 y = 6/x。

k = x · y

例题

例：过 (−2, 3) 求解析式

代入 xy = k：k = −2 × 3 = −6，所以解析式是 y = −6/x。

因为 k < 0，图像在第二、第四象限。

y = −6 / x

例题

例：矩形面积 12

长 x、宽 y，面积 12，则 xy = 12，即 y = 12/x。

长扩大几倍，宽就缩小几倍——这就是反比例在实际问题里的样子。

y = 12 / x

一句话记住

两个量的乘积是不为零的常数，就说它们成反比例，函数写作 y = k/x（k ≠ 0），也可写成 xy = k。x、y 都不能为零，所以图像是两支不与坐标轴相交的双曲线：k > 0 时在一、三象限，每一支上 y 随 x 增大而减小；k < 0 时在二、四象限，每一支上 y 随 x 增大而增大。画图按列表、描点、连线三步，用平滑曲线。求解析式用待定系数法，一个点就够：k = xy，如过 (2, 3) 得 y = 6/x，过 (−2, 3) 得 y = −6/x 且在二、四象限。实际应用中，矩形面积一定时 y = 12/x，长扩大几倍宽就缩小几倍。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • k 等于零：k = 0 时不是反比例函数。
  • 比较函数值跨支：不同分支上的点不能直接用增减性比较。
  • 图像画成折线：双曲线是平滑曲线，且不与坐标轴相交。
  • 忽略 x ≠ 0：定义域不含零，图像在 y 轴两侧断开。
  • 求 k 时把坐标相乘算错符号：k = xy，负点要带负号。
