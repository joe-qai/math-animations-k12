抽样与样本估计

样本估计总体

总体太大时，只能抽一部分来推断整体。简单随机抽样保证每个个体等可能被抽到；分层抽样按比例从各层抽取，适合层间差异明显的情况。用样本平均数估计总体平均数，用样本方差估计总体波动。

知识精讲

概念 · 公式 · 例题
概念

简单随机抽样

从总体中逐个不放回地抽取，且每个个体被抽到的机会相等，叫简单随机抽样。

常用方法：抽签法、随机数法。

优点是操作简单、理论清楚；缺点是总体很大时编号和抽取成本高。

样本必须具有代表性，否则估计会有系统偏差。

每个个体等可能被抽到

公式

分层抽样

当总体由差异明显的几部分组成时，按各部分所占比例抽取，叫分层抽样。

若第 i 层有 Nᵢ 个个体，总样本量为 n，则该层抽取 n × Nᵢ/N 个。

分层抽样能保证各层都有代表，估计通常比简单随机更精确。

计算时先求抽样比 n/N，再乘各层人数。

nᵢ = n × Nᵢ / N

例题

例 1：分层抽样

某校高一、高二、高三分别有 300、200、500 人，用分层抽样抽 100 人。

总人数 N = 1000，抽样比 = 100/1000 = 1/10。

高一抽 300 × 1/10 = 30 人，高二抽 20 人，高三抽 50 人。

三层人数相加 30 + 20 + 50 = 100，与样本量一致。

30、20、50

公式

平均数与方差

样本平均数 x̄ = (x₁ + x₂ + … + xₙ)/n，反映集中趋势。

样本方差 s² = [(x₁−x̄)² + … + (xₙ−x̄)²]/n，反映离散程度。

方差越大，数据越分散；方差越小，数据越集中。

标准差是方差的算术平方根，单位与原数据一致。

s² = Σ(xᵢ−x̄)²/n

概念

用样本估计总体

用样本平均数估计总体平均数，用样本方差估计总体方差。

样本量越大，估计通常越稳定，但成本也越高。

抽样必须随机，不能只挑「方便」的个体。

估计是概率意义上的接近，不保证完全相等。

x̄ ≈ μ，s² ≈ σ²

例题

例 2：先算平均数，再算方差

样本 2，4，4，6，9，求平均数和方差。

平均数 x̄ = (2 + 4 + 4 + 6 + 9) / 5 = 25 / 5 = 5。

方差 s² = [(2 − 5)² + (4 − 5)² + (4 − 5)² + (6 − 5)² + (9 − 5)²] / 5 = (9 + 1 + 1 + 1 + 16) / 5 = 28 / 5 = 5.6。

方差衡量的是「离平均数的平均平方距离」，所以先算平均数，再逐项作差。

x̄ = 5，s² = 5.6

一句话记住

简单随机保等可能，分层抽样按比例；平均数看集中，方差看波动。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「按人数比例分层」改成「按性别分层」，先统计各层人数再按比例抽。
  • 把「求平均数」改成「求方差」，先算平均数再逐项平方。
  • 把「样本估计总体」改成「用频率分布直方图估计」，用组中值代替具体数据。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 分层抽样必须按比例，不能每层抽一样多。
  • 方差公式分母是 n，注意与统计软件中除以 n−1 的样本方差区分。
  • 样本量不是越大越好，要兼顾成本与代表性。
  • 只抽容易接触到的人，样本会有系统偏差。
