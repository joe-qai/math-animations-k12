平行四边形

两组对边分别平行，推也推不散

伸缩门、活动衣架，推一推会变形，可两组对边始终分别平行——这就是平行四边形。这一节从生活图形讲起，先给出定义，再讲四条性质（对边、对角、邻角、对角线），五种判定方法与等腰梯形这个反例，接着是底乘高的面积、求角的例题、周长与对角线的例题，最后收在三个易错点上。

知识精讲

概念 · 公式 · 例题
概念

定义与四条性质

两组对边分别平行的四边形，叫平行四边形。记作 ▱ABCD，字母要按顺序写。

四条性质：① 两组对边分别平行且相等；② 两组对角分别相等；③ 相邻的两个角互补，和是 180°；④ 两条对角线互相平分。

对边平行且相等，对角相等

概念

五种判定方法

① 两组对边分别平行；② 两组对边分别相等；③ 一组对边平行且相等；④ 对角线互相平分；⑤ 两组对角分别相等。

注意：「一组对边平行、另一组对边相等」不能判定平行四边形，等腰梯形就满足这个条件却不是平行四边形。

一组对边平行且相等

公式

面积：底乘高

平行四边形的面积等于底乘高，S = ah。高是从一条边到对边的垂直距离，不是斜边。

同一个平行四边形，选不同的边作底，对应的高也不同，但底乘高的结果不变。

S = 底 × 高

公式

对角线互相平分

两条对角线相交于一点 O，O 同时是两条对角线的中点：OA = OC，OB = OD。

这条性质在做题时最常用：给了整条对角线，除以 2 就是一半；给了两半相等，就能证平行四边形。

OA = OC，OB = OD

例题

例：∠A = 60°，求另外三个角

对角相等：∠C = ∠A = 60°。邻角互补：∠B = 180° − 60° = 120°。

再对角相等：∠D = ∠B = 120°。检验：60 + 120 + 60 + 120 = 360°，正好是四边形的内角和。

60°、120°、60°、120°

例题

例：求周长与对角线的一半

AB = 5，BC = 8。对边相等，所以 CD = 5，AD = 8，周长 = 2×5 + 2×8 = 26。

若对角线 AC = 10，O 是 AC 的中点，所以 OA = 10 ÷ 2 = 5。

周长 26，OA = 5

一句话记住

两组对边分别平行的四边形叫平行四边形。四条性质：对边平行且相等、对角相等、邻角互补、对角线互相平分。五种判定：两组对边分别平行、两组对边分别相等、一组对边平行且相等、对角线互相平分、两组对角分别相等；但「一组对边平行、另一组对边相等」不够，等腰梯形就是反例。面积 S = 底 × 高，高必须是垂直距离。例题：∠A = 60° 时，∠C = 60°、∠B = ∠D = 120°；AB = 5、BC = 8 时周长是 26，AC = 10 时 OA = 5。记住：对角线互相平分，是平行四边形最好用的性质。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 面积拿斜边当高：高必须垂直于对边。
  • 「一组对边平行、另一组对边相等」当成判定：等腰梯形是反例。
  • 把「对角线相等」当判定条件：那是矩形的性质，不是平行四边形的判定。
  • 邻角当成相等：邻角是互补，对角才相等。
  • 求对角线时忘了一半：对角线互相平分，OA = AC ÷ 2。
