三角函数定义与诱导公式

一全正，二正弦

摩天轮转到哪个位置，座舱的高度和水平距离就由角度决定。把角放在单位圆上，终边交点的纵坐标就是正弦、横坐标就是余弦，这就是三角函数的定义。有了单位圆，一百多度的角也能算三角函数值，靠的就是诱导公式：把大角化小、把负角化正。符号规律记一句话：一全正、二正弦、三正切、四余弦。

知识精讲

概念 · 公式 · 例题
概念

任意角与弧度制

角可以任意大，也可以为负：逆时针为正，顺时针为负。

与角 α 终边相同的角写成 α + k · 360°（k 为整数）。

弧度制规定 π 弧度等于 180°，所以 1 弧度约为 57.3°。

弧长 l = |α| r，扇形面积 S = ½ l r = ½ |α| r²。

π rad = 180°

概念

用单位圆定义

把角 α 的顶点放在原点、始边与 x 轴正半轴重合，终边与单位圆交于点 P(x, y)。

规定 sinα = y，cosα = x，tanα = y / x（x ≠ 0）。

所以正弦是纵坐标、余弦是横坐标，正切是纵坐标比横坐标。

因为点在半径为 1 的圆上，所以 sinα 与 cosα 都在 [−1, 1] 内。

sinα = y，cosα = x

公式

同角关系

平方关系：sin²α + cos²α = 1，它来自单位圆上 x² + y² = 1。

商数关系：tanα = sinα / cosα，要求 cosα ≠ 0。

知道一个角的正弦或余弦，用平方关系能求出另一个，但要先判断符号。

切化弦、弦化切，是同角关系最常见的两种用法。

sin²α + cos²α = 1

公式

诱导公式

公式一：α + 2kπ 与 α 终边相同，三角函数值完全不变。

公式二：sin(−α) = −sinα，cos(−α) = cosα，tan(−α) = −tanα。

公式三：sin(π − α) = sinα，cos(π − α) = −cosα。

公式四：sin(π + α) = −sinα，cos(π + α) = −cosα。

sin(π − α) = sinα

概念

四个象限的符号

第一象限：正弦、余弦、正切全为正。

第二象限：只有正弦为正，余弦和正切为负。

第三象限：只有正切为正，正弦和余弦为负。

第四象限：只有余弦为正，正弦和正切为负，口诀是一全正、二正弦、三正切、四余弦。

一全正，二正弦

例题

例 1：已知正弦求余弦和正切

已知 sinα = 3/5，α 在第二象限，求 cosα 与 tanα。

先用平方关系：sin²α + cos²α = 1，得 cos²α = 1 − 9/25 = 16/25，所以 cosα = ±4/5。

第二象限余弦为负，取 cosα = −4/5。

再用商数关系：tanα = sinα / cosα = (3/5) / (−4/5) = −3/4。

cosα = −4/5，tanα = −3/4

例题

例 2：先化锐角，再定符号

求 sin150° + cos240°。

150° = 180° − 30°，用 sin(π − α) = sinα，得 sin150° = sin30° = 1/2。

240° = 180° + 60°，用 cos(π + α) = −cosα，得 cos240° = −cos60° = −1/2。

相加：1/2 + (−1/2) = 0。每一步先化到锐角，再按象限定符号。

sin150° + cos240° = 0

一句话记住

三角函数用单位圆定义：终边与单位圆交于 P(x, y)，则 sinα = y、cosα = x、tanα = y/x。同角关系是 sin²α + cos²α = 1 与 tanα = sinα/cosα。诱导公式把任意角化到第一象限，核心是「奇变偶不变，符号看象限」。符号规律记一全正、二正弦、三正切、四余弦。

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 已知一个三角函数值求另外两个，先定象限，再选正负号。
  • 化简诱导公式，先把角化成 kπ/2 ± α 的形式，再判断函数名和符号。
  • 角度与弧度混用，先统一单位，再代公式。
04

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 忘记讨论象限：由 sinα 求 cosα 时，正负要看 α 在第几象限。
  • 把 cos(π − α) 写成 cosα：余弦在第二象限为负，要加负号。
  • tanα 忽略分母：cosα = 0 时正切不存在。
  • 角度弧度混用：同一个式子里不能一半用度、一半用弧度。
