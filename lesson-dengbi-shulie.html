等比数列

后项比前项等于 q

等比数列从第二项起，每一项与前一项的比都等于同一个常数 q。通项 aₙ = a₁qⁿ⁻¹，前 n 项和要分 q = 1 与 q ≠ 1 两种情况。等比中项、下标运算、求和讨论，是这一节最常考的三件事。

01

知识精讲

概念 · 公式 · 例题
概念

定义与公比

从第二项起，每一项与前一项的比都等于同一个常数 q，这个数列叫等比数列，q 叫公比。

q 不能为 0，等比数列的每一项都不能为 0。

q > 0 时各项同号；q < 0 时各项正负交替。

判断一个数列是否为等比数列，要看 aₙ₊₁/aₙ 是否为与 n 无关的常数。

aₙ₊₁ / aₙ = q

公式

通项与下标

通项 aₙ = a₁ qⁿ⁻¹。

更一般地，aₙ = aₘ qⁿ⁻ᵐ，指数是下标之差。

已知任意两项，可以先用 aₙ/aₘ = qⁿ⁻ᵐ 求 q，再求首项。

下标运算时，指数是「大下标减小下标」，不要写反。

aₙ = a₁ qⁿ⁻¹

公式

前 n 项和

当 q = 1 时，Sₙ = n a₁。

当 q ≠ 1 时，Sₙ = a₁(1 − qⁿ)/(1 − q) = a₁(qⁿ − 1)/(q − 1)。

使用求和公式前，必须先判断 q 是否等于 1。

含参数的等比数列求和，往往要分 q = 1 与 q ≠ 1 讨论。

Sₙ = a₁(1−qⁿ)/(1−q)

例题

例 1：求通项与和

等比数列首项 a₁ = 2，公比 q = 3，求 a₅ 与 S₅。

a₅ = a₁q⁴ = 2 × 3⁴ = 162。

S₅ = 2(1 − 3⁵)/(1 − 3) = 2(1 − 243)/(−2) = 242。

也可以用 S₅ = 2 + 6 + 18 + 54 + 162 验证。

a₅ = 162，S₅ = 242

概念

等比中项

若 a、b、c 成等比数列，则 b² = ac，b 叫 a 与 c 的等比中项。

注意 b 可以取正或负，具体符号由所在项的位置决定。

只有 a、c 同号时，才存在实数等比中项。

等比中项与等差中项不同：等差是 2b = a + c，等比是 b² = ac。

b² = ac

一句话记住

通项 a₁qⁿ⁻¹，求和先看 q 是否为 1；等比中项 b² = ac，注意正负。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「求 a₅」改成「已知 a₃、a₆ 求 q」，用 a₆/a₃ = q³。
  • 把「q ≠ 1」改成「q = 1」，求和直接写 n a₁。
  • 把「等比中项」改成「三项成等比求参数」，列 b² = ac 解方程并检验。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 公比 q 不能为 0，等比数列中不能出现 0 项。
  • 求和前忘记讨论 q = 1，直接套公式会分母为零。
  • 等比中项有正负两个可能，不能只取正。
  • 下标运算指数写反，把 aₙ = aₘqⁿ⁻ᵐ 写成 aₘqᵐ⁻ⁿ。
