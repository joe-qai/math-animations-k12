02

知识精讲

概念 · 公式 · 例题
概念

方程就是一台天平

天平左边放 2 个相同的方块，再加一个 3 克的砝码；右边放 11 克，天平正好平衡。

把这件事写成数学式子：2x + 3 = 11。这里的 x 就是每个方块的重量，是我们要求的未知数。

「=」就像天平的横梁：左右两边一样重，才能平衡。

公式

等式的基本性质

天平两边同时拿走同样重的东西，天平仍然平衡；同时把两边都分成相同的份数，也仍然平衡。

方程也一样：两边同时加、减、乘、除同一个数（除数不为 0），等式仍然成立。这是解方程的全部依据。

若 a = b，则 a ± c = b ± c；a ÷ c = b ÷ c（c ≠ 0）

例题

解 2x + 3 = 11

第一步，去掉左边的 3：两边同时减 3，得到 2x + 3 − 3 = 11 − 3，即 2x = 8。

第二步，求一个 x：两边同时除以 2，得到 x = 4。一个方块重 4 克。

概念

检验：把答案代回去

把 x = 4 代回原方程：2 × 4 + 3 = 8 + 3 = 11，等于右边，成立。

检验不是多余的一步。它能抓住「只在一侧运算」「移项不变号」这类最常见的错误。

一句话记住

解方程的核心只有一句话：两边同时做相同的事。把未知数周围的数一层层剥掉，最后让 x 单独留在一边。

03

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 只在一边减 3，另一边不动——天平立刻失衡。必须「两边同时」。
  • 移项要变号：把 +3 移到右边，要写成 −3。
  • 算完不检验，符号错误很难自己发现。
