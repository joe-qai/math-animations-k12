函数及其应用（中考专题）

一次、反比例、二次：一张图看懂三种函数

函数是中考分值最高的一块，也是压轴题的主战场。这一节按「图像—解析式—最值—建模」四条线梳理：一次函数里 k 决定增减、b 是与 y 轴交点的纵坐标，待定系数法两点定一条直线，与 x 轴交点就是方程 kx + b = 0 的解；反比例函数要画两支，k 的几何意义是矩形面积 |k|，与一次函数的交点靠联立方程；二次函数三种写法各有用途，对称轴 x = −b/2a，开口看 a；求最值时先配方再看顶点是否落在题目给的区间内，这是最大的分水岭；最后用一道利润题走完设、列、求顶点、作答四步。

知识精讲

概念 · 公式 · 例题
概念

一次函数：k 与 b 的意义

y = kx + b 中，k 决定增减：k > 0 时 y 随 x 增大而增大，k < 0 时相反；b 是图像与 y 轴交点的纵坐标。

求解析式用待定系数法：找两个点代入，解出 k 与 b。图像与 x 轴的交点横坐标，就是方程 kx + b = 0 的解。

y = 2x − 1 过 (0, −1) 与 (2, 3)

概念

反比例函数：两支与 |k|

y = k/x 的图像是两支：k > 0 在一、三象限，k < 0 在二、四象限，每一支各自单调。只画一支是常见错误。

k 的几何意义：图像上任意一点向两坐标轴作垂线，与坐标轴围成的矩形面积等于 |k|。与一次函数的交点，把两个解析式联立解方程即可。

S矩形 = |k|

公式

二次函数：三种写法

一般式 y = ax² + bx + c；顶点式 y = a(x − h)² + k；交点式 y = a(x − x₁)(x − x₂)。给顶点用顶点式，给两个交点用交点式。

对称轴 x = −b/2a，顶点坐标代回解析式算。开口方向看 a：a > 0 向上有最小值，a < 0 向下有最大值。

对称轴 x = −b/2a

例题

例：顶点不在区间内

求 y = x² − 2x − 3 在区间 [2, 4] 上的最小值。配方得 y = (x − 1)² − 4，顶点是 (1, −4)，但 x = 1 不在区间内，函数在 [2, 4] 上单调递增。

所以最小值在端点 x = 2 处取得，y(2) = −3。这正是很多人直接写 −4 而丢分的地方。

y(2) = −3

例题

例：利润最大化

每件利润 x 元，每天可卖 40 − 2x 件，总利润 W = x(40 − 2x) = −2(x − 10)² + 200，其中 0 < x < 20。

顶点 x = 10 在范围内，所以每件利润 10 元时总利润最大，为 200 元。作答时要写清单位和结论。

W = −2(x − 10)² + 200

概念

函数应用的四步

设自变量并写出取值范围；列函数关系式；配方求顶点并检查是否在范围内；回答问题、带单位。

常见模型：销售利润、抛物线拱桥与投篮、围栏面积。取值范围往往由实际意义决定，比如件数为整数、长度为正。

设 → 列 → 求 → 答

一句话记住

函数复习抓四件事。第一，看图像说性质：一次函数的 k 定增减、b 定截距；反比例函数是两支、矩形面积为 |k|；二次函数看 a 的开口、对称轴 x = −b/2a。第二，求解析式用待定系数法，二次函数按已知条件选一般式、顶点式或交点式。第三，求最值必须先配方，再判断顶点是否落在题目给的区间内：在就取顶点，不在就取端点。第四，应用题按设、列、求、答四步走，取值范围由实际意义决定，最后一定要带单位作答。

易错提醒

先避开，再提速

这三个坑，考试里最常见

  • 忽略 k 的符号，把增减性说反。
  • 反比例函数只画一支，或把两支连成一条曲线。
  • 求最值不看取值范围，顶点不在区间内也直接写顶点。
  • 求出解析式不回代检验，点是否在图像上不确定。
  • 应用题算出结果不写单位、不回答题目问的那句话。
