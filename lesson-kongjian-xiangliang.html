空间向量与立体几何

建系、求法向量、算角

空间向量把立体几何变成计算题：先找两两垂直的三条线建系，写出各点坐标；再求平面的法向量；线面角用 sin，二面角用两法向量的夹角，点到平面的距离用点积投影。步骤固定，关键是坐标写对、法向量解对。

知识精讲

概念 · 公式 · 例题
概念

建系与坐标

优先选三条两两垂直的直线作 x、y、z 轴，常见于正方体、长方体、直棱柱。

把交点作为原点，尽量让更多点落在坐标轴上或坐标平面内。

写坐标时逐点确认「到三个坐标平面的距离」，不要凭感觉。

建系方式不唯一，选计算量最小的一种。

O-xyz 右手系

公式

法向量与线面角

平面 α 的法向量 n 与平面内任意向量都垂直，满足 n·AB = 0 且 n·AC = 0。

求法向量时先设 n = (x, y, z)，代入两个点积方程，令其中一个分量为 1，解出另外两个。

直线与平面所成角 θ 满足 sinθ = |a·n| / (|a||n|)，其中 a 是直线的方向向量。

注意线面角用 sin，不是 cos；线面角的范围是 0° 到 90°。

sinθ = |a·n| / (|a||n|)

例题

例 1：求平面法向量

平面过 A(1,0,0)、B(0,1,0)、C(0,0,1)，求它的一个法向量。

AB = (−1, 1, 0)，AC = (−1, 0, 1)。

设 n = (x, y, z)，则 −x + y = 0，−x + z = 0，所以 y = x，z = x。

取 x = 1，得 n = (1, 1, 1)。

n = (1, 1, 1)

公式

距离与二面角

点 P 到平面 α 的距离 d = |AP·n| / |n|，其中 A 是平面内任意一点。

二面角的大小等于两个半平面法向量的夹角或其补角，最后要结合图形判断。

求二面角时，先分别求两个平面的法向量，再算夹角余弦。

若图形显示二面角是锐角，而法向量夹角余弦为负，就取它的相反数。

d = |AP·n| / |n|

例题

例 2：线面角

正方体棱长为 1，求体对角线 AC₁ 与底面 ABCD 所成角的正弦值。

以 A 为原点，AB、AD、AA₁ 为坐标轴，则 A(0,0,0)、C₁(1,1,1)。

AC₁ = (1,1,1)，底面法向量 n = (0,0,1)。

sinθ = |AC₁·n| / (|AC₁||n|) = 1 / √3 = √3/3。

sinθ = √3/3

一句话记住

建系写点、解方程求法向量；线面角用 sin，二面角看图形定锐钝，距离用点积投影。

02

变式提醒

换个条件，再走一遍

同一道题，换三种问法

  • 把「求线面角」改成「求点到平面的距离」，直接套 d = |AP·n|/|n|。
  • 把「二面角」改成「证明面面垂直」，只需证两个法向量点积为零。
  • 把「正方体」换成「直三棱柱」，建系后坐标多一个高度分量。
03

易错提醒

先避开，再提速

这几个坑，考试里最常见

  • 线面角用 sin，二面角用 cos，两个公式不能混。
  • 法向量不唯一，但方向要一致；解方程时不要漏掉一个分量。
  • 二面角可能是法向量夹角的补角，最后必须结合图形判断。
  • 建系后坐标写错，后面的计算全错；写点前先核对三条轴。
